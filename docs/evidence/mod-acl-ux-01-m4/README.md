# MOD-ACL-UX-01 M4 — «Векторная память»: реальные параметры и честная пустота

Доказательства к коммиту правки страницы `#/modules/embeddings`
(MOD-ACL-UX-01 M4). Всё воспроизводится ОДНОЙ командой, без ручной сборки
окружения.

## Команда

```bash
py -3 tools/ui_mod_acl_m4_embeddings_e2e.py
```

Что она делает:

1. поднимает локальный http-стенд с НАСТОЯЩИМИ `web/index.html` + `web/app.js`
   (Telegram не задействован: синтетическая TMA-идентичность, `/api/*`
   перехватываются);
2. достаёт дерево `web/` базового коммита через `git archive` (по умолчанию
   `--base dd52cbf9`) и поднимает второй такой же стенд — так «до» и «после»
   снимаются с одного маршрута и одного набора API-ответов;
3. `/api/config` собирается из `services/param_catalog.py`: все непустые
   категории каталога, секреты — `{configured,last4}` (как маскирует продукт),
   плюс `modules = registry_for_frontend()`; для области «Векторной памяти» это
   ровно `models_embeddings` 16 + `keys_llm` 9 = 25 параметров;
4. идентичность — синтетический ГЛОБАЛЬНЫЙ админ (`/api/me`
   `is_global_admin: true` и `/api/access/me`), поэтому область — GLOBAL, как
   на снимке владельца;
5. рендерит оба состояния в 1280x900, снимает PNG и проверяет DOM.

Полезные флаги: `--out DIR` (артефакты), `--base SHA` (другая база),
`--serve-only` (поднять стенд и осмотреть вручную; в консоли нужен TMA-стаб —
команда печатается самим скриптом).

Маркер успеха: `MOD-ACL-M4-EMBEDDINGS OK`, код возврата 0.

## Что именно проверяется (DOM, а не «выглядит нормально»)

База `dd52cbf9` (дефект владельца):

* вкладки: только `['overview']`, параметров 0;
* блок пустой вкладки присутствует и содержит ложную причину
  «…сервер отфильтровал их по правам».

Кандидат:

1. вкладки `['overview', 'settings']`, на «Обзоре» пустого блока нет,
   в тексте страницы НЕТ слов про фильтр прав;
2. «Основные настройки»: группы `keys_llm` («Основная нейросеть», 9) и
   `models_embeddings` («Отпечатки текста и длина», 16) в порядке каталога,
   всего 25 параметров; поле поиска доступно;
3. поиск `embedding_dim` сужает набор до одного параметра (внутри набора
   групп страницы) и не подменяется пустым блоком;
4. четыре честные причины пустого блока выбираются по фактическому состоянию
   компонента и видны в DOM (`data-empty-cause`):
   `no-data`, `scope`, `filtered`, `none`; упоминание прав появляется ТОЛЬКО
   в `filtered`.

## Про Browser Use

Для этого доказательства Browser Use НЕ нужен: снимки и DOM-проверки делает
локальный Chromium внутри Playwright. Если браузерный MCP в окружении ревьюера
падает на постороннем модуле (`oci` — Oracle Cloud SDK), к проекту это
отношения не имеет: `oci` нигде в репозитории не импортируется. Второй
браузерный линзой можно осмотреть тот же стенд через `--serve-only`.
