# AdminBot — ваш карманный цифровой абьюзер с элементами ИИ

*Решение для тех, кто хочет токсичности в чате, но ленится писать сам. Теперь с памятью слона, терпением снайпера и запасным аэродромом для нейронки.*

**Версия:** v2.43.0 | **Тестов:** 2611 | **Язык:** русский (как сами ответы, так и этот файл)

Бот живёт в Telegram-группе, следит за несколькими героями чата, реагирует на слова-триггеры и умеет пользоваться нейросетью: подслушивает переписку, делает саммари, проверяет факты, гуглит, пересказывает видео и сайты и даже лечит себя сам. Всё это — с иронией, за которую его и держат.

---

## Быстрый старт

```bash
pip install -r requirements.txt
cp .env.example .env          # впиши API_TOKEN от @BotFather, остальное опционально
mkdir -p media/dead_page media/leha_greeting media/slavik/slavik_random
mkdir -p media/common/otboy media/common/danger media/common/selfdev media/common/work media/common/goodmorning
py bot.py                       # на Linux — python3 bot.py
```

Накидай в папки `media/` файлы (фото/видео/GIF — бот сам разберётся, что куда) — и всё, через три секунды бот готов страдать фигнёй в продакшене.

> Команды запуска даны для Windows (`py`). На Linux замени `py` на `python3`.

## Где живут настройки

**Всё настраивается одним файлом — `.env`.** В коде дефолты, в `.env` — правда жизни. Hot-reload не завезли: поменял — перезапусти бота.

- **На сервере:** `nano /var/www/admin_bot/.env` → сохранил → `systemctl restart admin_bot`.
- **Локально:** правь `.env` (создай его из шаблона `cp .env.example .env`). Сам `.env.example` — шаблон: в него добавлены все переменные с дефолтами и комментариями, можно смело переписать его в рабочий `.env`.
- **Перед правкой сделай копию:** `cp .env .env.bak.epic59`. Откатить всегда быстрее, чем вспоминать, что ты там менял в три часа ночи.
- **Секреты (токены, ключи) живут только в `.env`.** В README — ни одного ключа: здесь только имена переменных. В git `.env` не коммитим (для этого есть `.env.example` с плейсхолдерами).

Куда смотреть, если что-то сломалось: в секцию «Мониторинг» ниже.

## Функции бота

### Люди, за которыми бот следит

#### Слава — главный герой этого цирка

- **Возвращение.** Зашёл в чат (покинул → вернулся) → бот пишет **«ДОЛБОЕВ ВЕРНУЛСЯ»**. Каждый раз одно и то же, и каждый раз смешно. Славе — нет.
- **Dead Page.** Слава делает репост из канала **@d_pages** → бот берёт случайный пост из своего приватного канала (где он должен быть админом) и пересылает его в чат. Альбомы пересылаются целиком, без разрывов. Два раза подряд один и тот же пост не шлётся — разнообразие превыше всего. Если приватный канал упал или бота оттуда выгнали — fallback: случайная картинка + случайный текст из папки `media/dead_page/`.
- **Месть за удалённый репост.** Telegram не сообщает боту, что Слава снёс репост. Поэтому бот узнаёт об этом окольным путём: когда кто-то отвечает или цитирует удалённое сообщение. Узнал → удаляет свою dead page. Нет прав на удаление → отправляет одну токсичную фразу из пула (в духе «снёс репост мёртвой страницы? стыдно стало?»). Ровно одно срабатывание на один репост — двойной порции не будет.
- **Чат-реакции** — трёхуровневая система эскалации. На одно сообщение срабатывает ровно один сценарий, в жёстком порядке приоритетов: dead page → гифка → рандом-медиа → mimic → «пошёл нахуй»:
  1. Написал «куча»/«кучи»/«кучу» → **«ДАЛБАЕБ»** (прицельный выстрел по грамматике).
  2. Каждое 5-е сообщение → **гифка** (`media/slavik/slavic_chlen.mp4`; файл реально так называется).
  3. Каждый 10-й ответ «пошёл нахуй» → **случайное медиа** из `media/slavik/slavik_random/` — фото, видео, GIF, аудио, войс или вообще любой файл. Вместо текста, а не вместе с ним.
  4. Длинное сообщение (больше 5 слов) → **шепелявый mimic** (передразнивание, см. ниже).
  5. Всё остальное → **«пошёл нахуй»** (catch-all, потому что Слава всегда заслуживает).
- **Военный оповещатель.** Слава пишет военные слова (дрон, БПЛА, ракета, тревога, убежище и ещё 90+ словоформ) — бот отвечает случайной фразой из пула: «потрясись», «повизжи», «прячься под шконку быстрее» и соседями. Психологическая поддержка наоборот. Слова ловятся в обычных сообщениях, в подписях к медиа и в репостах. Отдельно: репост из каналов «ЧП Пермь» или «Радар БПЛА» (от любого пользователя) — тоже ор.

#### Алан — объект пристального интереса

- **Приветствие при входе.** Зашёл в чат → случайное видео из `media/leha_greeting/` с подписью `@Alan_Z`.
- **Приветствие после сна.** Молчал дольше 6 часов и наконец написал → приветственное видео «с возвращением». Бот как будто соскучился. На самом деле — просто фототропизм на движение. Таймер молчания хранится в БД и переживает рестарт бота.
- **Автоответчик.** Каждые 10 сообщений Алана бот проявляет крайний интерес к его темам: NixOS, продажа SSD по цене трёх таких же, витамины Life Extension, 5-секундные прогулки с гантелями, уличный тренажёр и реванш за колени. Всего в пуле 52 фразы плюс вопросы-подколы («а ты вообще разминался? или как обычно — с дивана сразу к штанге?»). **На проде реплики выключены** рубильником `ALAN_REPLIES_ENABLED=False`: фразы написаны, отрепетированы и пока никому не показаны. Алан страдает молча.

#### Костик — генератор случайных оскорблений

На каждое сообщение Костика — случайное оскорбление из пула. Вероятность настраивается: `1.0` = всегда, `0.0` = никогда (режим «Костик в отпуске»). Костик не выбирал эту жизнь, жизнь выбрала его.

#### Вася / Админ — лингвистическая симметрия

- Написал «вася» (в любых формах) → **«АДМИН»**
- Написал «админ» → **«ВАСЯ»**

Это не баг, это зеркало души чата.

#### Оля — отдельное внимание за отдельные видео

Оля присылает видео/фото с подписью «Спасибо, что пользуетесь - @SaveAsBot'ом» → бот отвечает случайным медиа из `media/olya/cringe/` (простым сообщением, без цитирования). Триггер срабатывает, если: подпись содержит этот текст (сравнение не придирается к тире, апострофам и регистру), или в подписи упомянут `@SaveAsBot`, или это репост от самого SaveAsBot. Обычные видео Оли игнорируются — точность прежде всего. Хочешь старый беспредел (реакция на всё подряд)? `OLYA_ALWAYS_SEND=True`.

### Общие реакции на слова

Бот слушает весь чат и реагирует на слова-триггеры. Слова ловятся в тексте и в подписях к медиа; регистр не важен («Отбой», «ОТБОЙ», «отбой» — всё сработает); матчится только отдельное слово («отбойный» не сработает). Ответ приходит реплаем на сообщение, и в Telegram подсвечивается именно найденное слово (нативное цитирование).

- **Отбой.** Кто-то пишет «отбой» → случайное медиа из `media/common/otboy/`.
- **Danger.** Danger-слова (118 словоформ: бпла, ракетная, сирена, взрыв, хлопок…) или фразы-связки (17 штук: «ракетная атака», «уйти в бомбоубежище», «атака дронов»…) → случайное медиа из `media/common/danger/`. Одиночные «атака»/«угроза»/«прилёт» больше не будят бота — только в связках: обсуждение игры за «атаку» бота не волнует.
- **Selfdev.** «саморазвитие», «личностный рост», «прокачка» → мотивирующее медиа из `media/common/selfdev/`. Репосты игнорируются: саморазвитие — дело личное.
- **Work.** «устал», «заебался», «запарился», «нет сил» → сочувствующее медиа из `media/common/work/`. Сочувствие — случайный файл. Репосты мимо: чужая усталость — чужая проблема. **На проде выключено** (`COMMON_WORK_MEDIA_ENABLED=False`) — усталые страдают молча.
- **Goodmorning.** Раз в сутки в настроенное время (по умолчанию 07:00) бот будит чат случайным медиа из `media/common/goodmorning/` и случайной подписью из пула («❗️❗️❗️ ПАДЪЕМ НИГЕРЫ…» и ещё пять в том же тоне). По умолчанию рассылка выключена — пока не задан список чатов, будильник молчит, и это правильно.

От спама защищают двухуровневые кулдауны: общий на все common-реакции плюс персональный на danger/selfdev/work. Подробности — в таблице параметров.

#### Mimic — передразнивание

Шуточная трансформация текста «под шепелявость»: «что» → «фе», «учишься» → «учифся», «рука» → «люка». Это чистая замена букв по словарю и правилам, без нейросети. Работает в двух местах:

- Для жертв из списка `MIMIC_VICTIM_USER_IDS` — если сообщение длинное (больше 5 слов) и не репост.
- Для Славика — встроено в его цепочку реакций (см. выше).

Репосты бот не передразнивает — цитирует только первоисточники. Проверить трансформацию можно командой `/mimic [текст]`.

### ИИ-сервисы (SmartModule)

Мозг бота — нейросеть через провайдера apinet.cloud (модель `deepseek-v4-flash`).

#### Summary — бот, который подслушивает

Бот слушает **весь** чат и раз в 6 часов (00:00 / 06:00 / 12:00 / 18:00 по Екатеринбургу) выдаёт токсично-ироничное саммари: кто с кем спорил, кто какую хуйню сморозил и кто оказался «самым главным шизом». Или по команде `/summary` — если не спамить (кулдаун на повторный вызов, с фразой-отборкой, где честно указано, сколько ещё ждать: «хули ты дрочишь, подожди 42 секунды»).

Имена в саммари подставляются по каскаду: алиас (из `SUMMARY_ALIASES`) → имя и фамилия → username → ID. Длинный ответ приезжает кусками с паузой, чтобы не упираться в лимиты Telegram.

**Трёхуровневая память — как у слона с амнезией по расписанию:**

| Уровень | Срок | Что это |
|---|---|---|
| L1 — окно генерации | 6 часов | Свежая история, которую бот реально читает (до 500 сообщений / 120 000 символов) |
| L2 — сырая память | 30 дней | Полная переписка для точных цитат из прошлого (поиск по ключевым словам) |
| L3 — векторный архив | 90 дней | Старьё сжимается нейронкой в факты по темам и ищется по смыслу (если векторный поиск не завёлся — ищется текстом, бот не падает) |

**Бот не умеет падать:** упал векторный поиск → текстовый; упала нейронка → честное «не смог сделать саммари потому что упал апи»; упала база данных → «база данных подавилась». Маленькими буквами, без техдеталей. UX-дизайн уровня «прости, я в пролёте».

**Свежие апгрейды:**
- Лимиты контекста теперь считаются **в токенах** (tiktoken), а не в буквах. Точнее, чем «на глаз».
- **Бегущий конспект:** контекст заполнился на 80% → старые сообщения тихо сжимаются в саммари, последние дословно. Нейронка не захлёбывается, история не теряется.
- **Стриминг саммари** (тестовый режим, по умолчанию выключен): длинное саммари «растёт» на глазах вместо ожидания готовой простыни.

#### DirectChat — бот вливается в разговор

Бот отвечает на **прямые обращения** — и только на них. Сам он никогда не начинает диалог (скромный):

- **Реплай** на сообщение бота.
- **Тег** `@username` в сообщении.
- **Слова-триггеры:** «бот», «ботик», «ботяра», «ботина», «ботохуета», «ботохуйня». Матчится только слово целиком: «робот», «работа» и «забота» бота не будят, а вот «ботохуета» — будит. Шаблон настраивается через конфиг (`CHAT_BOTWORD_PATTERN`), а не зашит в код — хочешь другие слова, вперёд. (Выключается флагом `DIRECT_CHAT_BOTWORD_ENABLED`; Алана и Костика эта ветка не касается — их сообщения уходят своим хендлерам.)
- Команды `/…` бот не перехватывает — у них своя жизнь.

При ответе бот держит в голове контекст: последние 100 сообщений чата, цепочку ответов глубиной до 6 и память о прошлых диалогах с тобой. Диалоги запоминаются отдельно и в чужие саммари/фактчеки не подмешиваются.

**Защита от «задрочивания» бота:**
- **Token Bucket:** 3 обращения подряд — дальше кулдаун (по умолчанию 5 минут) с фразой, где честно указано оставшееся время.
- **Circuit Breaker (предохранитель):** 3 сбоя нейронки подряд → бот на 5 минут перестаёт дёргать нейросеть и отвечает человечными отмазками из пула («мозги временно ушли на профилактику, скоро вернутся» и ещё три в том же духе). Истёк срок — одна пробная попытка: мозг вернулся с обеда → работаем; снова сбой → ещё пять минут тишины.
- **Фоллбэк-провайдер:** бот ходит в apinet.cloud (модель `deepseek-v4-flash`) через OpenAI-совместимый клиент; при сбое провайдера срабатывает фоллбэк-провайдер, если настроен в .env.

**Ещё слои защиты и вежливости (новое):**
- **Дедуп повторов.** Пишешь «бот бот бот» пять раз подряд — получишь один ответ, остальные из кэша. Модель не дёргается, деньги не тратятся, ты всё равно не услышал ничего нового.
- **Молчание после 5 кулдаунов подряд.** Долбишься в закрытую дверь — бот перестаёт её открывать вообще. Навязчивым собеседникам — тишина, это тоже ответ.
- **Пустой ответ нейронки → реакция 🗿.** Раньше были заглушки, теперь просто истукан. Во всех ИИ-фичах: молчаливое осуждение универсально.
- **Индикатор «печатает…»** у всех фич смарт-модуля: горит, пока нейронка думает. Бот выглядит живым, искусственных пауз нет.
- **Стилевые якоря:** бот видит свои недавние ответы и держит тон — не скатывается из токсичного абьюзера в вежливого консультанта на середине мысли.
- **Ловля настроения:** лёгкая подстройка тона под твоё состояние через контекст (системный промпт неприкосновенен — канон есть канон).
- **Температура модели пресетами:** точный / сбалансированный / болтливый. Три степени откровенности.
- **Правка ответа ботом** → память цепочки обновляется. Цепочка не врёт даже после редактур.

**Команды прямо в диалоге с ботом:**
- `/clear` — сбросить память текущего разговора. Начали с чистого листа.
- `/persona [имя]` — карточка человека из памяти графа: что бот о тебе (или о нём) накопал. Без аргумента — своя карточка; `/persona <имя>` и `/persona list` — только для админа.
- `/tone` — переключить тон: формально ↔ по-свойски.
- `/forget` — забыть конкретный неверный факт или всё сразу. Важное помечено защищённым: при сжатии памяти и /forget не стирается. Слон забывает выборочно.

#### SmartCache — не платим за одно и то же дважды

Спросил бота про одно и то же второй раз — зачем дёргать нейронку и платить повторно? SmartCache запоминает ответы на умные запросы: повторный одинаковый вопрос в течение 30 минут (TTL кэша — 1800 секунд) получает готовый ответ из кэша, мгновенно и бесплатно. Кэш держит до 1000 ответов, старые вытесняются. По умолчанию выключен — включается рубильником `SMART_CACHE_ENABLED=True` (подробности в таблице параметров).

#### FactCheck — суд присяжных по заявке

Отвечаешь реплаем на чьё-то сообщение и начинаешь ответ со слова **«фактчек»** — бот берёт проверяемый текст, гоняет его через поисковики (каскад Tavily → Exa → DuckDuckGo) и выдаёт токсичный вердикт через нейронку, **реплаем на проверяемое сообщение**. Как будто позвал арбитра, который не умеет быть вежливым.

- Всё, что написано после слова «фактчек» («фактчек да ты что, это давно опровергли»), уходит нейронке как подсказка.
- Репост тоже можно фактчекнуть (триггер в подписи) — реплай не обязателен.
- Стикер или фото без текста → порция абьюза без поиска. Проверять нечего — осуждать всегда есть кого.
- Регистр не важен; «фактчекинг» не матчится — не надо тут терминов.

#### SmartSearch — «загугли за меня, я устал»

Пишешь **«найди/поищи/загугли + запрос»** — бот собирает факты через те же поисковики, выжимает суть через нейронку и присылает токсичную выжимку реплаем на твоё сообщение. Не сарказм ради сарказма — там и факты есть. «Найди» без запроса → порция абьюза, поисковики не беспокоим: они для тех, кто дописал мысль.

#### YouTube — пересказ видосов

Пишешь **«транскрипт», «че за видос», «о чем видео», «поясни за видос», «перескажи видос», «че в видосе»** плюс ссылка на YouTube (`youtube.com/watch?v=`, `shorts/`, `youtu.be/`) — бот вытаскивает субтитры (русские → английские → автогенерация), клеит таймкоды `[MM:SS]` и скармливает нейронке с токсичным промптом. Если YouTube тупит — бот честно ретраит с токсичными уведомлениями («ютуб опять тупит, пробую выдрать текст еще раз»). Нет субтитров совсем → «в этом высере нет субтитров, сиди и слушай ушами». Ссылку можно прислать и реплаем на чьё-то сообщение со ссылкой — ответ придёт на него же.

#### Web — пересказ страниц

Пишешь **«поясни за ссылку», «че по ссылке», «о чем статья», «поясни за статью», «выжимка», «че на сайте», «перескажи статью»** плюс любой http(s)-URL — бот читает страницу (локальный парсер, при провале — Tavily/Exa) и пересказывает суть. Сайт сдох или за пейволлом → «сайт сдох или закрылся пейволлом, читать нечего».

#### Checkup — бот лезет в свои логи и орёт на тебя оттуда

Спроси в чате **«чекап», «ты в порядке», «живой собака», «пульс бота», «чекни здоровье», «как сервак»** — бот устроит самодиагностику: заберёт логи (из облачного мониторинга Better Stack, а если тот обосрался — из локального `journalctl`) и выдаст токсичный отчёт о своём здоровье реплаем на твой вопрос. Отчёт пишет нейронка в роли токсичного DevOps-инженера, унижающего разработчика за кривой код. «чекапчик» и «живой собакен» пролетают мимо — триггер знает границы слова.

Теперь в тот же чекап входит и **метрики здоровья памяти**: размер базы, свободное место на диске, счётчики записано/протухло/дублей. Да, бот сам себе сдаёт анализы — и озвучивает результаты всё с тем же унижением. В основном тебя.

### Память бота (GraphRAG) — кто кого назвал долбоёбом

Поверх трёх уровней памяти у бота есть **граф знаний** прямо в SQLite: когда старые сообщения сжимаются в факты, бот отдельным вызовом нейронки извлекает связи «кто с кем спорил», «кто кого жёстко оскорбил», «кто на чём фанатеет». Участники и темы становятся узлами, связи — рёбрами, а повторное упоминание одной и той же связи накачивает её **вес**. Да, у ваших конфликтов теперь есть вес. Буквально.

Факты из чата живут вечно; факты из поиска/фактчека/ютуба/веба — 14 дней. Перед генерацией саммари или ответа в DirectChat бот подмешивает в контекст собственные прошлые знания — как настоящий слон, который помнит, что ты наговорил неделю назад. Аварийный выключатель — `GRAPH_RAG_ENABLED=False`, и бот ведёт себя как до появления графа.

С недавних пор память стала умнее и экономнее:

- **Дедуп при записи:** дубль факта не запишется дважды — сравнение по смыслу, а не по буквам. Свежий факт побеждает старый при конфликте.
- **Веса значимости:** у каждого факта вес — «важно» живёт дольше «мемов». Плюс квота на человека: один болтун не забьёт память целиком.
- **TTL+LRU:** факты, которые бот реально использует, живут дольше неиспользуемых. Как шкаф: нужное наверху, хлам на выброс.
- **Уборка по расписанию:** однотипные эпизоды сливаются в общие факты, дубли склеиваются, мусор выбрасывается.
- **Time-decay:** старые связи в графе слабеют, свежие выигрывают. Обиды тускнеют со временем. Немного.
- **MMR:** подбор фактов разнообразный — не три одинаковых карточки подряд, мы не на конвейере.
- **Кэш эмбеддингов + int8-сжатие векторов:** та же память, меньше денег и места.
- **Резервная копия базы раз в день** + экспорт фактов текстом, читаемым глазами (а не только роботами).

Решение «не переезжать на Mem0/Zep/Letta» зафиксировано: своя схема памяти уже взрослая, подсматриваем только приёмы.

## Как менять тексты ответов

Тексты бота живут в двух местах: **пулы фраз в коде** и **медиа в папках**.

**Фразы — в файлах хендлеров и сервисов** (каждый пул — список строк; добавил строку — расширил пул):

| Что меняем | Где живёт |
|---|---|
| Оскорбления Костику | `handlers/kostik.py` (список `KOSTIK_REPLIES`) |
| Реплики Алану про SSD и витамины | `handlers/alan.py` (список `ALAN_REPLIES`, 52 фразы) |
| Ответы Славе («ДАЛБАЕБ», военные фразы, «пошёл нахуй») | `handlers/slavik.py` |
| «АДМИН» / «ВАСЯ» | `handlers/vasya.py` |
| Фразы-отборки (троттлинг саммари) | `services/summary_throttling.py` |
| Пулы умных сервисов («в этом высере нет субтитров…», «интернет сдох, ищи сам», «мозги временно ушли на профилактику…») | `services/smartmodule_phrases.py` |
| Утренние подписи | `services/goodmorning_captions.py` |
| Danger-слова и фразы | `filters/word_lists.py` (плюс свои — через `DANGER_WORDS` в `.env`) |

**Медиа — просто кидаешь файлы в папки.** Бот сам разберётся с типом: фото (jpg/png/webp/bmp), видео (mp4/mov/webm), GIF (в имени файла есть слово «gif»), аудио (mp3), войс (ogg), всё остальное уйдёт как документ. Битый или недоступный файл бот пропустит с ворчанием в лог, а не упадёт.

| Папка | Когда отдаёт содержимое |
|---|---|
| `media/dead_page/` | Fallback dead page (jpg + txt) |
| `media/leha_greeting/` | Приветствие Алана |
| `media/slavik/slavic_chlen.mp4` | Гифка каждые N сообщений Славы |
| `media/slavik/slavik_random/` | Рандом-медиа Славе |
| `media/common/otboy/` | Слово «отбой» |
| `media/common/danger/` | Danger-слова и фразы |
| `media/common/selfdev/` | Слова про саморазвитие |
| `media/common/work/` | Слова про усталость |
| `media/common/goodmorning/` | Утренняя рассылка |
| `media/olya/cringe/` | SaveAsBot-видео Оли |

**Справку `/info`** правит только админ — командой `/edit_info` (превью в личке, файл `info_text.md` руками не трогаем: бот умеет пережить ручную правку, но лучше не рисковать).

## Известные нюансы

- **Приватность бота должна быть выключена.** Обязательно: BotFather → `/setprivacy` → **Disable**. Иначе бот в группе видит только команды и упоминания: не услышит ни «отбой», ни Славу, ни саммари-материал. Это настройка Telegram, а не баг.
- Бот должен быть **админом** приватного канала из `DEAD_PAGE_RELAY_CHANNEL_ID` — иначе dead page нечего пересылать.
- `DEAD_PAGE_COOLDOWN=0` → спам на каждый репост. Весело, но чревато баном.
- Приветствие Алана (F7) срабатывает при **смене статуса**. Если Алан уже в чате на момент старта бота — проверяй через `/alangreet`.
- Таймер молчания Алана живёт в БД и переживает рестарт: перезапустил бота — бот не «забыл» Алана.
- Слава иногда обижается, но всегда возвращается. Это не баг, это фича личности.
- Костик не понимает, за что. И не поймёт.
- Без интернета уровень токсичности падает до нуля. Техническое ограничение вселенной.
- Геопозиции, контакты и кубики (dice) в память не сохраняются: саммарить кубики нечего. Медиа без подписи попадают в контекст как `[фото]`.
- Если векторный поиск (sqlite-vec) на сервере не завёлся — бот молча переходит на текстовый поиск. В логах WARNING, в чате никто ничего не заметит.
- Удаление dead page работает через пассивную телепатию: бот узнаёт, что Слава снёс репост, только когда кто-то ответит или отцитирует удалённое сообщение. Удалил молча и без реплаев — бот не заметил. Такая вот слежка.
- `/summary` не удаляется из чата (в отличие от админ-команд): команда — тоже сообщение, а память собирает всё. Свидетелей трогать нельзя.
- `setMyCommands` при старте перезаписывает меню бота: в нём живут `/summary` и `/info`. Если в BotFather было своё меню — оно сменится на это.
