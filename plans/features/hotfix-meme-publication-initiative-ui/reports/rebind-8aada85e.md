## 2. Границы привязки — что доказательством НЕ является

1. **Тождества содержимого с одобренным P0-кандидатом больше нет.** `git diff --stat ab662a75 8aada85e --
   services/meme_initiative.py` → `35 insertions, 4 deletions` (речевая проекция EVOL v5, под своим
   рубильником). Поэтому строки P0 нельзя «перепривязать» ссылкой на прежнее тождество деревьев;
   мостом служит повторный прогон принятого набора (п.1), а не утверждение о байтовом равенстве.
2. **Смоук-загрузка `/web/` не наблюдает страницу «Инициатива»** — без Telegram-контекста приложение
   показывает гейт. Ни одна структура вкладок, карточек, фильтров и диагностики в DOM не наблюдалась.
3. **Код P1-перекомпоновки в отдаваемом ассете есть, но он не отревьюен.** В `web/app.js` на `8aada85e`
   присутствуют ключи вкладок `overview/text/memes/publications/diagnostics` и строки
   «Текстовая инициатива», «Публикации», «Диагностика», «Координация отправки», «Последняя попытка».
   При этом единственный вердикт по P1 (`plans/features/p0-meme-publication-hotfix/ui-review.md`) —
   **Needs Fixes по кандидату `7c267442`, который НЕ является предком `8aada85e`**: на релизную линию
   попал другой вариант (`1c7f030f`, ребёнок `ab662a75`, влит в 2.58.153), ревью по нему не проводилось.
   Присутствие кода не заменяет приёмку: строки `HMF-UI-01..10` остаются `PENDING`.
4. **Четыре предсуществующих красных пина** (PVR-04 текстовые пины, хвост схемы 42, `this.api(` счётчик,

  не наблюдалось; проверяется при следующем реальном мем-цикле, не рукой владельца.
