## Эндпоинты

Все под TMA-auth. Нет initData → 401. Нет права → 403. Тела промптов не пишутся в логи.

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/prompts/catalog` | Каталог всех зарегистрированных промптов по family, без текстов. Только глобальный админ. |
| GET | `/api/prompts/{key}/versions` | Активная ревизия, заводская метка, совпадение, хронология, события. `X-Chat-Id` → chat-scope. |
| GET | `/api/prompts/revisions/{id}/source` | Полный текст сохранённой ревизии. Chat-ревизия чужого чата не отдаётся. |
| GET | `/api/prompts/revisions/diff?a=&b=` | Unified diff двух ревизий (сервисный difflib). |
| POST | `/api/prompts/{key}/activate` | Включить сохранённую совместимую ревизию. Отказ гейта — 200 `applied=false` + `reason_text`, указатель не меняется. |

Глобальный просмотр — глобальный админ или право редактировать этот ключ. Chat-scope — грант на этот чат (или глобальный админ / владелец своих ЛС). Чужой чат не читается и не активируется. Скрытый ключ каталога — только глобальный админ, ручное включение закрыто.

Существующий `POST /api/config` после успешной записи промпт-ключа журналирует новый immutable-снимок (`record_manual_activation`). Если журнала нет (тестовый пул не asyncpg), ответ `/api/config` не меняется. Поле `prompt_snapshots` появляется только когда снимок реально записан.

## Честные пробелы

1. Отдельного времени активации в принятом payload нет: `ActivationRow` не несёт `created_at`, `list_versions` его не отдаёт. UI показывает время записи версии и прямо говорит, что таймер включения не выдумывается. Событие включения (откат / вперёд / поставка) показывается без фальшивых часов.
2. In-memory журнал фильтрует `list_revisions` по `scope=global` по умолчанию, а PG-список — только по `chat_id`. Поэтому chat-строки на продовом PG видны в списке, а на Memory-двойнике — нет. Изоляция чужого чата проверяется на `/source` и `/activate` и от журнала не зависит.
3. Кодовый блок без `pg_key` виден в каталоге и в истории, но включение — 422: переключаемого значения в базе нет. Просмотр не обещает активацию.
4. Живой снимок экрана 390px в этом лейне не снимался. Раскладка закреплена CSS и структурным тестом, не браузерным прогоном.
