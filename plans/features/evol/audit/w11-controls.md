## 3. EVOL-043 — единый контракт контрола

### 3.1. Токены (единственный источник)

В том же `:root`, что и палитра §8 (второй палитры нет), добавлены:
`--ctl-h-sm/-h/-h-lg/-h-touch`, `--ctl-radius/-radius-sm/-radius-pill`,
`--ctl-hairline`, `--ctl-pad-x/-pad-y/-gap`, `--ctl-font/-font-sm/-font-mono`,
`--ctl-line`, `--ctl-accent/-accent-ink`, `--ctl-surface/-surface-hover`,
`--ctl-disabled-opacity`, `--ctl-field-bg`, `--motion-fast/-base/-slow/-ease/-pulse`,
`--ctl-progress-h/-radius/-track/-fill`, `--kb-inset`, `--ctl-safe-bottom`.

Размеры контролов не дублируются числами: `--ctl-h: var(--control-h)` и
`--ctl-h-touch: var(--control-h-touch)` (значения W9 не переопределены).

### 3.2. Одна роль — один компонент

| роль | компонент | применено |
|---|---|---|
| primary | `.btn-accent` (единственный градиент §8) + `.ctl-btn.ctl-btn--primary` (контракт: размер, типографика, radius, фокус, состояния) | `sticky-save`, модули, настройки |
| secondary / ghost | `.btn-ghost` + `.ctl-btn--secondary/--ghost` | шапка, списки, фильтры |
| destructive | `.btn-danger` + `.ctl-btn--danger` + обязательный `.ctl-danger-note` словами | опасные действия |
| toggle | `.ctl-toggle__track/__thumb` (внутри `.module-toggle`) | **все 15 тумблеров** (модули, ИИ, память, доступы, PERMsoc) |
| checkbox/multi-select | `.ctl-check` (hit ≥44, подпись связана, отдельный `.ctl-check__hint`) | новые формы/списки |
| radio/segmented | `.ctl-seg__btn[aria-checked]` | переключатель переноса строк в редакторе промпта |
| dropdown/combobox | `.ctl-pop[data-placement]` + `.ctl-pop__search` | панель области (класс состояния), новые списки |
| text/textarea/editor | `.ctl-textarea` (модификатор `.field`) + `.ctl-mono` + `.ctl-editor-area` | редактор промпта, конфиг-поля |
| slider/number | `--ctl-h`/`.ctl-unit`/`.ctl-error` | числовые поля конфигурации |
| menu/tabs/dialogs | `.ctl-menu__item`, `.ctl-sheet`, `.ctl-seg` | панели/листы |

Состояния кнопки/тумблера описаны явно: `data-state="pending"` — курсор
`progress`, но **включение не рисуется** (ожидание ≠ успех); `error` возвращает
статическую подпись; `[aria-disabled]`/`:disabled` — прозрачность 0.45 +
`not-allowed` + `.ctl-disabled-reason` словами (не «просто серый»).

### 3.3. Доступность

Один общий список `:focus-visible`/`:focus-within` покрывает legacy-кнопки,
`.field`, новые `.ctl-*` и `.module-toggle` — вместо 28 разрозненных правил
(они сохранены, но больше не единственный источник).

Стыки карточек: контракт `.ctl-stack` убирает копию кромки на стыке
(`border-top-color: transparent` у последующих), **без** маскирующих
`::before/::after` поверх шва. Замер живой страницы: хаб `/` 6 поверхностей,
каталог модулей 15 поверхностей — двойных контуров **0** (и до, и после).

**Визуальный обход соседнего слоя (найдено живым осмотром 390 px):** в панели
области подпись «Глобальные настройки» налезала на бейдж `GLOBAL` — текстовый
столбец не ужимался (подпись рисовалась ПОД бейджем). Исправлено на источнике:
столбец и его строки получили `min-width: 0` + truncate (W11-11). Замер после:
`sub.right = 189 < badge.left = 197`, перекрытия нет.

## 4. EVOL-044 — клавиатура

### 4.1. Один источник видимой области

`_ctlViewportMetrics()` (модульная функция, `web/app.js`): `visualViewport` →
TMA `viewportHeight` → layout viewport. Перекрытие клавиатуры считается как
`innerHeight − (vv.height + vv.offsetTop)`, поэтому Android (layout и visual
viewport сжимаются вместе → 0) и iOS (страница накрыта → > 0) различаются без
хардкодов и без списков устройств.

`_syncKeyboardOffset()` только применяет эти метрики (`--kb-offset`,
`--vv-h` **лишь при открытой клавиатуре**, классы `html.kb-open`/`kb-tight`) и
выводит поле из-под клавиатуры. Чтение visualViewport живёт в одном месте — в
миграционном коде второй реализации нет.

### 4.2. Поле в фокусе

`_ctlRevealFocusedField()` прокручивает **ближайший реально скроллящийся
контейнер** ровно на величину перекрытия. Сам control не переставляется:
каретка, selection, IME/черновик остаются (в живом прогоне проверено значение
и `selectionStart/End` до/после открытия клавиатуры).

`_preserveEditViewport`/`_captureEditViewport` (CFG-04A.1) не изменены —
поворот/переключение shell по-прежнему сохраняет прокрутку и каретку.

### 4.3. Редактор длинного промпта

Найденный дефект: при открытой клавиатуре поле схлопывалось до **44 px**
(формула вычитала `--kb-inset` из `--vv-h`, а `--vv-h` уже равен видимой
высоте). Исправлено на источнике: `max-height: min(60dvh, var(--vv-h) − 120px)`
+ `min-height: 96px`; живой замер при видимой области 504 → `max-height`
**384 px** (было 44 px).

Добавлена опция переноса строк (`Перенос / Без переноса`, `data-nowrap`):
по умолчанию перенос включён (поведение не меняется молча); «без переноса» даёт
`white-space: pre` и горизонтальный скролл **внутри** поля — страница не
растягивается. Редактор остаётся внутристраничным: app-fullscreen не
вызывается (`document.fullscreenElement === null`, в разметке нет
`requestFullscreen`).

### 4.4. Оверлей/меню

`_ctlPlacePopover()` (чистая функция) → flip вверх, когда снизу не помещается,
и лист (`sheet`), когда не помещается ни сверху, ни снизу. `positionScopePanel`
применяет результат к реальной панели области (`data-placement`, ограничение
`max-height`), горизонтальный клампинг L-4 сохранён. Живой прогон 390×844 с
клавиатурой: панель `bottom=248` при видимой области 504, последний пункт
достижим, Esc закрывает и возвращает фокус (штатный `closeScope`).

Действия сохранения — существующий `<sticky-save>` (он уже поднимается над
клавиатурой через `--kb-offset`); новый компонент панели не заводился. Добавлено
только правило «не липнуть, когда над клавиатурой места нет»
(`html.kb-tight .sticky-save { position: static }`), чтобы кнопка не оказалась
вечно скрытой.

## 5. EVOL-045 — достоверный прогресс и движение

* `_ctlProgressModel(done, total, opts)` — единственный источник процента:
  пара `done/total`, единицы, период, `aria-label`. Модели-обёртки для
  реальных витрин: `ctlCpuProg`, `ctlMemProg`, `ctlDiskProg`,
  `ctlContextProg`, `ctlCallsProg`, `ctlTokensProg`, `ctlDreamProg` — все 11
  полос «Статуса», «Аналитики» и «Памяти» читают один контракт (старый
  `budgetRatio` оставлен для совместимости JS-API, но полосы больше не
  рисуют процент напрямую);
* нет данных / устарело → `unknown`/`stale`: штрихованная дорожка, нулевая
  заливка, текстовое «нет данных» (никаких «успешных 0 %»/100 %);
* `done>total` → `anomaly: 'done>total'` (полоса клампится к 100 %, подпись
  говорит «больше лимита: X > Y»), отрицательные → `error`;
* determinate-заливка без бесконечной анимации: только `transition: width`,
  ширина не «проигрывается с нуля» (нет `animation` у `.ctl-progress__fill`);
* indeterminate — только по явному сигналу «работает/проверяется», спокойные
  2.4 c, состояния `waiting/checking/working/deferred/done/error` различаются;
* пульс `.ctl-dot[data-live="1"]` — только у подтверждённого heartbeat
  (2.4 c, изменение яркости, не масштаба карточки); одноразовая подсветка
  `.ctl-flash--once` — на фактически обновившемся показателе;
* предупреждения — существующий health-tint EVOL-032, красной мигающей каймы
  не добавлено;
* `prefers-reduced-motion`: пульс, бегущая полоса, вспышка и спиннер кнопки
  выключены, вместо indeterminate — статичная штриховка, текстовые статусы
  остаются (живой замер: `animationName === 'none'`, `::after display === 'none'`).

Живые значения (`/api/status` фикстура: CPU 42 %, RAM `percent=null`, Диск 100 %):

| полоса | `data-state` | `aria-valuenow` | подпись | ширина |
|---|---|---|---|---|
| CPU | `idle` | 42 | «CPU, 42 % из 100 %» | 42 % |
| RAM | `unknown` | — (нет) | «нет данных» | 0 %, штриховка |
| Диск | `done` | 100 | «Диск, 100 % из 100 %» | 100 % |

## 8. Осознанные ограничения (не «сделано», а решение)

1. **Легаси-кнопки не переклассифицированы.** 397 кнопок с `.btn-accent/.btn-ghost/.btn-danger`
   уже имеют один визуальный рецепт; их размер задаётся утилитами Tailwind
   (`text-xs/text-sm`) и плотностью конкретных панелей. Массовая замена на
   `.ctl-btn` изменила бы высоту ~397 кнопок и сломала утверждённую плотность
   `sticky-save`/каталога. Волна добавляет **контракт** (фокус, disabled,
   состояния, токены) и компонент для новой разметки; визуальный редизайн
   соседних панелей не заявляется.
2. **`more-menu-panel`/`viz-ovpop`/`cover-menu`** остаются на общем overlay-слое
   EVOL-023 (`--overlay-*`). Они уже читают одни токены; переписывать их на
   `.ctl-pop` в этой волне значило бы трогать меню и попапы без дефекта.
3. **Пульс heartbeat** живёт на существующих индикаторах; новых индикаторов
   «для красоты» не добавлялось — пульс включается только там, где статус
   приходит с сервера (`data-live="1"`).
