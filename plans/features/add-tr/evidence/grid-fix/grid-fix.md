## 2. Первопричина

`web/static/app.css` (до фикса, `4486-4497`) принудительно включал **две** колонки
по **viewport** (`@media (min-width:360px) and (max-width:599px) { … repeat(2,
minmax(0,1fr)) }`, решение P0A-UX §4-C1) без учёта фактической ширины контейнера.
На 360px карточка = 156px; после вычета padding (20), иконки (18), двух gap (16) и
badge (~70, `inline-block`, min-content) телу карточки оставалось **30–66px**.
`.speech-card-title` не имел ни `min-width`, ни `overflow-wrap`, поэтому ink
заголовка не переносился, а выходил из бокса в зону badge (≈20px у «Характер»,
до +40px у «Возможности бота»); подписи с `overflow-wrap:anywhere` рвались по
2–5 букв. Горизонтального overflow не было — потому дефект и не ловился прежним
e2e (он проверял только `scrollWidth − innerWidth`).

## 3. Что изменено (`web/static/app.css`)

1. `.speech-grid` / `.speech-grid-tight`: порог колонки — **220px минимума
   содержимого** (padding 20 + иконка 18 + 2×gap 16 + badge ≤72 + читаемое тело
   ≥84 ≈ 210, округлено вверх до существовавшего 220); число колонок решает
   **контейнер** (`repeat(auto-fill, minmax(min(220px,100%),1fr))`), а не viewport.
2. Удалён медиа-запрос «ровно 2 колонки на 360–599px» — на узком экране колонка
   одна и во всю ширину (комментарий в CSS ссылается на эту регрессию).
3. `.speech-card-title`: `min-width: 0` + `overflow-wrap: anywhere`
   (**не** `word-break: break-all`: слово рвётся только если реально не влезает).
4. `.speech-card > .badge`: `flex: none` — ужимается тело карточки, статус
   остаётся целиком читаемым.

Проверенное по заданию (первопричина, не симптом): Grid/Flex-структура карточки
(иконка `flex:none`, тело `flex:1 1 auto; min-width:0`, badge — flex-item),
контейнерные размеры (`gridW` 280…1008px замерены), min-content badge (70–72px),
`width/max-width` (`.card` без ширины, `.speech-screen { max-width:1180px }` не
срезает колонки ниже порога), вложенные grid (`.speech-screen` — grid, витрина
внутри hub-grid с `grid-column:1/-1`; утечек `min-width` нет), `position` (карточка
не позиционирована), наследование общих классов (`.card` — только стекло/тень),
safe-area/fullscreen (влияют лишь на нижний padding + отдельный полноэкранный
редактор; витрина не меняет ширину — проверено прогонами `fullscreen_*`).
`@media (max-height:480px) and (orientation:landscape)` витрину не трогает.
