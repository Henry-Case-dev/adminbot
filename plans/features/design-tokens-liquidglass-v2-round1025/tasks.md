## 3. [P0] Блок 2 — Liquid Glass: уровни A/B/C, избирательность

> Инвариант §9: **текст всегда резкий**; преломление — **не** на textarea/таблицах прав/логах/длинных формах/редакторах промптов.

- [x] **T-2538** [@Builder] — **Три уровня §9 + `@supports`-фолбэк.** **A** — настоящее оптическое преломление (SVG `feDisplacementMap`); **B** — стекло с backdrop blur + блики/кромка/тень; **C** — непрозрачный fallback (в т.ч. при `@supports not (backdrop-filter)`). Обновить токены `--glass-bg`/`--glass-bg-strong`/`--glass-blur`/`--glass-border` под новую палитру. Не полагаться только на `backdrop-filter: url(...)`.
  **Готово, когда:** уровни различимы и переключаемы без JS-ошибок; при отсутствии поддержки — читаемый уровень C (не прозрачная пустота); существующие glass-потребители (панели «Сводка»/«Модули»/«ИИ», модалки, `.sticky-save`) не теряют фон.
- [x] **T-2539** [@Builder] — **Избирательное применение §9.** Allow-list: sidebar, header, селектор области, Hero Статуса, карточка графа, отдельные крупные виджеты. Deny-list (уровень C / без преломления): `textarea`, таблицы прав, логи, длинные формы, редакторы промптов. Класс-маркер (напр. `glass-a`/`glass-b`) вместо «всем `.card`».
  **Готово, когда:** запрещённые контейнеры **не** получают преломление/blur (отрицательный тест); allow-list совпадает с §9; текст в формах/таблицах/логах резкий.
- [x] **T-2540** [@Builder] — **Преломление — только крупные элементы (§9).** Смещение сильнее у краёв и слабее к центру (оптическая карта, **не** случайный шум); не искажать текст/кнопки; **без WebGL-рендера на каждой карточке** (никаких новых библиотек — CSP/zero-build); SVG-фильтр разместить CSP-safe (inline в разметке или data-URI), количество применений ограничено.
