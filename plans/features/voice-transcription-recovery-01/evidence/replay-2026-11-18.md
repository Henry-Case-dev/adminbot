## 5. Ограничения (честно)

* **Первый прогон прерван** `timeout 780` на третьем объекте pass 2: `_drain` ждал фоновую задачу
  по 180 с на объект. Его JSON не напечатан, сохранились строки логов (все три объекта pass 1 —
  `ready rev 1`; pass 2 для объектов 1–2 — `rev 1` + `memorize skipped`). Полный JSON даёт pass 3.
  В раннере после этого `_drain` ограничен 45 с и не считается ошибкой.
* **Память**: факты `graph_facts` создаются LLM-пересказом и не содержат текст дословно, поэтому
  прямая атрибуция «этот факт — из этого replay» невозможна; в канале шёл и живой голосовой трафик
  (в окне прогона появились 3 факта в личном чате, 2 в канале, origin `voice_transcript`).
  Доказан **механизм** идемпотентности (skip на повторах), а не количество записей первого прохода.
* **video_note**: транскрипт 10 символов — реальный короткий текст (ASR `ok`, детерминирован),
  не заглушка, но выразительность нулевая; это свойство исходного аудио, не дефект транспорта.
* **Cloud fallback** в этом окне не срабатывал (локальный путь здоров) — его живой путь проверен
  только unit-тестами (`local 400 → cloud 200` и т.п.).
* **`test -w`** под uid 101 возвращает `no` при работающей записи (ACL + `access(2)`); для
  деплой-проверки нужен фактический `touch`, иначе проверка ложно-отрицательная.
* **Размер 1222542** локально на 2 123 B меньше облачного значения из диагноза (см. §2).

## 7. Воспроизведение

```bash
# в одноразовом checkout фикса (не в /var/www/admin_bot):
git archive --format=tar HEAD -- config services handlers SmartModule filters tools web docs scripts \
  docker bot.py | tar -x -C "$DIR"
git apply -p1 fix.patch           # diff базового 642fa3cd → tip по 4 файлам
ln -s /var/www/admin_bot/.env "$DIR/.env"
export TELEGRAM_API_FILES_DIR=/var/www/admin_bot/docker/telegram-bot-api
export DB_PATH=/var/www/admin_bot/local_database.db TMPDIR="$DIR/tmp"
cd "$DIR" && /var/www/admin_bot/venv/bin/python replay_runner.py   # рядом с этим файлом
```

Раннер — `replay_runner.py` (в этом же каталоге): read-only снимки, journal→getFile-идентификация,
два прохода replay, Writer-probe, запрет отправок, R17-безопасный JSON. Полные `file_id`/токен/DSN
не печатаются.
