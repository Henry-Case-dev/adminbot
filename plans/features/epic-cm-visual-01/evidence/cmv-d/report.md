# CMV-D — fullscreen, инспектор, мобильный, честные состояния

Ветка: `cmv/d-fullscreen`, база `dfba4080` (`evol/impl`, A+B+C слиты).
Срез карты: `CMV-D-FULLSCREEN-INSPECTOR` (`plans/features/epic-cm-visual-01/requirements-map.json`),
включая `CMV-ERR-01..08` и `CMV-INV-09` (честные состояния), которых не закрыли A и B.
Источник: `plans/current_task.md` §2–§3, §8–§9, §11, §12.3, §13;
контракт `plans/features/evol/arch/cm-visual-01-contract.md` §5–§6, §9.

## 1. Полноэкранный режим — интерфейс исследования (§3.1–§3.2)

- Одна логическая сцена: `#cog-inspector-slot` живёт внутри `status-graph-full`,
  встроенная карта при `graphFullVisible` не рендерится (`v-if`); сеть vis одна
  (`web/index.html:14751`; стенд: `.vis-network == 1`, `.cognition-graph == 1`).
- Панель 56–64 px строго по порядку «название → счётчики → поиск → фильтры →
  Сбросить вид → Закрыть»: `web/index.html:14635`, стили `web/static/app.css:2168`.
- Тело — CSS-grid `minmax(0,1fr) auto` (`web/static/app.css:2180`); колонка
  инспектора `clamp(300px,26vw,360px)` при выборе (`:2215`). Сцена сужается
  (стенд: `canvas.right <= slot.x`), панель не перекрывает сцену.
- Без выбора колонка места не занимает (`:2191`, на телефоне `:2204`); камера при
  открытии/закрытии инспектора не сбрасывается (стенд сверяет `pos`).
- `Esc`/Back закрывают РОВНО один уровень и возвращают фокус на «Полный экран»:
  `web/app.js:32916` (`_cogReturnFocusToFullBtn` проверяет фактический
  `document.activeElement`, ограниченный повтор), вызовы в `closeGraphFull`.
- Встроенная сцена 420 px (цель §2.1), телефон `clamp(340px,46dvh,420px)`,
  `touch-action:none`: `web/static/app.css:1584`, `1605`.
- Сцена получает явный размер при смене контейнера (`web/app.js:30778`,
  `net.setSize`): vis следит только за `window.resize`, иначе при
  embedded↔fullscreen битмап оставался старым и граф выглядел пустым.

## 2. Инспектор — в потоке, а не поверх сцены (§8.1–§8.2, CMV-VIS-07/09)

- ОДИН слой карточки переезжает в слот своего режима телепортом контракта §9.1:
  `web/index.html:14771` (`<teleport v-if="cogCard" :to="cogCardSlot">`); выбор
  слота — `web/app.js:8922`, классы места показа — `web/app.js:8928`.
  `id="cog-card"` в документе ровно один, второй логики нет.
- Встроенная карта: компактная панель ПОД сценой (`position: static`,
  `web/static/app.css:1869`), раскрывается кнопкой «Подробнее», свой scroll.
- Соседи кликабельны, у каждого «Перейти»: `web/index.html:14911`,
  `web/app.js:32232` (`cogFocusNeighbor`) плавно переводит камеру (`net.focus`,
  масштаб от `fitScale`), обновляет выбор, подсветку и карточку.
- «Открыть в Памяти» сохранено; действия данных активны только при доступности,
  иначе видна причина (`data-cog-action-reason`). Добавлено отсутствовавшее
  действие §8.1(6) «Снять выбор» — `web/index.html:14942`, `web/app.js:32367`
  (снимает выбор/подсветку/детали и закрывает карточку, камеру не трогает).
- Подпись выбранного объекта читается полностью: стенд сверяет текст заголовка
  карточки с моделью и отсутствие обрезки (`scrollWidth == clientWidth`).

## 3. Мобильный режим (§3.2, §12.3)

- Нижний лист 40dvh → 80dvh, свайп по ручке, страница не двигается:
  `web/static/app.css:1809`, `web/index.html:14785`, жесты `web/app.js:32216`.
- Лист читается: плотный стеклянный фон (`web/static/app.css:1817`), узлы не
  просвечивают сквозь текст; место сцены уменьшается на высоту листа
  (`web/static/app.css:2210`), поэтому в полосе над ним есть РЕАЛЬНЫЕ узлы —
  стенд считает их по камере vis на 390 и 360.
- Тач-цели ≥44 px: `web/static/app.css:1860–1868`; стенд измеряет фактические
  rect'ы (7–9 целей, нарушений нет) на 390 и 360.
- Пинч двумя пальцами и панорама одним: РЕАЛЬНЫЕ касания через CDP
  (`Input.dispatchTouchEvent`) — масштаб и камера меняются, горизонтального
  скролла нет.
- Клавиатура в поиске не рвёт сессию: маршрут, чат и модель те же.
- Мобильный `simple`-комок: `_cogFallbackPosition` больше не возвращает всем
  узлам «центроид + 22/+22» — узел встаёт на своё место кольца, занятые точки
  пропускаются (`web/app.js:30224`).

## 4. Счётчики и честные состояния (§9.9, §11)

- Четыре величины не смешиваются: `cogCounterParts` (`web/app.js:8770`) —
  «в базе» (только если сервер прислал итог), «из API», «в фильтре»
  (существующая строка), «на экране» (поштучно + свёрнутые в районы). Источник —
  `_cogCounts` (`web/app.js:31336`), публикация — `_cogRefreshCounts` (`:31351`),
  разметка частей — `web/index.html:13137`.
- `truncated` помечен «Показана часть графа» и объяснён по hover/фокусу:
  `web/app.js:8832`, `web/index.html:13143`, `:14684`; плашка переносится по
  словам и не выходит за вьюпорт при 320 px / 200 % (`web/static/app.css:1709`).
  Формулировка «всего N» к выдаче API не применяется.
- Пусто: `data-cog-state="empty"` + «Открыть в Памяти», без зависшей анимации.
  Один узел: карточка без ложных соседей («связей не записано»).
- Ошибка API: сообщение словами + «Повторить» (`cogLoadErrorLabel`,
  `web/app.js:8813`), исправный last-known-good не стирается, помечается
  устаревшим; успешный повтор снимает ошибку.
- Смена чата/области: модель сбрасывается сразу, ответ прошлого чата
  отбрасывается по поколению (`web/app.js:32152` + проверка в
  `loadCognitionGraph`).
- «Нет сети» больше не выдаётся за «визуализация не загрузилась», когда данных
  ещё нет: состояние рендерера честное.

## 5. Строка 4 шапки — подсказка жестов (CMV-HDR-04)

Компактная подсказка «Колесо/щипок — масштаб · Перетаскивание — перемещение ·
Нажатие — связи» показывается один раз при входе (`web/index.html:13255`,
стиль `web/static/app.css:1728`), после первого действия с картой уходит
(`_cogHintDone`, `web/app.js:32188`), а тот же текст остаётся доступной
подсказкой сцены (`title` + полный текст в `aria-label`, без лишнего визуально
скрытого узла).

## 6. Побочная находка ревью CMV-C — имя кластера

`computeClusters` называл кластер САМЫМ КОРОТКИМ заголовком парадигмы
(2 «Alpha» + 8 «Zeta» → «Парадигма: Alpha»). Теперь считается частота, при
равенстве — короткий, затем лексикографический порядок; результат детерминирован
при любом порядке узлов. Правка в одном блоке `computeClusters` (не LOD, не
labels, не aggregates) — коммит `53d25635`.
