## F1. Гистерезис плотностного обзора (§5.1, §13)

Было: `denseOut` вычислялся и не читался; выход из плотностного обзора — жёсткий
`r > denseMax = 1.05`. При 702 узлах и плотном кадре уровень 0↔1 переключался на
каждом событии колеса у границы (ревью: 12 переключений на обходе).

Стало (`web/static/cognitive-map.js`):

- `:1141-1142` — две границы плотностной полосы по r: вход в обзор
  `denseInRatio = denseMax` (1.05), выход `denseOutRatio = denseMax * (1 + delta)` (1.176);
- `:1147-1149` — плотность считается один раз (`denseMeasured`, `denseIn`, `denseOut`),
  теперь без условия `value <= denseMax`, поэтому `denseOut` реально используется;
- `:1161-1167` — уровень 0 держится, пока `r <= denseOutRatio`; за порогом `T1·(1+δ)`
  обзор держится плотностью (`denseOut` — свой 20 % гистерезис: 60 вход / 48 выход);
- `:1173` — возврат в плотностной обзор только внутри полосы входа (`r <= 1.05`),
  между 1.05 и 1.176 уровень остаётся рабочим («мёртвая зона» 12 % по r).

## F2. Подпись района — доминирующая парадигма (§5.2, §13)

Было: `paradigmTitle` — лексикографически первая парадигма тайла; при
`dominantKind === 'paradigm'` и доле типа ≥ 0.6 подпись называла район
произвольным заголовком.

Стало (`web/static/cognitive-map.js`):

- `:874-901` — считается частота каждого КОНКРЕТНОГО заголовка парадигмы;
  тема района — самый частый заголовок (при равенстве — меньший по алфавиту,
  детерминированно), сохраняются `paradigmTitle` и `paradigmShare`;
- `:928-930` — название попадает в подпись только когда доминирует и тип (≥ 0.6),
  и сам заголовок (≥ 0.6); иначе — «Группа · N» с числом всех участников района;
- `:955-956` — `paradigmTitle`/`paradigmShare` отдаются в объекте района (наблюдаемость).
