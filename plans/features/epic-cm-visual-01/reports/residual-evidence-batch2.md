# Residual evidence — batch 2 (EPIC-CM-VISUAL-01)

Ветка: `cmv/residual-evidence-2` (от `df00f178` = `evol/impl`). Продуктовых правок нет.
Проба: `plans/features/epic-cm-visual-01/evidence/residual2/probe.py` + адресная
допроба `probe_fix.py` (локальный стенд `ui_round1025_matrix._start_server` +
`ui_evol_w15_composition_e2e`, реальные `web/index.html` + `app.js` + `app.css`
этой ветки; порты случайные, API-стабы epic-фикстур). Факты и sha256 — в
`evidence/residual2/manifest.json`.

Пакет: первые 12 строк задания, проверяемые UI/пробой. Остальные 12
(ANI-01, PHY-03/04, AI-01..04, INV-10, PERF-05/06, VIS-13, GATE-17) — пакет 3.

Метод каждой строки: реальные кадры desktop 1440 / mobile 390, фактические
rect'ы/стили/счётчики из DOM и движка (DataSet, камера vis, аллокатор подписей,
fx-счётчики), отрицательный контроль, консоль без ошибок, ровно один
vis-network инстанс на пробу (`visNetworks: 1` во всех пробах). Фикстуры:
BASE = `cog_payload()`, RICH2 = BASE + длинный текст/без заголовка/длинное
название + три одноимённых узла, SINGLE = один узел без рёбер, FIX-702 и
WEIRD-702 = FIX-702 + странные узлы (id 9201+ вне диапазона фикстуры — первый
запуск с id 201/202 дал коллизию `fact:202` с узлом фикстуры, исправлено в
`probe_fix.py`). Для NAV-01 в стаб `/api/config` injected реальный параметр
`limits.summary_aliases` (тот же путь, что в проде).
