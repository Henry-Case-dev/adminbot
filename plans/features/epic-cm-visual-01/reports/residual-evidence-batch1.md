# Residual evidence — batch 1 (EPIC-CM-VISUAL-01)

Ветка: `cmv/residual-evidence` (от `df00f178` = `evol/impl`). Продуктовых правок нет.
Проба: `plans/features/epic-cm-visual-01/evidence/residual/probe.py` (локальный стенд
`ui_round1025_matrix._start_server` + `ui_evol_w15_composition_e2e`, реальные
`web/index.html` + `app.js` этой ветки; порты случайные, API-стабы epic-фикстур;
данные `BASE = cog_payload()`, `RICH` = BASE + 3 узла фикстуры (nameless creature с
длинным текстом, узел без заголовка/текста, узел с длинным названием), `FIX-702`
= `tests/fixtures/cmv/cog_map_702.json`). Факты и sha256 артефактов — в
`evidence/residual/manifest.json`.

Метод каждой строки: реальные кадры desktop 1440 / mobile 390 (или оговорённые
в требовании 768/702-fit), фактические rect'ы/стили/счётчики из DOM,
отрицательный контроль (снимок состояния, где элемента нет или он не виден),
консоль без ошибок, ровно один vis-network инстанс на пробу
(`manifest.json → counters: visNetworks: 1` во всех пробах).
