# Residual evidence — batch 3, финальный (EPIC-CM-VISUAL-01)

Ветка `cmv/residual-evidence-3` (от `df00f178`). Продуктовых правок нет.
Проба: `plans/features/epic-cm-visual-01/evidence/residual3/probe.py`
(стенд `ui_round1025_matrix._start_server` + `ui_evol_w15_composition_e2e`,
реальные `web/index.html` + `app.js` + `app.css` ветки; FIX-702 = 702 узла /
2400 рёбер, payload детерминированный), допроба `addendum.py`
(wheel-трасса, pinch-якорь, gesture-поллинг, фокус-длительность) и
`probe_click_flash.py` (whole-canvas diff импульса клика). Пересъёмка
VIS-13: `vis13_reshoot.py` (три ревизии на локальных стендах). PERF-06:
существующий инструмент `tools/ui_cmv_e_leaks.py` в ИСПРАВЛЕННОЙ версии
ветки `cmv/perf` (57912225: WeakRef, isConnected), `--repo` на эту ветку.

Факты и sha256 каждого артефакта — `evidence/residual3/manifest.json`
(строки CMV-VIS-13 и CMV-PERF-06 добавлены в манифест отдельным проходом).

Метод: реальные кадры desktop 1440 / mobile 390 (VIS-13 — 1536×960 DPR1,
те же условия, что у принятых пар fit/mobile), числа из DOM/движка
(сцена, fx-канвас, камера vis, план пульса), реальные события мыши/колеса/
клавиатуры Playwright, консоль без ошибок, ровно один vis-network инстанс
на пробу. Отдельно зафиксированные ограничения стенда: момент создания
vis-сети не перехватывается (vis в бандле, `window.vis` отсутствует);
rAF-сэмплер камеры ненадёжен во время анимаций — таймлайны камеры сняты
поллингом из Python (шаг ~80–100 мс).

  fx-канвас, band [1.28r, 2.55r]): у 4 из 5 узлов измеренный период
  совпал с планом — 3349.7 против 3488 (Δ138), 3999.9 против 3703 (Δ297),
  3199.5 против 3259 (Δ60), 3049.8 против 3004 (Δ46) — все в 3000–5000;

  среднего кольца, <0.05 %) — «изменение яркости небольшое»; ядро узла
  статично, геометрия не дышит. Один узел (fact:327) не разложился —
  соседний дрейф сцены (честно зафиксировано). Mobile 390: 3 узла,
  амплитуда 5.5–7.1 luma, периоды в диапазоне, значимость ниже (шум
  плотной сцены выше). Итог: пульсация есть, период 3–5 s, фазы
