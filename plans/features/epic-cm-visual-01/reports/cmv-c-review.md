## Блокирующие находки

### F1. Мигание LOD на плотностной границе (§5.1, §13). Builder
`cognitive-map.js:1113-1143`: переменная `denseOut` (строка 1122) вычисляется и нигде не читается, то есть
заявленный гистерезис выхода из плотностного обзора не реализован. Уровень 0, включённый по плотности, выходит
только по жёсткому `r > denseMaxRatio = 1.05` (`cog-visual.js:235`), без полосы delta. На наборе 702/2400:
r=1.045 даёт уровень 0, r=1.060 даёт уровень 1, и так на каждом событии колеса или щипка. Каждое переключение
это батч hidden на 696 строк (`app.js:30996`) плюс пересборка плана подписей, то есть видимая дрожь обзора ровно
там, где пользователь начинает приближаться. Тест `evol_cognitive_map_test.js:1152` проверяет одну точку r=1.0;
обход 220 шагов вверх/вниз шёл без плотного кадра и потому дыру не ловит. Комментарий кода (1089-1091) обещает
выход по плотности ниже denseExitRatio, в коде этого нет.
**Правка:** читать `denseOut` в ветке p===1 и/или навесить полуширину delta на denseMaxRatio (вход 1.05*(1+delta),
возврат 1.05*(1-delta)); лишнюю переменную не оставлять мёртвой.
**Перепроверка:** обход r 1.00 в 1.15 и обратно шагом 0.005 при 702 узлах и плотности не ниже 60: ноль переключений
внутри полосы; плюс тест на дрожание плюс-минус 0.01 около 1.05.

### F2. Подпись района может назвать недоминирующую парадигму (§5.2). Builder
`cognitive-map.js:885-888`: `paradigmTitle` выбирается как лексикографически ПЕРВАЯ парадигма тайла, а не самая
частая. При `dominantKind === "paradigm"` и доле типа не ниже 0.6 (строки 914-916) подпись становится
"Парадигмы: <этот заголовок> · <все участники района>". Если 60 процентов элементов это парадигмы разных
названий, на экран попадает произвольное имя как тема группы, а число относится ко всем элементам. Спека §5.2:
показывать название группы только там, где оно реально известно, не выдумывать тему; §13 отдельно запрещает
выдуманные сообщества. В сдаточных кадрах путь не сработал (все подписи нейтральные "Группа · N"),
дефект латентный, но класс тот же.
**Правка:** считать долю конкретного заголовка парадигмы (не типа) и подписывать им район только при его
доминировании, иначе нейтральное "Группа · N"; число в подписи либо все участники, либо явно "N из M".
**Перепроверка:** тест с районом из трёх и более парадигм без доминанты: подпись нейтральная.
