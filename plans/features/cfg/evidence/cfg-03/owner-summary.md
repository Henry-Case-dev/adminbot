# CFG-03 — сводка владельцу (R2)

**Что сделано (простыми словами).** Проверены **все 579 настроек** мини-аппа:
у каждой найдено, где она живёт (вкладка/экран), где сохраняется и **кто её
реально читает в работе бота**. Это не «поля нарисованы» и не «в базе
лежит» — искали фактических потребителей в коде.

**Числа (кандидат):**

| Показатель | Сколько |
|---|---|
| Всего настроек | **579** |
| Настройки с найденным потребителем | **565** (552 обычных + 13 через динамические шаблоны) |
| Без потребителя — и это честно показано в интерфейсе | **7** |
| Без потребителя — служебные env-настройки (вне UI) | **7** (6 из них читает docker-контур, 1 — мёртвая) |
| Настройки без места в интерфейсе (UI_missing) | **0** |
| Найдено и исправлено несоответствий «показывается, но не действует» | **5** |
| Отложено (нужна правка чужого теста — см. failures.md) | **2** (типы) |
| Параметров с ссылками на автотесты | **456** |

**Что исправлено:** 5 настроек, которые выглядели рабочими, но в реальности
ничего не меняли, теперь честно об этом пишут прямо в карточке:
«Не влияет: значение сохраняется в конфиге, но рантайм его не читает».
Это: доля бюджета Response, потолок словаря замков, окно «N лет назад»
dig_into_lore, коды стран прокси Webshare и повторы при блокировке.

**Что проверено на живом интерфейсе:** описания видны в карточках (вкладка
«Память», окна модулей «Ответы в чате» и «Выжимка видео»), группа «Медиа-шара»
рендерится в окне «Выжимки видео», на мобильном 390px всё видно без
горизонтальной прокрутки, ошибок в консоли нет.

**Что не проверено / осталось:**
* Проверки на живом сервере (изменение без перезапуска, реальные отказы) —
  этап релиза; здесь только локальные/стендовые проверки.
* Две настройки с несоответствием типа (пауза частотного лимита генераций;
  повторы прокси YouTube) — исправление требует правки тестов других задач,
  поэтому задокументировано и отложено.
* `media_base` — служебная настройка окружения, которую никто не читает
  (в интерфейсе её нет; решение о чистке `.env` — за владельцем, не блокирует).
