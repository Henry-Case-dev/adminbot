# CFG-03 — список проверок, требующих владельческого/живого события (R4)

Правило PET: обязательные device-чек-листы владельца **не создаются**
(AGENTS.md §PET, решение 18.10.2026); агентские проверки — агентам.
Ниже — только то, что нельзя безопасно/полно проверить без живого процесса
или решения владельца, с точным сценарием для агентской проверки на
релизном этапе (Ф6).

## 1. Живые hot-проверки (CFG-03.4) — агентские, этап релиза (preprod)

| Параметр (класс) | Сценарий | Кто |
|---|---|---|
| `limits.image_daily_limit` (int-лимит) | на preprod: глобально 1 → генерация изображения разрешена ровно 1 раз, вторая — отказ с фактическим остатком; вернуть 60 | агент (безопасный малый объём) |
| `flags.vision_enabled` (bool-флаг) | выключить в одном чате → анализ изображений в нём не запускается; включить → работает | агент |
| `limits.chat_burst_limit`/`chat_cooldown_seconds` | переиспользован P0/CFG-01 live-эвиденс (2.58.88) — повтор не требуется | — (reuse) |
| `limits.image_freq_limit_*` | переиспользован CFG-02B live (выборочно) | — (reuse) |

## 2. Решение владельца (продуктовое) — не блокирует

| Вопрос | Контекст | Варианты |
|---|---|---|
| Выводить ли из интерфейса 5 честно помеченных «не влияющих» настроек | CFG-03.6: «выводиться из интерфейса **после отдельного согласования**» | (а) оставить с честным описанием (текущее); (б) скрыть из UI (каталожная Δ + re-pin); (в) вернуть функциональность (отдельная задача) |
| Чистить ли `media_base` из `.env` | env-only, никем не читается (api-only, вне UI) | (а) оставить как есть; (б) удалить строку из `.env` при следующем деплое |

Оба вопроса **не блокируют** релиз и не требуют немедленного ответа
(стоящее PET-правило: без новых обязательных согласований).

## 3. Нельзя проверить статически (честно)

* Реальное поведение 13 RELATIONS-лимитов подтверждено динамическим
  шаблоном чтения + тестами `tests/test_relations_service.py` (зелёные);
  живая выборка стадий отношений на preprod — по желанию, не требуется
  (детерминированный юнит-контур достаточен).
* «Перекрытия» (env-потолки, cached constructor state): env-потолки вне
  каталога собраны (13 имён, `audit-summary.json` → `env_only_ceilings`);
  диагностируемость — через существующий админский дамп
  (`services/debug_config.py`, `GET /api/debug/config`, R17-маска) — не
  требует новых ручек. Живое сравнение effective vs declared на preprod —
  этап Ф6.
