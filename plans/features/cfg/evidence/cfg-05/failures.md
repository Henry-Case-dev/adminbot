# Failures — новых воспроизводимых регрессий нет

## Результат

За время CFG-05-Verify **не обнаружено ни одной новой конкретной воспроизводимой регрессии** стекла, полигонального фона или компоновки:

- материал/линза/токены: 0 отличий base `95d11472` ↔ deployed `99f5672c` (2050 ячеек, `glass-invariant.json`);
- «Статус»: PNG 390×844 **побайтово идентичны**; карточка «Бот» 390 и 1440 — 0 отличающихся пикселей;
- 178 исторических замечаний — ровно те же на base и на deployed (`base-only=0`, `cand-only=0`);
- пины: 131 passed + 4/4 node OK.

## Что выглядело отличием и почему это не регрессия

1. **106 rect-дельт** на конфиг-экранах (`ИИ-LLM-Провайдеры`, `ИИ-Промпты`, `ИИ-Отношения`, `ИИ-Лор`, `ИИ-Умный-кэш`, `ИИ-Имена`) — высоты/смещения карточек. Это геометрия CFG-04 (тех-ключ/переключатели/подсказки), 0 отличий по `bg/bf/border/filter/tier/refract`; «Статус» без дельт.
2. **69 пикселей** на 1440-кадре «Статуса» — живая метка времени (08:48:48 vs 08:48:56), проверено кропом.
3. **`/static/app.js` → 404** — штатно: index.html грузит `/web/app.js` (хэш совпал с git).
4. **120 б / 22 б дельты** index.html и `/static/app.css` — серверная подстановка `__APP_VERSION__`→`2.58.97` (30 и 4 строки), тот же паттерн записан в release-evidence CFG-04; блок `#lg-lens` и токены при этом не меняются.

## Правило триажа CFG-05.4 (source L190)

Новая **конкретная воспроизводимая** регрессия в нужном клиенте:
1. фиксируется отдельной записью здесь: шаги, кадр/лог, причина, затронутая поверхность;
2. чинится точечно в **существующей** задаче-владельце (CFG-04 / U08 / SOUL-17 / WIN-GLASS), не в CFG-05;
3. гипотетический («может быть, на каком-то устройстве») дефект **не** держит CFG-05 открытым и не задерживает очередь.

На 20.10.2026 таких записей нет.
