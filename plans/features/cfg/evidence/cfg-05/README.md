Поэтому «сдвиг у кромки» здесь не измерялся заново — это доказано ранее в SOUL-17 (`_strong_*`, verify 77/1) и U08/WG; CFG-05 их не переигрывает.
2. **Реальные устройства/перф** (Android/Windows, reduced-motion, overdraw) — остаются `SOUL-17.4 READY_FOR_LIVE`; живые пункты WG — `PENDING_OWNER_E2E`. CFG-05 их не присваивает.
3. **Скриншот владельца от 18.10** в репозитории не хранится; платформа в источнике не названа. Ничего не домысливается, свой кадр его не подменяет (`owner-observation.md`).
4. **Живой кадр прода без Telegram-сессии не снимался:** `/web/` в обычном браузере не отдаёт авторизованный «Статус»; подделывать кадр запрещено. Вместо этого снят рендер **тех же байтов** локально (`cand97` = `99f5672c`) и сверены хэши отдаваемых файлов. Живые клиентские наблюдения — за владельцем (правило 20.10).
5. Все live-веб-наблюдения 2.58.97 (конфиг-экраны) уже есть в `plans/features/cfg/evidence/release-25897/acceptance/cfg04/` — переиспользуются, не дублируются.
