# MCA-16 `mca-16-experience-lessons` — threat & failure analysis (T-4990, Risk R3)

**Фича:** `mca-16-experience-lessons`; **Risk: R3** (подтверждение планового `mca-round1027-plan.md:208`). **Дата:** 05.10.2026, Step 2 @Architect. **Основание R3:** новая durable-схема v28 с журналами поведения + контур, влияющий на будущие ответы (контекст/приоритет), + анти-самоподтверждение и injection-поверхность обратной связи + изоляция чатов/обезличивание global + совместимость уроков при смене tool/model + видимая владельцу оценка «обучения». Отказ может привести к ложной активации урока, утечке содержимого чужого чата, самоподкреплению, устаревшему применению, неограниченному росту данных или ложному «бот улучшился». Денежный контур не затрагивается (K5 OFF не трогается); истинность/права/идентичность не рандомизируются. Митигации завязаны на spec §/задачи; проверка — focused-тесты и live T-5015.

## Сценарии отказа (поведение при сбое)

- **Ошибка записи эпизода/feedback (DB locked/сбой):** fail-open — рабочий ответ не блокируется; эпизод/сигнал пропускается с честной причиной; повторов-дублей нет (идемпотентность); bounded-буферы не растут бесконечно (THR-6/THR-11).
- **Review-job упал/прерван:** checkpoint/counters в `task_jobs` (mca-01); resume с курсора; повторный запуск не дублирует применения/utility (dedup); статусы заморожены, активные уроки продолжают работать по K4.
- **Смена tool/model/config:** затронутые уроки исключаются из отбора (`recheck_required`); повторная проверка в review-job; при провале — suspend с причиной; чат не ломается (THR-7).
- **Инъекция/мусорный feedback:** не проходит канонические правила → нет кандидата; injection не становится рекомендацией; событие честно фиксирует отказ (THR-2).
- **Миграция v28 не применилась:** fail-closed backup-guard (mca-14), сервис не активирует новые таблицы; deploy останавливается; повтор идемпотентен (no-op) (spec §12.6).
- **K1–K4 OFF / рестарт:** полный паритет 2.58.58 (K1) или документированные подмножества; таблицы v28 инертны; восстановление после OFF — включение гейта + рестарт (soft), данные не теряются.
- **Недоступность mca-07 retrieval-примитивов:** отбор деградирует до SQL-scope+compat без семантики? — нет: без semantic gate уроки **не применяются** (fail-closed, честная причина `retrieval_empty`); вопрос/источники не вытесняются (spec §6).

## Вывод

R3 подтверждён; все High-угрозы имеют проверяемые митигации в задачах T-4991–T-5016. Ложная активация исключена конструктивно (детерминированные проверки + независимость подтверждений; LLM/social не активируют в одиночку; injection не становится уроком).
