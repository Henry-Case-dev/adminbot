## Обоснование (кратко)

1. **Операция вместо диспозиции.** «Регулярно»/«изредка» модель трактует как
   позволение; «одно слово в большинстве разговорных реплик» и «1 из 4–5»
   — исполнимый якорь с сохранёнными ограничителями (не спам, не повтор,
   не только по просьбе).
2. **Честный header.** Делегирование L1 физически невыполнимо (`machine_json`,
   ноль упоминаний мата в system L1, в плане нет регистра). «Контекст
   определяет уместность и жанр» — то, что действительно происходит; просьба
   «без мата» и защита цитат/сводок остались дословно.
3. **P7 в §4.2** помечен как нереализованный в текущем runtime (контракт-цель
   F3), чтобы канон не содержал второго ложного обещания.
4. **UI-эффект-тексты §2.2 не менялись:** «изредка, но по-настоящему…
   большинство реплик — без мата» и «регулярная часть… не в каждом
   предложении» **не расходятся** с новой частотой (менее конкретны, но не
   противоречат); расширять UI не потребовалось.
5. **Прочие контролы (wit/sharpness/verbosity) не тронуты** — вне F1; их
   тексты — отдельный канон (упоминание L1 в `wit/high` — пре-существующее,
   вынесено в остаток для отдельного решения, см. ниже).
