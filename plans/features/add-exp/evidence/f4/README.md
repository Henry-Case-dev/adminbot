## 6. Инцидент лейна (честно)

Первый запуск волны дал **два** процесса: `systemd-run` стартовал, но
«Running as unit» ушёл в stderr sudo, раннер счёл запуск неуспешным и добавил
`nohup`-дубль. Следствия: по два якоря на волну, дублирующиеся ответы в чате
(владелец это заметил: «Бот че нахуй сам с собой разговаривает?»), лишние
платные вызовы. Исправлено: запуск только через `systemd-run`, проверка
`systemctl is-active`, счётчик процессов; прогон повторён начисто
(20:12–20:19). Уборка: удалены **все** тестовые сообщения обеих попыток —
23 (чистая волна) + 15 (остатки дубля) + 5 (хвост synthetic-turn цепочки) =
**43 сообщения**; легитимные ответы на реальные сообщения владельца
(`1166966`, `1166975`, `1166982`, `1166988` — у всех parent — сообщение
пользователя) **не тронуты**. Остаток тестовых: **0** (`residual-clean.json`,
`final-verify.json`). Сообщения владельца не удалялись.
