## 2. «Гайд по фичам» (INFO v8) — что дописано

- §7: гарантированный **текстовый** ответ на прямое обращение («не отделывается
  смайлом»); осознанная пауза вплоть до каменного молчания 🗿; семантический
  тон (в перепалке может уместно огрызнуться — манера, не хамство).
- §10: обложка растёт из выжимки (story-first), нет сцены → честный отказ,
  не generic-болванка. «Один honest-retry» из доп.указания в коде не найден
  как пользовательский контракт (только внутренний bounded-retry провайдера
  400-too-long) — в справку не внесён (§20/22.20: Help = подтверждённое
  behavior); честный retry-путь — уже описанный тестовый прогон стиля без
  расхода номера.
- §13: короткая контекстная реплика («а этот?», «и чё») = полноценный вопрос
  по контексту, не по длине; заказ формы (примеры: «Бот, в двух словах»,
  «Бот, распиши подробно со всеми деталями»); инструменты по смыслу задачи
  (2 ссылки ≠ приказ, 0 ссылок ≠ запрет); смешанные источники (сеть + история
  чата). Примеры в канон-формате blockquote+b/i, вёрстка-инварианты целы.
