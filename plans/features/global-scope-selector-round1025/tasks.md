## Верхнеуровневые задачи (детализация при старте)
- [ ] Селектор области — фундаментальный постоянно доступный элемент §5: тип области (Глобально/Чат/ЛС), название чата/ЛС, действие переключения; desktop — в закреплённом header, mobile — под заголовком страницы.
- [ ] Раскрытый селектор: поиск, Глобально, Чаты, Личные сообщения; полный `chat_id` — только в технических подробностях.
- [ ] Источник значения §5: если наследуется из глобального — показывать «Источник: глобальная настройка»; если переопределено — «Источник: PERMsoc».
- [ ] Действие **«Вернуть глобальное значение»** (только если сервер поддерживает возврат к наследованию) — **не путать** со сбросом к заводскому значению.
- [ ] Переключение области §5: проверка несохранённых изменений, предупреждение, отмена устаревших запросов, загрузка значений новой области, **не применять запоздавшие ответы**, не переносить черновик предыдущего чата.
- [ ] При выбранном чате явно помечать, что серверные метрики относятся ко всему серверу §14.
- [ ] Тесты §74 (глобальное наследование, локальные значения не исчезают) и §42 (stale-ответы при быстрой смене чата).
