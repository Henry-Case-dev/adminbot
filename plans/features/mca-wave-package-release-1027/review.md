## 7. Findings

### Blocking

- **[H-1] High — ошибочный волновой re-pin `saturate(103%)`, 2 новых падения полного pytest.**
  - Где: `tests/test_webapp_hotfix8_round1025.py:59`; `tests/test_webapp_hotfix9_round1025.py:131`.
  - Факт: `assert "blur(14px)" in blur and "saturate(103%)" in blur`; продукт `web/static/app.css:100` = `--shell-blur: blur(14px) saturate(105%);` (файл чист, == HEAD == прод 2.58.34/35). На якоре `8bd1389` тесты проходят (105==105), на дереве падают (2 новых failing против анкера).
  - Требование: spec §3 п.8 («любая новая failing-теста = блокер, если не атрибутирована документированно»), §4.3 («полный pytest+JS зелёный» на чистом worktree), §6.2 (re-pin — только version/count/boundary/sha256; CSS-токен — класс вне санкционированного). Известен с гейта ASAP-2.1 (запись L-R1028 / «MCA WIP-находки»: «тесты редактируются») — волна правку не внесла.
  - Impact: композиция T-4046 в текущем виде violated зелёный-критерий; в репозиторий закрепятся 2 постоянно красных теста.
  - Корректирующее действие: вернуть `saturate(105%)` в обеих строках (минимальный фикс, восстанавливает паритет с продом; правка CSS/новый код не требуется). Альтернатива «обновить app.css до 103%» — НОВЫЙ код, вне скоупа релиза, отклоняется.
  - Верификация фикса: точечный прогон обоих тестов + контроль полного прогона (ожидание: 1 failed — только известный `test_forbidden_paths_out_of_diff`); сверить, что дельта WTH после фикса пере-хэширована.
