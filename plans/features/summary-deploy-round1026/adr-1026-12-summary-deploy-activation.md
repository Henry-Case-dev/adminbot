## Контекст

§107 требует: новый пайплайн становится **основным сразу после завершения Эпика 2**; **не требуется** теневой режим, поэтапный rollout, длительное сравнение с Legacy, отдельный интерфейс выбора Legacy/Hybrid; функциональность **должна быть включена после деплоя**; алгоритмический фильтр включён по умолчанию; раздельный роутинг активен; **не оставлять фичу выключенной в ожидании ручной активации**; перед деплоем — минимальные функциональные тесты. §114 задаёт 11 минимальных сценариев и запрет публиковать тестовые результаты в основной чат. §115 — 7 пост-деплой-проверок и наблюдаемые артефакты (rich: изображение сверху + настоящий H1; plain: жирный заголовок + абзацы). §116 — критерии «ЭПИК 2 НЕ ЗАВЕРШЁН, ЕСЛИ…». §117 — 14 обязательных результатов Эпика 2.

### D1. Границы diff S10 (ответ (a) — границы)

**Решение.** Diff S10 минимален и состоит из:
- `config/settings.py` — **default `SUMMARY_HYBRID_L2_ENABLED` OFF→ON** (D2) + актуализация комментария (строки 978–983) + bump `APP_VERSION` (D7);
- `services/summary_generator.py` — **только** docstring `_hybrid_l2_enabled` (default/семантика), если требуется; логика `_run`/`_run_hybrid_l2`/резолв — **не меняется**;
- `services/summary_l2_writer.py` — docstring «default OFF» → актуализация;

**Вне diff:** §104-контур (`services/image_generation.py`, `compose_cover_image_prompt`, `_resolve_cover_style_text`, `build_cover_media`, порядок/прикрепление обложки); `services/telegram_send.py` (**reuse без изменений**); `services/summary_prompts.py`/`services/prompt_migrations.py` (каноны не меняются); `services/summary_filter.py`/`summary_context_restore.py`/`summary_l1_clusterizer.py`/`summary_fact_package.py`/`summary_article_formatter.py` (логика); `services/summary_test_run.py` (S9); `web/api/routes.py`; `web/**` (viewer/UI/карта — reuse); `db/**`; `services/param_catalog.py`; `bot.py`; порядок роутеров.

**Почему активация — одна строка default.** Иной рычаг (UI-тумблер, новый флаг, env-пин) либо нарушает §107 (ручная активация / новый интерфейс), либо требует Δ каталога ≠ 0 (санкция §85-UI — вне S10). Смена code-default — единственный способ «включить после деплоя» без ручного действия и без нового интерфейса.

### D2. Механика активации §107 (ответ (a)) — ГЛАВНОЕ

**Решение.**
1. **Активация = смена code-default, а не ручной тумблер.** `config/settings.py`: `SUMMARY_HYBRID_L2_ENABLED: ClassVar[bool] = _env_bool("SUMMARY_HYBRID_L2_ENABLED", True)` (**OFF→ON**). После деплоя (при отсутствии явного `false`) новый пайплайн — основной во всех чатах: `_run` резолвит `hybrid=True` и уходит в `_run_hybrid_l2` **без какого-либо действия оператора**.
2. **Семантика слоёв сохраняется, смысл переворачивается.** Резолв-цепочка `per-chat override → hot (flags.summary_hybrid_l2_enabled) → env/default` **не меняется** (байт-в-байт); меняется только значение по умолчанию. Отсутствие override → **ON (основной путь)**; любой явный `false` → **аварийное выключение** (kill-switch).
3. **«Ручная активация» запрещена, «аварийное выключение» разрешено.**
   - *Запрещено:* требовать ON-действие (тумблер/интерфейс) для запуска пайплайна; вводить UI/селектор Legacy↔Hybrid; оставлять фичу выключенной «до ручного включения».
   - *Разрешено:* оператор вправе явно **выключить** пайплайн при инциденте — `SUMMARY_HYBRID_L2_ENABLED=false` в `.env` + `systemctl restart admin_bot` (deploy-level, обратимо рестартом), либо запись non-catalog `flags.summary_hybrid_l2_enabled=false` в `bot_settings` (runtime-путь резолва уже читает этот ключ). Это **не** активация, а аварийный тормоз.
4. **Раздельный роутинг** — уже активен (факт 5); §115 п.3 проверяет независимый резолв L1/L2.
5. **Фильтр** — `SUMMARY_FILTER_ENABLED` default ON (факт 4); не меняется.
6. **Per-chat override сохраняется** (факт 3): для не-каталожного `flags.summary_hybrid_l2_enabled` штатного UI-пути нет; унаследованный/ручной `false` для чата остаётся аварийным OFF этого чата — §115 проверяет целевой чат. Новых ключей каталога не вводится.
7. **«Не оставить выключенной» операционно:** деплой-процедура (D7) проверяет, что `.env` не пинит `SUMMARY_HYBRID_L2_ENABLED=false` (если пинит — снять/исправить), и §115 п.1 подтверждает effective ON. При расхождении деплой блокируется.

**Альтернативы.**
- **(b) env-пин `SUMMARY_HYBRID_L2_ENABLED=true` на сервере, default в коде OFF.** Отклонено: master остаётся OFF → свежий деплой без пина снова выключен (§116 «пайплайн остался выключенным»); активация становится ручным шагом (§107).
- **(c) Удалить kill-switch полностью.** Отклонено: лишает аварийного тормоза и ухудшает обратимость (High-риск «невозвратный откат»).
- **(d) Добавить каталожный ключ/UI-тумблер Hybrid.** Отклонено в S10: Δ каталога ≠ 0 → требует отдельной санкции §85-UI (вне S10).

### D3. §114-предполётный harness (ответ (c))

**Решение.** §114-проверка выполняется **локально, до деплоя**, и **не публикует** ничего в основной чат.
- **База:** reuse S9 dry-run `services/summary_test_run.py::run_summary_test` (0 публикаций/0 памяти/0 `generate_image`) + `SummaryGenerator.build_test_rows` (read-only окно + S1/S2) для этапных сценариев; моки/шпионы LLM и `services/telegram_send` для живого `_run`-пути (публикация/обложка/фолбэк).
- **Покрытие (11/11):** (1) несколько параллельных разговоров; (2) короткие важные ответы; (3) длинные сообщения; (4) `reply_to`; (5) упоминания; (6) почти пустой лог; (7) невалидный JSON L1; (8) ошибка LLM; (9) ошибка генерации обложки; (10) Rich Message с H1; (11) обычный текстовый fallback. Сценарии 1–8 — dry-run/юнит+интеграция (S1–S5-контуры), 9–11 — живой `_run` с подменённым `send_rich_message`/`send_text`/`generate_image` (шпион: 0 реальных вызовов Telegram).
- **Жёсткий инвариант harness:** число реальных отправок Telegram = **0** (шпионы `send_rich_message`/`send_text`; тест «0 публикаций тестовых результатов в основной чат»).
- **Артефакты:** тест-модуль (напр. `tests/test_summary_deploy_round1026.py`) + чек-лист «сценарий → тест → pass/fail» в evidence фичи; R17-safe (только числа/коды/id, без ключей/сырых текстов).
- **Опциональное усиление:** прогон существующего S9-контура «Тестирование» на проде (0 публикаций, 2 реальных LLM-вызова) на целевом чате — как «живое» предполётное evidence (использует уже задеплоенный S9, не требует кода S10).

**Альтернатива «живой тестовый прогон с публикацией в тестовый чат»** отклонена: §114 прямо запрещает публиковать тестовые результаты в основной чат; dry-run/шпионы дают покрытие без побочных эффектов.

### D4. §115 — первый рабочий запуск: 7 проверок + артефакты (ответ (d))

**Решение.** После деплоя выполняются **все 7 проверок** (evidence — в `deployment.md` и §117-документе; наблюдаемость — существующие S7/S8, без новой витрины):

| # | Проверка | Как подтверждается (наблюдаемо) |
|---|---|---|
| 1 | Hybrid активен | effective-резолв `_hybrid_l2_enabled(target_chat)` = **True**; в логах прогона `mode=hybrid_l2` |
| 2 | Фильтр включён | резолв `flags.summary_filter_enabled` = **True**; событие `FILTER_COMPLETE` |
| 3 | Модели L1/L2 | резолв слотов `SUMMARY_L1_*`/`SUMMARY_L2_*` (пусто → глобальная модель); в логах `L1_COMPLETE`/`L2_COMPLETE` — провайдер/модель (R17-safe) |
| 4 | Загрузка промптов | канон L1/L2 (`services/summary_prompts.py`) и миграции (`prompt_migrations.py`) загружаются; байт-проверка |
| 5 | Штатный запуск | обычный прогон Саммари (ручной `/summary` админом или тик планировщика cron 0/6/12/18) |
| 6 | Логи всех этапов | сквозной `run_id`: `SUMMARY_START` → `FILTER_*` → `L1_*` → `L2_*` → `FORMAT_*` → `COVER_*` → `PUBLISH_*` → `SUMMARY_COMPLETE` |
| 7 | Публикация | `PUBLISH_RICH_COMPLETE` **или** `PUBLISH_TEXT_COMPLETE` (+ `message_id`) |

**Наблюдаемые критерии (§115):** rich — **полноценная статья, изображение сверху + настоящий H1** (`<img>` → `<h1>`); plain — **обычное текстовое сообщение с жирным заголовком (`<b>`) и абзацами**; в обоих случаях **текст читаем**. Evidence — скриншот сообщения + фрагмент логов (R17-safe).

**Разграничение с §114:** §114-тесты **не публикуют** в основной чат; §115 п.5/7 — это **легитимный первый рабочий прогон**, который публикует в целевой чат (в этом и смысл «подтверждения успешной публикации»).

- **VERIFIED для активации** = deploy VERIFIED (health/version/логи/0 ошибок/Δ DDL=0/§104-контур не тронут) **и** §115 7/7 с evidence, и effective ON подтверждён. **Live-приёмка качества публикации (rich/plain) — за владельцем.**

**Альтернатива NOT_APPLICABLE** отклонена: S10 меняет рантайм-поведение (default ON) → прод/master разошлись бы.
