# MCA-10b `mca-10b-random-applications` — threat-failure-analysis.md (Step 2 @Architect, 05.10.2026)

Risk **R3** (подтверждён, ADR-1028-17). Формат — по прецеденту mca-10a/mca-15 (THR-ID → угроза → сценарий → митигация → где проверяется). Инварианты: R17, «выбор ≠ вердикт», OFF = бит-в-бит 2.58.60, вторые механизмы запрещены.

| ID | Угроза / отказ | Сценарий | Митигация (решение ADR-1028-17) | Проверка |
|---|---|---|---|---|
| THR-1 | **Дублирование применений** — несколько функций рождают независимые поводы написать/несколько 5%-проверок на одну реплику | memory-вариант и форма прошли по отдельной проверке каждая; бот «спамит» вариативностью | Один `choose()` на conversation operation (D3); один гейт после сна (D4); карта purpose→probability одна (D2) | A29-фикстура: одна проверка/один draw на ситуацию |
| THR-2 | **Рекурсия исследования** — exploration-job завершается и запускает новую лотерею, цепочка разрастается | фоновой job после пакета сна триггерит ещё один sleep-гейт | Hook только на завершении **обычного** пакета сна; job не считается пакетом; exploration-job никогда не создаёт exploration-job (D4, ТЗ `:614`) | A37: завершение job → 0 новых лотерей |
| THR-3 | **Дубли job после рестарта** | restart повторно создаёт archive_sample/belief_review/association_pair | Уникальный ключ `(chat_id, package_run_id, type)` в `task_jobs` (coalesce/unique v14); идемпотентный повтор (D4) | A37/§14.3: рестарт — 0 дублей |
| THR-4 | **Random OFFSET по архиву** — случайный прыжок по 2M строк, «исследование» без покрытия | выбор диапазона `OFFSET rand()` по таблице | Нижняя группа покрытия → draw периода → поддиапазон по стабильным ID; OFFSET запрещён (D7, ТЗ `:648`) | A31-фикстура + код-ревью запрета |
| THR-5 | **Повреждение основного cursor** — случайная обработка будущего диапазона двигает основной проход через непроверенное | основной worker считает случайный диапазон выполненным | Покрытие отмечается только по факту совместимой версии; cursor не двигается через непроверенное; покрытие объединяется без дублей (D7, ТЗ `:650`) | A31: непроверенные не пропущены, покрытие без дублей |
| THR-6 | **Starvation основной очереди** — random jobs вытесняют полный archival проход | очередь забита exploration-jobs | exploration-job — отдельный kind, основной worker его не выбирает; исполнение отдельным шагом после сна (D4) | A31/R7d: основная очередь не блокируется |
| THR-7 | **Подмена retrieval случайностью** — нерелевантная старая история поднимается над подходящей; direct-запрос заменён случайным | «разнообразие» обходить релевантность | Отбор релевантность→разнообразие; признак допуска = версия ранжирования; `direct_request` в `INELIGIBLE_MEASUREMENTS` (D6, ТЗ `:630`, `:89–92`) | A30: нерелевантная исключена; direct не заменён |
| THR-8 | **Колебания убеждений** — повторные review на тех же материалах бесконечно переписывают убеждение; отсутствие контрпримера задним числом «повышает уверенность» | belief_review крутится, счётчик «улучшений» растёт без изменений | `material_refs_hash` в `mca_belief_reviews`: те же материалы → kept, версия не растёт; «нет контрпримера» ≠ усиление; счётчик не растёт без изменения (D8, ТЗ `:664–666`) | A32-фикстуры (обе стороны) |
| THR-9 | **Ложная каузальность/склейка** — аналогия становится причинным утверждением или автосклейкой историй; дубли события дают «связь» | Association попадает в досье как факт | Отдельный тип производной интерпретации, статусы, stale по версиям; продолжение — только правила EpisodeService; разные canonical ID обязательны (D9, ТЗ `:682`) | A33: аналогия ≠ причинность/склейка; дубли отвергнуты |
| THR-10 | **Второй контур инициативы** — фоновая находка отправляется в Telegram напрямую из worker | research job сам пишет в чат | Результаты → память/очередь кандидатов; отправка только единственным координатором (D4/D9, ТЗ `:614`) | Код-ревью + A37-регресс |
| THR-11 | **Утечка персональных деталей (R17)** — витрина/события показывают сырой контекст, источники, ключ; чужой chat scope | наблюдатель без прав раскрывает кандидатов | R17-safe события (ID/коды/числа/refs); фильтрация по правам/chat scope в snapshot; ключ/сырой контекст не отдаются (D11, прецедент 10a-snapshot) | R17-скан + A35-регресс прав |
| THR-12 | **Имитация квантовости** — анимация выглядит как выбор, которого не было; повтор генерирует новые QRNG/LLM вызовы; exploration показан как quantum, если не дошло | витрина «рисует» активность | Воспроизведение только записанных событий; запрет новых вызовов на открытии/кадре/повторе; «Пока нет событий»; метка = actual_source (D11, ТЗ `:712`) | A35: journal-ID/source/без внешних запросов |
| THR-13 | **Расход квоты/запаса применениями** — 5 purpose-ов истощают ANU-запас, ломая прямые случайные ветки | фоновые draw выедают буфер | Один источник и единая квота 10a; draw раздельные по решениям, но запас общий с watermark/fallback 10a; новых источников нет (D2; GEN-R3) | Регресс 10a quota/запас (focused) |
| THR-14 | **Дрейф каталога/OFF-нечестность** — F8-процедура пропущена или OFF показывается как работа | настройки не совпадают с фактом; матрица §27.1 врёт | F8 обязателен (D16); kill-switch env-only с честным `disabled`/`not_run`; гейт-матрица OFF-паритета в §14.2 (D13/D12) | F8 `--check`; OFF-паритет тесты |

**Критические (блокируют релиз при отказе митигации):** THR-2, THR-5, THR-8, THR-11, THR-12. Остальные — важные, проверяются focused-фикстурами §14 spec.
