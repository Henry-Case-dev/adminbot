# PVR-S4 — единый контроль версий промптов в админке (UI)

Ветка: `pv/ux` (от `7a8af045`, ветка `evol/impl`). Пакет:

## Что сделано

Один компонент `prompt-version-card` (`web/app.js`, шаблон
`#prompt-version-card-tpl` в `web/index.html`) смонтирован там, где
редактируется промпт:

| # | Поверхность | Монтаж |
|---|---|---|
| 1 | вкладка «Промпты» — редактор библиотеки | `web/index.html` (`data-prompt-editor`) |
| 2 | карточки модулей (два generic-рендерера `:data-cfg-key`) | `variant="bar"` |
| 3 | «Инициатива → Мемы» — два промпта | два `v-model` на `memeDraft.*` |
| 4 | Speech/Character — редактор блока | `data-speech-block-detail` |
| 5 | каталог зарегистрированных промптов | `variant="history"` |

Вторая реализация панели истории удалена вместе с корневым состоянием
`promptHistory` и его методами (`web/app.js` −450 строк): история, diff,
активация, baseline и восстановление живут только в компоненте.

## Поведение

- **Карточка**: имя, область человеческими словами (`Глобально` /
  `этот чат · <название>`), состояние одной фразой — `Действует в этом чате ·
  изменён вручную · 03.11 23:42`, `Наследуется от глобального`, `Изменён
  глобально`, `Базовый по выбору владельца`, `Исходный из кода`. Сырые
  `act:`/`fac:`/`sha`/`revision_id` в карточке отсутствуют — только в
  раскрываемых «Подробностях» (`⋯`).
- **Черновик** визуально отличается (`pv-text--dirty`, бейдж «черновик не
  сохранён», раскрываемый действующий текст сервера), кнопки «Отменить
  несохранённое» / «Сохранить».
- **Панель истории**: боковая на десктопе (`min(560px, 46vw)`), полноэкранная
  на ≤767px; полный список по `entries[]` с догрузкой по `page.next_cursor`
  (потолка 50 нет); строки: номер, дата, источник, кто, область, статус,
  «Посмотреть»; полный дословный текст без обрезки и без пересохранения;
  diff «было → стало» красит только `+`/`-` (контекст — `pv-diff__ctx`).
- **Действия по правам**: «Применить эту версию» — только при непустом
  `revision_id` и `actionable`; иначе видимая причина (`нет прав`,
  `code-only`, `несовместима`, `retired`, `журнал недоступен`).
  «Назначить базовой» меняет только указатель и говорит прямо: «Базовая
  версия изменена, действующий текст пока прежний». Панельные действия:
  «Снять назначение», «Восстановить базовую (для чата)», «Вернуть исходную из
  кода» (с подтверждением), «Скопировать глобально» в чатовой области.
- **Никакого оптимистичного «сохранено»**: после Save/Применить/Назначить
  компонент перечитывает `/versions`, хост — конфигурацию (`promptVersionReload`);
  409/422/503 показываются честным текстом, черновик остаётся в поле.
- **Мемы**: два промпта рядом на ≥1024px и столбиком на мобильном, у каждого
  своя «История версий»; сырой `{joke}: 0` заменён спокойной подсказкой:
  `0` → «Прикол автоматически добавится после шаблона», `1` → «Прикол
  вставится в отмеченное место», `≥2` → существующая ошибка конфигурации.
  Текст шаблона и рендерер не тронуты.
