Это коррекция существующих ASAP Speech Architecture и Factcheck — без новых подсистем, без второго пайплайна, без второго источника характера и мата.

## Классификация архитектуры

`ARCH_REUSE_CONFIRMED`: все точки ответственности уже существуют — Prompt Registry/Composer, Personality Core (`services/chat_prompts.py`), Expression (`services/mca_expression.py`), Style Policy, Factcheck (`factcheck_planner/orchestrator/renderer`, `search_aggregator`), Checkup (`checkup_service`), Effective Prompt Inspector (`web/api/speech.py`). Новых публичных контрактов не вводим; меняется содержимое действующих слоёв и корректность существующих проверок. Единственная блокирующая зависимость — порядок «реестр -> текст промптов» (общий `prompt_migrations.py`).

`ARCHITECT_REQUIRED` был заявлен точечно по аддендуму ASAP 4 (принадлежность каждого фрагмента старого Checkup-промпта слою §1 и целевая композиция genre/Core/Expression/Style — новый общий контракт распределения инструкций). **Заморожено Architect 24.10**: `arch-checkup-transfer.md` §1 (вердикт `ARCH_REUSE_CONFIRMED`), `arch_freeze.status=frozen` в `slice-graph.json`. Карта принадлежности и порядок слоёв больше не пересматриваются Builder'ом; CHECKUP/CORE разблокированы. Остальные слайсы (FORENSIC, PROMPTS, FACTCHECK, EXPRESSION, OPS) от этой заморозки не зависели.

## Порядок (6 этапов из §10)

1. **W0 — FORENSIC** (`FORENSIC`): трасса запуска 23.10 по 10 этапам, извлечение подписи/изображения/меты/дат, проверка лимитов planner и лексического фильтра, ошибки Tavily/Exa/DDG/SafeFetcher. Только чтение прода, артефакт в `forensic/`.
2. **W0 — PROMPTS** (`PROMPTS`): provenance_missing по существу, восстановление связи штатным API, Inspector/редактор показывает сохранённую и действующую редакцию, причину, источник, ревизию и способ разрешения. Защита не отключается, метаданные не выдумываются.
3. **W0 — EXPRESSION** (`EXPRESSION`): диагностика пути `effective -> payload -> raw -> outbound` по пяти маршрутам, затем семантика FREQUENT без квот и постпроцессора, серия реальных проб.
4. **W1 — FACTCHECK** (`FACTCHECK`, после FORENSIC): семантические запросы, отдельные вердикты по утверждениям, различение «нет доказательств / сбой поиска / сбой обработки / частично проверено», честный renderer.
5. **W1 — CHECKUP + CORE** (`CHECKUP`, `CORE`, после PROMPTS): Checkup получает Core/Expression/Style и не задаёт личность, убирается строчная буква; Core дополняется качествами §5.1 без замены авторской редакции.
6. **W2 — OPS** (`OPS`, после CHECKUP), затем **W3 — ACCEPT**: 23 сценария, governance-запреты §1, отчёт §11, деплой и postdeploy-наблюдение.

## Дополнение 24.10 #2 — свобода речи в Personality Core

Поздняя корректировка владельца (`source-2026-10-24.md`, ADDENDUM #2, L802-806) **включена в эту карту**, без нового эпика и без новых слайсов.
