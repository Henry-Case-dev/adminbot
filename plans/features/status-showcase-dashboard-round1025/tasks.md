## Верхнеуровневые задачи (детализация при старте)
- [ ] Desktop-композиция §12: 12 колонок; строки — Hero(5)+Системные метрики/сердцебиение(7) / Граф(8)+Сон(4) / Мониторинг интеллекта (вся ширина, 3 панели: убеждения/парадигмы/эволюция) / Превью карты LLM-вызовов(7)+Живая лента досье(5) / Бюджеты (вся ширина) / Логи (вся ширина); порядок не переставлять произвольно; пропорции можно корректировать по контенту.
- [ ] Hero состояния бота §13: имя/статус/последняя активность/аптайм (если отличается)/компактное предупреждение при ошибке; Liquid Glass; без длинной таблицы и постоянной яркой пульсации.
- [ ] Системные метрики §14: CPU/RAM (число+progress bar), диск (занято/всего+%), аптайм; отсутствие данных ≠ 0; при выбранном чате — пометка «метрики всего сервера».
- [ ] Живое сердцебиение §15 (Canvas 2D + `requestAnimationFrame`): реальные источники (доступность/CPU/RAM/диск/критпроцессы/актуальность телеметрии); состояния HEALTHY/WARNING/CRITICAL/UNKNOWN с цветом/интенсивностью/частотой/амплитудой/характером импульса; polling 10–30 с; сглаживание/гистерезис; UNKNOWN при потере; без выдуманного BPM; тултип/клик (CPU/RAM/диск/статус/время обновления/причина); reduced motion; на mobile — отдельная горизонтальная область.
- [ ] Граф связей §16: сохранить; поиск по имени/алиасу, фокусировка, ближайшие связи, фильтры, подробности, сброс вида; семантику веса не менять; mobile — упрощённый граф + отдельный экран полного исследования.
- [ ] Виджет сна §17: обычный + глубокий сон; desktop — справа от графа, mobile — сразу после графа; время до сна/глубокого, текущее состояние, последнее выполнение, результат; бейджи «Сон через…»/«Глубокий сон через…» и «Сон до…»/«Глубокий сон до…» с glow при активности; активное состояние — с сервера (не таймер); эмодзи сохранить; единый источник времени следующего запуска; понятный статус при ошибке.
- [ ] Мониторинг интеллекта §18: **убедиться, что работает** (не менять по существу); три самостоятельные области (убеждения — живая лента, время/текст, раскрытие, скролл не сбрасывается; парадигмы — реальные данные/история/причины отсутствия, без выдумок; эволюция характера — реальные черты/история/состояние экстрактора, не статичная диаграмма).
- [ ] Живая лента досье §19: **«Новые факты»**, подзаголовок «Что бот недавно запомнил»; имя/текст/время/тип; только вертикально; скролл не сбрасывается; полная работа с памятью — в разделе «Память».
- [ ] Логи §20: остаются внизу Статуса; фильтры ERROR+WARN (дефолт)/ERROR/WARN/INFO; раскрытие подробностей; копирование строки; log viewer не переписывать; быстрый переход вверху «Ошибки: N · Предупреждения: N» со скроллом к логам; расположение ячеек/столбцов не менять без нужды.
- [ ] Превью карты LLM-вызовов §21: компактное превью последнего вызова (не одна строка с числом токенов); полная карта — в «Аналитике» (F6).
- [ ] Проверки §70/§77 и результаты §117 п.7–10 (скриншоты, Liquid Glass, сердцебиение, карта токенов).
