## Блокеры

### A. Баннер композера OFF всё ещё метит дословный хвост окна

- Владелец: Builder.
- Требование: REQ-HA-ISOLATION-SUPPLEMENTARY. Прошлая правка: баннер только у конспекта, не у дословных строк хвоста.
- Где: `services/direct_chat_service.py`, `_build_global_context`, склейка `head + tail` и затем баннер над всем телом.
- Наблюдение: блок выше. На пути ON баннер только у head-куска, хвост — отдельный кусок без баннера. На OFF голова и хвост склеены, баннер поставлен над склейкой.
- Влияние: при выключенном композере разбор последних N снова говорит модели, что свежие сообщения окна не подтверждают события диапазона. Это тот же пользовательский эффект, что в прошлом ревью.
- Правка: баннер только над строками конспекта. Дословный хвост должен быть вне этой фразы: явная граница перед хвостом или отдельная секция, как `global_tail` на пути ON. Тест, который смотрит только предыдущую строку, поправить — он сейчас защищает дефект.
- Перепроверка: тот же зонд. Баннер есть, конспект под ним, дословная строка окна не под «не подтверждает события». Без конспекта и без выборки баннера нет. Путь ON не трогать.

### B. Выдуманная дата без нуля в дне или месяце остаётся в note

- Владелец: Builder.
- Требование: REQ-HA-NO-INVENTED-STATS. Обещание фикса: выдуманные даты срезаются из note и помечаются.
- Где: `_ha_strip_invented_claims` делает `replace` по строке из `invented_date_violations`. Детектор принимает `5.10.2024`, флаг пишет `05.10.2024`. Срез ищет уже прибитую нулём форму, которой в note нет.
- Наблюдение: `5.10.2024 была встреча` → `flags=invented_date:05.10.2024 note=5.10.2024 была встреча`. `15.3.2025 была встреча` → флаг `15.03.2025`, в note дата цела. Контроль `15.03.2025` срезается — поэтому тест зелёный.
- Влияние: Writer по-прежнему видит выдуманную дату как факт. Флаг написан другой строкой и дату в note не отменяет.
- Правка: срезать ту запись даты, которая реально стоит в note (написание, которое нашёл детектор), а не только `ДД.ММ.ГГГГ` с нулями. Флаг оставить. Дату, которую подтверждает штамп ref, не трогать. В тест добавить неприбитые формы, не ослабляя прибитую.
- Перепроверка: notes `5.10.2024`, `15.3.2025`, `5.3.2025` теряют дату и получают флаг; `15.03.2025` по-прежнему срезана; дата строки выборки в note остаётся.
