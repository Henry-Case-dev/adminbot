## Блокер

BLOCKER. Владелец: Builder. Требования: source-2026-10-29.md, раздел 3.3 (строка 177) и раздел 4.1 (строка 201); проверка H14 и запрет терять сообщения без информации о потере; строки карты REQ-HA-INCOMPLETENESS-REPORTING, REQ-HA-CONTRACT-REWORK, REQ-HA-PAGES-NOT-FULL.

Наблюдение на живой SQLite, кандидат 2aaa2ee5:

1. Выборка 85 сообщений. Первая страница: available=85, remaining=45, has_next=1. Между страницами удалены id 41-84, якорь 85 жив. Продолжение: requested=85, available=41, processed=41, remaining=0, has_next=0, incomplete=0, reason пустой, в теле только m85. 44 сообщения исчезли, а ответ говорит, что выборка полная.
2. Выборка 100. После первой страницы удалены id 50-90. Финал обхода: available=59, processed=59, incomplete=0, reason пустой. Сообщения n60 в объединённых страницах нет, n100 есть. Дыра не названа.

Причина: payload курсора (tool_router.py, около строк 387-394) не хранит захваченный available. _history_continue (около 3367-3372) пересчитывает available по живому COUNT. _format_history_page (около 3387-3398) ставит incomplete=1 только если fetched равен 0 и remaining больше 0. Если выживший хвост ещё читается, remaining становится 0 и неполнота не зажигается. Тест test_vanished_tail_reports_incompleteness в tests/test_history_pages.py (около 317-341) закрепляет дефект: он требует incomplete == 0.

Влияние: модель считает, что дочитала обещанную выборку, и строит вывод по дыре.

Минимальная правка, без Architect:

- Класть захваченный available в курсор и читать его обратно.
- Если живой COUNT окна меньше захваченного available, ставить incomplete=1 и непустую причину. Не использовать anchor_missing, пока строка якоря на месте. Причина: tail_missing.
- Выжившие строки всё равно отдавать (фактический охват). Не выдавать эту страницу за полную выборку и не откатываться на depth=50.
- H7 без удаления (30 из 2000, одна страница, курсор не выдаётся) оставить с incomplete=0.
- Исправить тест, который сейчас требует incomplete=0 на исчезнувшем хвосте. Добавить регрессию на дыру в непрочитанном участке (якорь жив, часть строк дошла, incomplete=1).

Перепроверка: два сценария зонда выше; test_available_short_of_requested; класс TestCursorFailClosed.
