## 3. D12 — факты фактического подключения (подтверждено)

* `GET /api/vision/state` → `runtime_snapshot` (provider/model/api_type/detail/
  checked_at/visible_reason; ключей/секретов в ответе нет) → computed
  `visionStateFacts`: Провайдер (хост), Модель, Тип подключения
  («OpenAI-совместимый»), Результат проверки (+время), Техническая деталь
  (R17-safe класс, отдельной строкой).
* Рендер в **двух местах**: секция Vision вкладки «LLM Провайдеры»
  (`data-vision-effective-line` + `data-vision-facts`) и карточка модуля
  «Распознавание изображений» (`data-vision-facts`) — e2e проверяет оба
  (llm-* и mod-*), включая раскрытые настройки.
* Актуальность: загрузка при входе на вкладку (и на «LLM Провайдеры», и на
  «Модели» для mod_vision, кэш 30 с); после пробы `state` из ответа сразу в
  линию/факты (e2e probe-* проверяет обновление факта «Результат»; probe-ok —
  линия «Распознавание работает»); после сохранения настроек Vision кэш
  сбрасывается и state перечитывается.
* 403: фоновая загрузка с `silent403` — без тоста «Доступ запрещён» (fail-open
  MCA-19); JS-тест фиксирует подавление тоста и то, что флаг не уходит в
  fetch-init; явные save/test по-прежнему показывают отказ.

## 4. §4 — первопричина переполнения (подтверждено замерами)

* Причина: на ≤767px `.prov-grid { 1fr }` = `minmax(auto,1fr)` → min-content-пол
  строки (rem-подпись `w-36` + intrinsic `<input>`) при Android-масштабе 20/24px
  раздувал трек за контейнер: `main.scroll-area` 376>320 и 449>360 (внутри main,
  не documentElement — потому прежние проверки не ловили).
* Лечение: контейнерный трек `repeat(auto-fit, minmax(min(320px,100%),1fr))`;
  `.app-shell.ia-v2 .prov-grid → minmax(0,1fr)` (≤767, снятие пола);
  `.prov-grid > *`, `.prov-row`, `.prov-row .field/.secret-field__input` —
  `min-width:0`; `@container prov-grid (max-width:479px)` — подпись над полем,
  `width:auto/max-width:100%` (скоуп — только формы провайдеров; контейнер
  `container-type: inline-size` уже стоял на `.prov-grid` в базовом правиле);
  `.prov-head` wrap + badge `flex:0 0 auto`; переносы — `overflow-wrap:anywhere`,
  `word-break:break-all` нет.
* Мои DOMRect-замеры (e2e): 320/root20 **376→320**, 360/root24 **449→360**;
  после — 0 overflow/row/control-issues на 320/360/390/430, landscape, font20/24;
  layout=stack на узких (container-driven), row в ландшафте 640/844.
* Полигон/стекло/прочие секции не тронуты: диф — только
  `.prov-grid/.prov-row/.prov-head/.conn-fact*` (+переформулирован комментарий
  speech-карточки, см. §6); backdrop/background/glass-правила не менялись.
