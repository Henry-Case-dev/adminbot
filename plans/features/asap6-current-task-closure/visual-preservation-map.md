7. Ссылка на полный Analytics

### Целевые вкладки Analytics
`Обзор | Процессы | Запуски | Инциденты | Память и интеллект | Модели и расходы | Саммари | Логи`

ПОПРАВКА ВЛАДЕЛЬЦА (08.10.2026): логи НЕ являются отдельной вкладкой-режимом. Блок логов физически живёт внизу Analytics (как до Wave 2), вне таб-переключения. Вкладка «Логи» = anchor/shortcut: scroll к существующему блоку, без смены режима и выноса логов из контекста.
- Первый экран «Обзор»: здоровье (N OK / N degraded / N blockers), саммари success, GraphRAG state, провайдеры, инциденты, ticker.
- Человеческие названия; technical details в Developer details (expandable).

## Компоненты метрик
- Ring/donut НЕТ в проекте; есть `.badge`-семейство + `.progress` (app.css:748, bar-red:1388).
- Правило: donut/ring только при реальном denominator; categorical state → badge с текстом (цвет не единственный носитель).
- Новый ring-компонент — только если нужен; предпочесть progress/badge.

## Верификация Wave 2
- Playwright: deterministic pass по каждой затронутой поверхности (desktop wide / laptop / mobile narrow), loading/error/empty states, reload persistence.
- Browser Use: human-like visual pass той же поверхности + Visual Neighborhood Sweep (косяки на той же странице/модалке чинятся в этом же раунде).
- Серверные API НЕ менять ради UI, кроме оговорённых (S4 embeddings поля).
