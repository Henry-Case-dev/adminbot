## Верхнеуровневые задачи (детализация при старте)
- [ ] Каталог модулей §32: заголовок, краткое описание, компактная панель быстрого управления, поиск, фильтры, основной каталог (desktop ≤3 колонки / tablet 2 / mobile 1; не огромная таблица).
- [ ] Карточка модуля §33: иконка/название/генеральный тумблер в верхней строке; описание; **фактическое состояние выбранной области**; кнопка «Настроить»; вся карточка ≠ тумблер; на mobile тумблер в верхней строке; тач-область ≥44×44.
- [ ] Панель быстрого управления §34–§36: избранные модули (кандидаты: Сводки чатов/Ответы/Фактчек/Поиск), закрепление админом, «Все избранные»; это **представление UI**, не конфиг поведения; состояние модуля всегда серверное.
- [ ] Единое состояние §37–§38: логический ключ `scope_type + scope_id + module_id` (`global/null/summary`, `chat/123/summary`, …); никаких независимых `useState`/копий конфигурации.
- [ ] Канонический **`ModuleConfigurationStore`** §39 на реактивном Vue: `getModuleState/setModuleState/refreshModuleState/subscribeModuleState`.
- [ ] **Одна мутация → все представления** §40: подтверждение → синхронизация панели/карточки/страницы модуля; не 3 запроса.
- [ ] Состояние во время запроса §41: блок повторной мутации, индикатор сохранения, подтверждение сервера, откат к серверному состоянию при ошибке, без бесконечных ретраев.
- [ ] Быстрая смена чатов §42: scoped query keys, корректная обработка устаревших ответов (ответ чата A не меняет тумблер чата B).
- [ ] Наследование и фактическое состояние §43: глобальное значение / локальное переопределение / фактическое; «Не работает: отключён глобально»; не уничтожать локальный override; «Ожидает применения».
- [ ] Поиск §44: «Найти модуль…» (русское название/описание/техническое имя/синонимы; «Саммари»/«сводка» → «Сводки чатов»); результаты сохраняют генеральные тумблеры; без отдельной страницы результатов.
- [ ] Индикаторы §45: Всего/Включено/Выключено/Есть проблемы для выбранной области; неизвестное ≠ выключено.
- [ ] Тесты §72 (единый переключатель) и §73 (независимость чатов), критерии §79/§116.
