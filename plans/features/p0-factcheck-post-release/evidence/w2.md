    message содержит директиву 1 раз, user-payload 0 раз, `<evidence>`

    `DownAggregator`, `<analysis_context>` в user-payload не вытесняет

  в `_TEMPORAL_FALLBACK_SYSTEM` и `TEMPORAL_VALIDATOR_SYSTEM` директивы нет;

  `["temporal_verdict", "temporal_validator", "temporal_verbalize"]`
  не изменился.
- Семантика согласована с существующим правилом (1) `TEMPORAL_ANALYST_SYSTEM`
