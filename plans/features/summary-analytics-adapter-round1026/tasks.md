## Приёмочные инварианты S8 (нарушение = НЕ принято; трассировка §ТЗ + ADR-1026-10 + SC-01…SC-18 спеки)
1. **Только реальные этапы (§25/§30):** ни одного **фиктивного** узла; **никаких выдуманных** `parent_id`/связей; агрегированные метрики **не изображаются как точные трассировки**; последовательность показывается только там, где подтверждается данными. **SC-02; REQ-S8-05/-08/-14.**
2. **Маппинг реальных шагов (§111, ADR D2):** `filter`→`algorithm`, `l1_clusterizer`/`l2_writer`→`llm`, `formatting`/`format`→`format`; **ни один реальный шаг Эпика 2 не попадает в `other`**; `publication`→`publish` **зарезервирован и не активируется**. **SC-01; REQ-S8-02/-03.**
3. **Вторая система визуализации запрещена (§111):** используется **существующий** `ExecutionGraph` (F6 §65, `web/static/execution_graph.js`); `GraphViewer`/`NodeCard`/`DetailPanel` **не переписываются** (§30/§111); расширяется только **adapter** + источник узлов. **SC-07; REQ-S8-01/-04/-05.**
4. **Adapter-контур (§25, ADR D3):** разделение слоёв «Backend metrics → Normalized execution graph → UI»; преобразование API-ответов **вне** SVG/Vue-компонента; нормализация существующих данных — **отдельным adapter** (§23). **SC-03; REQ-S8-06/-08.**
5. **`ExecutionNode` честен (§23, ADR D3/D4):** недоступные поля → `null`/«Нет данных» (никаких вымышленных значений). **SC-04; REQ-S8-06.**
6. **`kind`-разделение (§24/§111):** `algorithm` (Filter) / `llm` (L1 Clusterizer, L2 Writer) / `format` (Formatting) / `publish` (Publication, **GATED**); `kind` определяет состав полей (для `algorithm` — **без выдуманных LLM-токенов**). **SC-05; REQ-S8-03/-07.**
7. **§112-метрики честны:** неизвестная стоимость → **«Нет данных»**, **никогда выдуманный `$0`**; стоимость LLM **не смешивается** с расходом ресурсов сервера; безлимит (`-1`-sentinel) → **«Без лимита»**; `publication_status="gated"` — честный факт («Публикация: недоступна (гейт S6)»), не выдуманное «опубликовано» (§28). **SC-09; REQ-S8-09/-10.**
8. **§112-перечень полон (ADR D4):** исходные/после фильтра/восстановленные/процент отсева/темы/токены L1/L2/стоимость L1/L2/общая/время/статус обложки/статус публикации; для `algorithm`/`format` — реальные метрики **без** LLM-токенов. **SC-08; REQ-S8-09.**
9. **Закрытие F6 follow-up `L-F6S-1` (ADR D4):** `/analytics/usage/summary` (+`by_module`/`series`) дополняется **аддитивным** `price_known` (`BOOL_AND(price_known)`); `fromSummary` перестаёт жёстко ставить `priceKnown:true` → агрегат честно «Нет данных» вместо `$0` (аддитивно, без нового эндпоинта — трактовка R16). **SC-09; REQ-S8-10.**
10. **Корреляция по `run_id`/`correlation_id` (§112, ADR D5):** узлы/метрики связываются по `run_id` (S7) = `correlation_id` (S1–S5/S9) и `llm_usage_events` (PG, `module='summary'`); **второй идентификатор/второй учёт не вводится**. **SC-06; REQ-S8-11.**
11. **Режимы/агрегаты (ADR D6):** «последний вызов» (цепочка одного `run_id`) и «период» (агрегат) **не смешиваются**; агрегат не изображается как трассировка; **«нет `parent_id` → нет связи»** (ветвление не достраивается). **SC-10; REQ-S8-08.**
12. **publish-срез GATED (S6/D4, ADR D1/D8):** `kind="publish"`-узлы и `PUBLISH_*` **не реализуются/не вызываются** до live-приёмки Эпика 1; публикационный путь (§100–§106) и `generate_image` — **вне diff**; в diff — только зарезервированный маппинг `publication→publish`. **SC-12; REQ-S8-14.**
13. **Δ DDL=0 / Δ каталога=0 / без нового флага (ADR D7):** новых таблиц/колонок/индексов нет (SQLite v12; reuse `/analytics/*` + `llm_usage_events` + `llm_pricing`; снапшот прогона — **in-memory**, без persistence); `services/param_catalog.py` **вне diff**, F8 **не переиздаётся**; **новый флаг НЕ вводится** (мягкий откат — существующие env-only `TOKEN_ANALYTICS_ENABLED`/`TOKEN_FLOW_NODEFLOW_ENABLED`). **SC-13; REQ-S8-13.**
14. **CSP/zero-build:** без CDN/inline/`eval`/`v-html`/WebGL; `execution_graph.js` — same-origin `<script src=":?v=__APP_VERSION__">`; новые внешние зависимости — **0**. **SC-13; REQ-S8-13.**
15. **2-вызовность (ADR-1022-3/4/5):** S8 **не добавляет ни одного LLM-вызова** (adapter/метрики — read-only); `await_count==2` сохранён. **SC-14; REQ-S8-13.**
16. **R17/R18:** в узлах/метриках/логах — только числа/коды/id/host/HTTP-статус; **без** API-ключей, промптов, сырых текстов сообщений и сырых ответов LLM; теги/бэкапы не удаляются. **SC-15; REQ-S8-13.**
17. **Mobile §29:** граф **не сжимается до 320px**; конкретный вызов — **вертикальная последовательность этапов**; период — агрегированная диаграмма с раскрытием; числовые значения доступны без pinch-zoom. **SC-11; REQ-S8-12.**
18. **§110-viewer не переписывается** (S7 ✅): log viewer внизу Статуса — **вне diff**; S8 не вводит второй контур логирования. **SC-16; REQ-S8-14.**
19. **Не дублировать S9 (§113):** §112-метрики уже отображаются в dry-run S9 — S8 показывает их в контексте карты/анализа, **без** второй реализации сбора метрик; S9-контур вне diff. **SC-16; REQ-S8-14.**
20. **Deploy (ADR D9):** **ДА** — bump `APP_VERSION` **2.58.26 → 2.58.27** + `README.md` (`test_app_version_matches_readme`) + cache-bust; откат — annotated-тег `pre-round1026-s8` (→`2ffeb6a`) + `git revert`; hot-OFF не требуется (adapter/источник аддитивны). **SC-17; REQ-S8-13.**
21. **Ядро верифицируемо без S6 и без владельца (ADR D1):** все SC-01…SC-17 проверяются авто-прогонами (pytest/JS) и diff-аудитом **без** публикационного пути; live-приёмка Эпика 1/S1–S5/S7/S9 — **PENDING OWNER VERIFICATION** (доп. проверка, не блокер старта/верификации ядра). **SC-18; REQ-S8-14.**
