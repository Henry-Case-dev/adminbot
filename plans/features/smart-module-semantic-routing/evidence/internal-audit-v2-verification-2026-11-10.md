## 7. Правило, чтобы дрейф не повторился

- Любая инспекция продукта по этому релизу — только `git show 2b7e9c7f:<path>` (или `git worktree add` на `2b7e9c7f`). Рабочий каталог содержит `2.58.111` и для строк этого релиза недействителен.
- В отчёте указывать ревизию рядом с каждой цитатой: `file:line @ <sha>`.
- Перед привязкой: `git hash-object` файла против `git rev-parse <sha>:<path>` — при расхождении цитата недействительна.
