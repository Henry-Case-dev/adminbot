## Что изменено (r2)

`services/direct_chat_service.py`
- Добавлены `_split_writer_extras(blocks, selection_texts)` и
  `_insert_writer_extras(blocks, extras)` рядом с `_sent_user_text`:
  строгий ordered-subsequence split по ТОЧНЫМ provenance-текстам; `exact=True`
  только при полном совпадении по порядку и без неоднозначности; никакой
  склейки/нормализации/эвристик. Anchor — ведущий тег следующего ожидаемого
  selection-блока; `""` — tail. Вставка никогда не отбрасывает extra:
  ненайденный anchor → конец + WARNING + `degraded`.
- `_compose_user_content` live-success публикует
  `out_fallback["selection_texts"] = tuple(texts)` и
  `selection_payload_tokens`; legacy/fail-open этого не публикует.
- `_fallback_factory(anchored=())`: recompose и capacity-body строятся через
  `_insert_writer_extras`; capacity при
  `base_selection_budget − extra_reserve < 1`; extras сохраняются всегда;
  prepared: `payload_tokens` фактического user-тела сохранён, `budget` —
  effective input бюджета получающей модели, `selection_budget` — фактический
  allocator-бюджет; `degraded` — по capacity/anchor-деградации.
- `_l2_write_answer`: новые kwargs `selection_texts`,
  `primary_budget_tokens`, `primary_payload_tokens` (defaults None → паритет).
  Удалены `_selection_payload_exact`/`_sel_block_texts`/`_user_block_texts`.
  `_writer_extras_tokens` — один проход: time, plan, speech/lessons (composer
  OFF), все anchored extras, evidence, closing, `history_assembly_block`.
  `live_ok = selection_texts is not None and split.exact and factory`.
  Final fit больше не зависит от `fallback_budget_tokens`: при
  `primary_payload + extras > primary_budget` — один `allocate_selection` на
  primary `selection_budget`; prepared получает primary `budget`,
  `payload_tokens` отправленного user-тела, `policy_mode="final_fit"`,
  `final_fit=True`; capacity не переименовывается. Логи:
  `selection fallback recompose | anchored=N`,
  `L2 final fit | anchored=N`.
- Direct site передаёт `selection_texts`/`primary_budget_tokens`, factory — по
  наличию (решение принимает `_l2_write_answer` по `live_ok`), не по
  `selection_recompose`.
- Initiative L2: `_init_fb_factory(anchored=())`; `selection_texts =
  (context_block, <Fresh_Chat_Window>…)`; `primary_budget_tokens =
  initiative.l2`; `selection_budget_tokens = max(1, primary_budget −
  tokens(context_block))`; `primary_payload_tokens = tokens(context+window)`;
  убрано повторное вычитание fixed_context; capacity при
  `base − extra_reserve < 1`; body всегда содержит context + anchored extras.
