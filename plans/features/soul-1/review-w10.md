## Блокирующие находки

**F1 (BLOCKER). Ложные срабатывания на обычных не-image просьбах — платная генерация.**
Требование: §5.1 «по смыслу, а не только по одному regex/ключевику»; принцип слайса «ложное
срабатывание дороже пропуска».
Воспроизведение (реальный DirectChatService, capability ready; мой probe4):
«Бот, сделай уборку в квартире» → 1 генерация; «Бот, сделай план на март» → 1;
«Бот, сделай мемориальный пост про Петю» → 1; «Бот, надо сделать уборку в квартире» → 1.
Причина: `_IMAGE_OBJECT` (`services/direct_capabilities.py:176`) — подстроки без границ слова:
`"арт"` матчит квартир*/карт*/март*/стартап*/артефакт*, `"мем"` — мемориальн*/мембран*; шаг 2
(`:291`) даёт `actionable`, роутинг-фикс (`services/direct_chat_service.py:6378`) вызывает
существующий платный путь. Пользователь получает незапрошенную картинку и расход квоты.
Минимальная правка: сопоставление по словоформам/токенам с явными исключениями
(квартир*, карт*, март*, стартап*, артефакт*, мемориальн*, мембран*); тесты на эти строки.
Перепроверка: 4 строки → 0 генераций; шесть формулировок §5.1 → по 1 генерации.

**F2 (BLOCKER, тот же корень). Адресат/сам/отрицание не учитываются.**
Требование: §5.1 «Учитывать реплаи, контекст и настоящий адресат… при существенной
неоднозначности — один короткий уточняющий вопрос»; «не путать создать с придумать идею».
Воспроизведение (pipeline): «Бот, я сам нарисую мем, оценишь потом» → 1 генерация;
«Бот, подскажи идею мема, я сам нарисую» → 1; «Бот, Петя сказал: нарисуй мем про двачеров» → 1;
«Бот, нарисуй мем, но не рисуй» → 1 (детектор ВЕРНО говорит `create_image_negated`, но
основной пре-гейт `direct_chat_service.py:2221` не получает intent и регекс-дверь побеждает).
Минимальная правка: расширить детектор (self-action «я сам(а) нарисую/нарисую сам», атрибуция
«сказал/просил/написали/цитата», отрицания «не надо/не нужно/забудь/отмена») и передать
распознанный intent в основной вызов `_image_pre_gate_block`, чтобы явное отрицание/conceive
подавляло regex fast-path; тесты на эти строки.
Перепроверка: 4 строки → 0 генераций (допустимо уточнение/обычный ход).
