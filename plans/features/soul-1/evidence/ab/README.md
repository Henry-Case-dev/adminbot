## Ось A/B

ЕДИНСТВЕННЫЙ флаг `UNIFIED_COMPOSER_ENABLED` (env-ось, ON/OFF) на одной
HEAD-копии:

- **OFF («старая композиция»)** — байт-в-байт прежняя сборка речи:
  `prompt_style_blocks.compose_verbalizer_system(base, mode, plain, extent_block,
  character_block)` + MCA-23 scrub (реплика пути direct_chat_service
  L4570–4648). Без Core/Expression/юмора.
- **ON («новая композиция»)** — единый композер: `prompt_composer.compose_prompt`
  с реальными резолверами боя (`turn_snapshot` → Core через
  `resolve_core_ref`, `resolve_expression_settings`, humor craft/library,
  `identity_from_text`, `plan_ref_from_response_plan`, speech_plain/l2_writer)
  — реплика `_compose_speech_system` (L4403–4535). Тот же MCA-23 scrub.

Одна модель/провайдер/temperature; одинаковый user-текст сцены в обеих руках.
Зеркало прод-флагов — процесс-локальные env + FakeHot
(`flags.unified_composer_enabled=true`, core=full/owner_setting и т.д.);
персистентные конфиги не читаются и не пишутся. Сообщений в реальные чаты — 0.
Результаты НЕ переключают прод-флаги автоматически (L199).

- Ручные (слепой разбор, шкала 0/1/2): **остроумие, уместность, внутренняя
  связность, естественность, факты, адресат**.

1. Сцены — анонимизированные реплики-фикстуры по типовым окнам проекта, не

   `explicit_form_override` (0 LLM-вызовов); в бою план даёт L1 — отклонение

3. Одноходовые сцены без истории/тулов/уроков — сравнивается механика сборки
   (unified-слои vs простая сборка) на заводских текстах, не реконструкция
   байтов до 2.58.86 (R2).

   (код-канон, 240 симв.) одинаковы в обеих руках; PG-персоны прод-чата
   локально невоспроизводимы — отмечено в отчёте.

   локально не вызывался), ограничение в отчёте.

   telemetry-метрика 14.2, отдельный лейн). Компенсация аварии провайдера —
