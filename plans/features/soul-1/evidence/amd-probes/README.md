## Честные остатки / ограничения

1. `run_id=null` у фактчека: локальная копия `local_database.db` (12KB, схема
   dev) не содержит таблицы `mca_factcheck_runs`/`smart_messages` — durable-запись
   прогона локально невозможна; durable-пруф фактчека существует на проде
   (`tfr-38ab2b7fa98b44cb`, окно agent-checks-1). Verdict-payload захвачен целиком.
2. Search-каскад Tavily→Exa→DDG: какой уровень сработал, из ответа агрегатора не
   видно (в `.env` есть ключи Tavily/Exa) — зафиксировано как есть.
3. Проба AMD.8.2: 2 обезличенные сцены, одна модель, один проход — не
   статистика, а сравнительная проба; LLM-судья НЕ использовался (acceptance
   прямо запрещает объявлять качество по баллу судьи).
4. 4 тега `FAIL` в сыром `results.json` (summary `ok=8/12`) — дефект ассерта
   харнеса (префикс метки `detail=` вместо реального `level=`), поведение проб
   корректно; вердикты перевыведены из захваченных данных в
   `amd82-verdict-recheck.json` (4/4 PASS, 0 новых платных вызовов); чек в
   `scripts/amd_probes_harness.py` исправлен для воспроизводимости.
5. Финал-отчёт §3 (final-report.md) сохраняет историческую честную пометку о
   неснятом классе «абсурд» — обновление композиции отчёта вне скоупа пробы;
   пример класса теперь существует в evidence (`soul213-absurd-example.txt`).
