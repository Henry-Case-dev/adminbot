## 2. Схема источников, приоритеты, runtime manifest

Источники: `character.core` (документ Core, global→chat), `style.policy` (правила формы), Expression
(мат/резкость: EPISODIC/FREQUENT/OFF), персона/SelfModel (идентичность, ревизия одна на ход), L1-план
(extent/режим/жанр), Experience (уроки, `<Verified_Lessons>`), юмор (библиотека примеров + обучение),
канальный контракт (база). Приоритет: chat → global → factory → код; слои рендерятся в фиксированном
порядке (канал → Core → идентичность → уроки → план → hint политики → few-shot); Core защищён от
аддитивного бюджета; стиль применяется после выбора scope/типа выхода, машинные стадии правил не получают
(`skip_reason=machine_stage`).

Runtime manifest: каждый ход даёт `manifest_id`, послойный trace (источник/ревизия/символы/причина
пропуска из закрытого набора), diff по manifest_id, события деградации без текста промпта. Реальный
пример — `evidence/w2/manifest-direct-l2.txt`: `l2_writer, system 2520 симв., core r7.ac206fe822a2 …,
order_matches_canonical: True`, версия идентичности общая для tool-phase и L2. Эффективные слои видны
владельцу в «Речи и характере» (Inspector).

## 3. Реальные примеры

- **one_word vs micro.** Прод-проба (2.58.88, окно-1, реальные функции): `Да!!!`, `OK!!!`, `по-хорошему`,
  `да` → pass без изменений; «Да, конечно, всё сделаю» → `failed one_word_multiple_words`, текст НЕ
  обрезан. Payload-демо: вход «Да.» → доставляемый payload «Да» (1 лексическое слово); micro-путь без
  сжатия: «Да, вполне нормально.» (3 слова). `one_word` больше не схлопывается в `micro`.
- **«Без кавычек» + «без точки» с подтверждением payload.** `evidence/w3/style-payload-demo.txt`: вход с
  URL, версией `v1.2.3` и кодом → payload без завершающей точки, URL/версия/код байт-в-байт целы,
  `verify_outbound_payload status=ok`. Живое окно-2 (прод 2.58.89): включённый пресет
  `trailing_period.hard.strip` → следующая проба отдаёт текст без точки (`repaired=1`, ревизия
  `c6→c7`), мгновенный откат возвращает прежнее поведение. Кавычки-ирония: многословная цитата не режется
  вслепую — честный `conflict: quotes_require_rephrase`.
- **Короткий chat.** micro-реплики 2–8 слов (жёсткого лимита нет, >16 — наблюдаемый конфликт без обрезки).
- **Серьёзный technical.** Реальные генерации живого провайдера (Expression-оценка, 27 ходов):
  «Обувь в России не входит в список невозвратных товаров… 14 дней… бирки и упаковка» и др. —
  `add-exp/evidence/directives-fix/eval-replies.txt`.

  temporal_status=old_but_valid`, durable `tfr-38ab2b7fa98b44cb`; реальный веб-поиск 4039 символов; три
  разных правдивых отказа (не настроено / нет ключа / квота) ровно по шаблонам, 0 вызовов провайдера.
- **Непрошеная Initiative.** LIVE-FUNNEL на проде 2.58.90 (18.10, естественный контекст, без обращений):

  styled; при отбраковке L2 — честный LEGACY_FALLBACK (`message_id=1163554`), а не маскировка.
- **zero-feedback.** Сценарий «сообщения никто не комментирует» → сигнал `unknown`, гипотез/применений
  нет (`test_soul1_w4_humor_feedback.py::scenario_4`); счётчики витрины честные: sends=1,

- **Честно не снято:** живая генерация «3–6 предложений логичного абсурда» на реальном чате. Отдельной

## 10. Отчёт владельцу — простыми словами

Бот теперь говорит одним характером везде. Раньше у каждого модуля (фактчек, поиск, сводки, ответы,
инициатива) была своя копия «токсичного персонажа» — их было больше десятка, и они конфликтовали между
собой. Теперь характер описан одним редактируемым документом («Речь и характер» в меню), у него есть
версии, история и откат, и он подключён ко всем разговорным путям — от обычных ответов до фактчека и
сводок. Технические стадии (разбор JSON, проверка фактов) личностью не загрязняются. Старые
конкурирующие инструкции («токсичный бот-абьюзер», «игнорируй настройки безопасности») вычищены из
действующих промптов, при этом ваши собственные правки и накопленные наблюдения сохранены.

Форма речи настраивается отдельно («Стиль письма»): бот умеет отвечать ровно одним словом (и отличает
это от короткого ответа из пары слов), не ставит точку в конце и не обёртывает реплики в кавычки — с
сохранением ссылок, кода и версий. Всё это показано на реальных прогонах, включая подтверждение того
текста, который реально ушёл в Telegram. Бот перестал молчать в инициативе: найдены конкретные причины
молчания (порог тишины, лаг наблюдателя) и после исправлений доставлены 2 непрошеные реплики в
естественном контексте. Кнопка полного экрана на Windows Desktop честно объясняет, почему её нет, и
подсказывает, что переключить в BotFather, — это ограничение Telegram, которое кодом не обойти.

Что не сделано: A/B-сравнение «до/после» — не проводилось, потому что инфраструктура для него так и не
построена (есть только замеры цены: дополнительно ≈0 мс и 0 лишних вызовов модели); живая проверка
«абсурдных» много предложений ответов и сценариев юмора с живыми собеседниками продолжается по
наблюдению; видео-сценарий ждёт настройки медиа-провайдера. Полигон и дизайн MiniApp не тронуты
(проверено побайтово и скриншотами на 320–1440).
