1. `plans/features/soul-1/evidence/w4/frozen-assets.txt` (tracked) перезаписан прогоном W4-проверки из этого слайса: теперь в нём свежие HEAD/current-хэши после коммитов W5. 3. При коммите не захватить чужие/временные untracked из корня (`node_modules/`, `package.json`, `package-lock.json`, `.playwright-mcp/`).
4. Пре-существующее (не введено слайсом): пользовательский `topic` подставляется в канонический слот `{topic}` в system — так было до AMD26; материал чата (факты/диалоги/прошлая история) в system не попадает. На будущее, не блокер.
5. `html_safe=True` в композере влияет только на метку ревизии канала в манифесте (поведение не меняет); тесты его не утверждают — последствий нет.
