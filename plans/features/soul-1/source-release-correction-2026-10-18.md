# Коррекция подготовки релиза SOUL-1 (снапшот директивы владельца, чат, 18.10.2026)

1. В `current_task.md` уже есть позднее архитектурное уточнение, прямо отменяющее сохранение legacy-речевых промптов как активного слоя. Оно имеет приоритет над первоначальными SOUL-03/04. Не сохранять 11 старых заводских речевых значений в effective runtime только ради совместимости. Legacy остаётся исключительно в backup для аварийного отката. Подлинные авторские настройки, не конкурирующие с Personality Core, сохранить. Режимы вербализаторов и прочие кастомы проверить на скрытые инструкции характера.

2. Перед релизом проверить фактические LLM payload для Direct, Initiative, Factcheck, Summary и fallback. Единственный характер — новый Personality Core. Никаких скрытых старых определений личности из PG, Python, фабричных промптов или fallback. Не путать сохранение данных в backup с сохранением активных инструкций.

3. Все готовые функции SOUL-1 включить сразу во всех чатах. Это пет-проект с 1–2 активными чатами. Ранее установленное правило проекта — никаких искусственных OFF, canary-процентов и консервативных задержек без доказанной технической необходимости. Существующие rollback-механизмы оставить.

4. Уточнить, что подразумевается под «платной оценкой вариантов юмора»: реализован ли механизм генерации/ранжирования кандидатов или это только потенциальная функция. Если реализован и протестирован — включить по умолчанию с контекстной активацией и существующими бюджетами. Если не реализован — не блокировать релиз. Обязательные Humor Craft и Humor Feedback Loop должны работать сразу.

5. Не превращать эти уточнения в новое большое ТЗ и не открывать Human Gate. Проверить, исправить, провести Reviewer и выполнить релиз в штатном порядке. Затем продолжить очередь current_task без остановки.

**Требование к отчёту:** отдельно показать: какие legacy-инструкции исключены из реальных LLM payload, какие функции действительно включены и работает ли оценка вариантов юмора.
