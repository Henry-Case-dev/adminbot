# M4A «Векторная память»: реальные параметры, поиск и честная пустота (2.58.175)

Доказательство работ M4, вошедших в выкат `2.58.175` (`34213999`): вкладки, реальные группы каталога
9 + 16 = 25, честные причины пустоты, поиск по параметрам. Дефект владельца воспроизведён на базовом
коммите — то есть это не «стало лучше на глаз», а «до/после» на одном маршруте и одном наборе
API-ответов.

## 1. Команда и устройство стенда

```bash
py -3 tools/ui_mod_acl_m4_embeddings_e2e.py
```

Стенд (файлы `tools/ui_mod_acl_m4_embeddings_e2e.py`, `tests/fixtures/mod_acl_m4_embeddings_payload.json`,
`docs/evidence/mod-acl-ux-01-m4/` — всё в git-объекте `34213999`):

- поднимает локальный http-стенд с **настоящими** `web/index.html` + `web/app.js` из дерева коммита;
- достаёт дерево `web/` базового коммита через `git archive` (`--base dd52cbf9`) и поднимает второй
  такой же стенд — «до» и «после» снимаются с одного маршрута и одного набора ответов;
- `/api/config` собирается из `services/param_catalog.py`, секреты — `{configured,last4}` (как маскирует
  продукт); для области «Векторной памяти» это `models_embeddings` 16 + `keys_llm` 9 = **25**;
- идентичность — синтетический **глобальный** админ (`is_global_admin: true`), область GLOBAL, как на
  снимке владельца;
- проверки — по DOM, а не по «выглядит нормально»; маркер успеха `MOD-ACL-M4-EMBEDDINGS OK`, код 0.

Отчёт прогона: `docs/evidence/mod-acl-ux-01-m4/m4-embeddings-e2e.json` (`ok: true`, `fails: []`,
`base: dd52cbf9`, `route: #/modules/embeddings`, `payload: {items_total 591, models_embeddings 16,
keys_llm 9, modules 10}`).

## 5. Границы доказательства (что НЕ доказано)

1. **Живого взгляда владельца на исправленную вкладку после 2.58.175 нет.** Стенд — синтетическая
   TMA-идентичность + перехваченные `/api/*`; это сильное, но не живое подтверждение. Строки
   `MAC-S5-TAB-02`, `MAC-S5-EMPTY-01`, `MAC-S10-16`, `MAC-S15-14` поэтому остаются `PENDING` с
   условием «живое открытие карточки на 2.58.175».
2. **Сохранение/effective-source не проверялись**: `MAC-S5-TAB-02` покрыт только в части «живые поля
   каталога, сгруппированные по смыслу» + поиск. Явное сохранение, 409 и dirty state — это
   `MAC-S5-SAVE-01`, отдельная работа.
3. **Остальные вкладки не строились**: `MAC-S5-TAB-03` (промпты), `-04` (модели), `-05` (лимиты),
   `-06` (история), `-07` (расширенные) остаются `PENDING` — у «Векторной памяти» их нет, и это
   ожидаемо для инфраструктурного модуля.
4. **Наблюдение для следующей итерации:** на «Обзоре» после фикса есть кнопка «Открыть настройки
   модуля». `MAC-AC-07` перечисляет переход «Обзор → Открыть настройки» среди нежелательных; строка
   остаётся `PENDING`, вопрос выносится в M4A к моменту сборки «Обзоров» остальных модулей.

## 6. Гейт после этой сверки (`--stage release --slice M4A --candidate 34213999`)

`scoped=35 errors=82`: 4 строки среза `VERIFIED` (`MAC-S0-06`, `MAC-S5-289`, `MAC-S5-290`,
`MAC-S5-291`), 31 строка среза `PENDING` (вкладки TAB-02…07, сохранение, каталог, раскладка,
