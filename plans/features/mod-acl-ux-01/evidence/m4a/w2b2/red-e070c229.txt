4. Контрактные уточнения (в рамках H-1…H-7, без новых API):
   - `memory.lessons`: конверт `{enabled,state,count,lessons}`; строка
     «уроков: N / state» показывает СЫРОЕ состояние сервера
     (implemented/not_run/disabled). Чатовая область сохраняет прежний
     адрес `?chat_id=…` (существующий контракт «Памяти», round1039 green);
     глобальная — `?limit=50` (H-1).
   - `factcheck.temporal.runs`: compact-список `{runs}` + существующая
     модалка `openTemporalDetail(run_id)`; detail доступен только при
     наличии run_id. Для не-владельца состояние `denied` (RBAC API) —
     вкладки нет, deep link однократно уходит на bare.
   - H-7: вкладка «История» не делает собственных запросов; повторный вход
     использует 30-с кэш `loadTemporalRuns` / idle-guard `loadLessons`.
     Холодный старт factcheck допускает 2 запроса: bootstrap глобальной
     области до разрешения чата + повтор для фактической области (путь
     H-4/F2), далее — 0; e2e фиксирует «вкладка и простой не добавляют
     запросов» (n1→n2→n3 равны).
