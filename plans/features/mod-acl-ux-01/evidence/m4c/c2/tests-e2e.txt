
Стенд: реальные `web/index.html`/`web/app.js`/`web/static/app.css`; импорт C1
стабов (`ui_mod_acl_m4c1_roles_e2e`) + 3 новых read-GET; `TMA_STUB`; порт 8812.
C1-инструмент не изменялся.

Viewports 1920×1080, 1440×900, 1280×800, 768×1024, 390×844, 320×568:

- preview виден **только** внутри `[data-roles-pane="gates"]`; заголовок/note;
  0 чекбоксов; `scrollWidth <= innerWidth + 1`; 0 вложенных вертикальных
  скроллеров; поля не обрезаны; <768 — одна колонка формы, тач ≥44, кнопка
  на всю ширину; ≥768 — 2 колонки.
- admin `section.access` → `allowed`, слои `[role, global_admin_ceiling]`,
  у каждого guard.
- custom_access `section.access` → `mixed`, бейдж «Частично» (фактическое
  расхождение ролей и потолка).
- роль без назначений (`local_admin`, scope global) → `no-actor`, кнопка disabled.
- moderator, chat scope: param view → `allowed` + блок перекрытий (1 строка,
  legacy); тот же ресурс edit → `denied`/«Запрещено».
- local_admin с грантом чата edit → `allowed`, слои
  `[chat_access, chat_grant, chat_matrix]`.
- DM-владелец (self + «Личные сообщения») → `allowed`.
- Ошибки 401/403/404/422/503: отдельные карточки `data-preview-error`; решения
  нет; «Запрещено» не показывается; 503 содержит «временно», 403 — «не означает».
- Перекрытия чата: 403 → скрыто с подписью, НЕ error-карточка, решение не
  страдает; 503 → error-карточка внутри блока перекрытий.
- console/page errors: только сетевые `Failed to load resource` для
  сценарных статусов; JS-исключений нет.

Скриншоты (`shots/`): `preview-allowed-1440x900`, `preview-allowed-390x844`,
`preview-denied-1440x900`, `preview-denied-390x844`,
`preview-no-actor-1440x900`, `preview-no-actor-390x844`,
`preview-error-403`, `preview-error-503`, `preview-overrides-503`.
