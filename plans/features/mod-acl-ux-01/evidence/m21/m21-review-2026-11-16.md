## 3. Семантика (не менялась срезами M2/M2.1)

Каноническая семантика **GLOBAL default → CHAT override** (owner §0.1/§2.1/§2.3.1;
design §12.2/§12.5.1; `MAC-S2-TT-4`):

| GLOBAL | CHAT | Результат |
|---|---|---|
| ON | INHERIT | ON |
| ON | OFF | OFF |
| OFF | INHERIT | OFF |
| OFF | ON | **ON (только этот чат)** |

Static-модули (8: direct, factcheck, search, web, transcribe, video_summary,
media_download, checkup) — через `feature_gates.module_enabled`; shared (3: initiative,
character, random) — чат решает использование, общий пул/модель/планировщик живы;
`stories` — read-контур. Аварийные env-оси (`MCA_INTENTS_ENABLED`, `MCA_SELF_MODEL_ENABLED`,
`MCA_RANDOM_SOURCE_ENABLED`, `MCA_TEMPORAL_FACTCHECK_TOOL_ENABLED`,
`MCA_STORIES_VITRINA_ENABLED`) остаются отдельной осью и не подменяют сохранённый выбор.
