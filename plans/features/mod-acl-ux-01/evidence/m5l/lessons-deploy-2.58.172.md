# M5L / MOD-ACL-UX-01 — выкат 2.58.172: семантический контракт уроков (схема v46)

Запись о фактическом выкате `2.58.172` — релиза, на котором на прод попал
семантический контракт уроков (`lesson-strategy-contract.md`, FROZEN
09.11.2026): аддитивная схема v46, пороги подтверждений по классам,
свободные смысловые уроки из сервер-канонических шаблонов, гибридное
расписание «свежий поток + архив», временной ранг и аналитика контракта.

Артефакт фиксирует: что развёрнуто, чем развёрнутый SHA отличается от
ревьюированного кандидата, что произошло с БД при миграции `45 → 46`, какие
живые значения наблюдались после выката, арифметику пропускной способности и —
отдельным разделом — что этим доказательством **не** является.

## 2. SHA деплоя ≠ SHA ревью (и почему это не подмена)

Развёрнутый `bee14188` — релизный bump поверх одобренного кандидата
`c51933d0`: `APP_VERSION`, rolling-строка README, мета-док реестра параметров
и version-пины в тестах (27 файлов, 28 строк).

Проверка идентичности продуктового кода:

```
git diff --name-only c51933d0 bee14188 -- services handlers web
(пусто)
```

Единственное изменение в `config/` — строка `APP_VERSION = "2.58.172"`;
остальное — тесты-пины схемы и README. То есть живое поведение, снятое на
`bee14188`, относится к тому же продуктовому коду, который проверял Reviewer
на `c51933d0`. В карте `candidate_commit` = `c51933d0`, `deployed_commit` =
`bee14188` — два SHA осознанно разведены по разным полям.

## 5. Пропускная способность: арифметика

| Величина | Значение |
|---|---|
| Входящий поток | ≈ 2 218 сообщений/сутки |
| Проходов в сутки | 96 (tick 900 с) |
| Строк за проход (факт) | 100 = 2 активных чата × 50 |
| Дренаж за сутки | 96 × 100 = **≈ 9 600 строк/сутки** |
| Потолок при 6 чатах | 96 × 6 × 50 = **≈ 28 800 строк/сутки** |
| Свежий бэклог | **15 628** строк в одном чате, `deferred_chats = 0` |
| Чистый дренаж | 9 600 − 2 218 ≈ **+7.4 тыс. строк/сутки** |
| Ожидаемое закрытие бэклога | **≈ 2 суток** |

Вывод по узкому месту: ограничивает не число чатов (сейчас активны 2 из 6), а
потолок **50 строк на чат за проход**. При текущем потоке этого достаточно;
при росте числа активных чатов до 6 ёмкость вырастет втрое без изменения кода.

## 7. Чего этот артефакт НЕ доказывает

1. **Архивный курсор и покрытие архива.** Не созданы, потому что свежий
   бэклог ещё не разобран (`archive_skipped_fresh_backlog = 1`,
   `archive_watermark = None`). Условие наблюдения: после дренажа 15 628 строк
   (≈ 2 суток) должен появиться `archive_cursor:<chat>` в payload job,
   `archive_watermark` перестать быть `None`, а `archive_skipped_fresh_backlog`
   исчезнуть; курсор обязан пережить рестарт.
2. **Первое противоречие.** Ни один урок ещё не получил
   `temporal_rank × 0.5` и `recheck_required = 1`. Условие: два конкурирующих
   смысловых урока в одном `(scope_chat_id, scope_user_id, lesson_type)` с
   пересекающимся `semantic_scope_key` → старый ранг 0.5, статус и строка
   сохранены, эмитится `experience.lesson_contradiction`.
3. **Первое повторное подтверждение.** Инкремент `temporal_rank +0.1`
   (потолок 2.0) и рост `confirmation_count` только на новом `source_ref_id`
   не наблюдались. Условие: второй независимый эпизод того же правила.
4. **Применение урока в живом ответе.** `mca_lesson_applications` пуст,
   потому что после выката не было ни одного хода чата. Условие: живой ход с
   активным уроком → строка применения; Writer получает только
   `(lesson_id, recommendation, scope, temporal_rank)`; ложных
   `_forbidden_effects` — 0.
5. **Пять событий аналитики** из восьми: `experience.lesson_rejected`,
   `experience.lesson_contradiction`, `experience.archive_direction_selected`,
   `experience.archive_coverage`, `experience.stale_belief_flagged` — ещё не
   эмитировались, потому что не было соответствующих триггеров (нет
   отклонённого кандидата, нет противоречия, архив не начат, нет урока с
   рангом < 1.0).
6. **Эпик целиком.** `2.58.172` доказывает только срез M5L. Остальные срезы
   MOD-ACL-UX-01 (ACL M1, GLOBAL→CHAT M2, UI M3/M4A–C, EXP-FIX-08 M5B,
   production-proof M5C, live-acceptance M6) остаются `PENDING`; зелёный
   результат этого среза не является приёмкой эпика.

## 8. Наблюдения для backlog (не дефекты этого релиза)

1. `experience.fresh_stream_lag` эмитится с `reason_code = "fresh_stream_lag"`,
   которого нет в словаре кодов `services/mca_events.py`, поэтому в событии он
   отображается маркером `unmapped:18d14796`. Само событие полноценное:
   `usage_json` содержит `chat_id`, `lag_rows`, `cursor_rowid`, `threshold`.
   Это косметический пробел маппера, а не потеря события.
2. Два разных урока типа `failure_pattern` в разных чатах могут иметь один и
   тот же канонический текст рекомендации — это следствие сервер-канонических
   формулировок (текст зависит от `(lesson_type, rule_key)`, а не от чата) и
   не является утечкой между чатами: scope, доказательства и ранг у уроков
   свои. Наблюдение, не дефект.
