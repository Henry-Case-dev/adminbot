# 2.58.211 — ограничения и что осталось

## Границы релиза
- В релизе только **W2a**: клавиатура вкладок (`MAC-S5-198`), память вкладок
  и условный дефолт (`MAC-S5-OVW-01`), UI-часть «свежесть ≠ активность»
  (`MAC-AC-08`).
- **W2b/W2c не входят**: вкладка `history` по 6 `history_source`, rich-вкладки,
  зона «Расширенные», остальные 18 страниц, скрытие пустого Обзора
  (`MAC-AC-07`), разнесение tablist/tabpanel по APG (BACKLOG_ONLY).
- **Провайдер активности не регистрируется**: `last_activity_at=null` —
  штатный честный контракт (`Измерение не подтверждено`), а не дефект.

## MAC-AC-08
Кодом закрыта только freshness/activity-согласованность «каталог ↔ страница».
Наблюдение **живых permissions** (реальный второй аккаунт/роль) в этом релизе
не обеспечено — остаётся **W3** со ссылкой на `MAC-S10-16`; строка не
переводится в VERIFIED по stub-проверке.

## Известное поведение (не дефект)
- **К-5**: содержимое запомненной вкладки проверяется только когда данные
  активного scope загружены (`configItems` непусты). Иначе `setActiveChat`
  (он очищает `configItems` до ответа `/api/config`) ронял бы вкладку в дефолт
  на время смены чата, нарушая К-4/3 «страница не прыгает». Структурная
  невалидность (`m.tabs`/`_workspaceTabApplicable`) удаляется всегда.
- **`mod_embeddings`**: не входит в `WS_OVERVIEW_LIVE`, поэтому bare-адрес
  открывает `settings` (осознанный design→delta теста
  `mod_acl_ux_m4_module_params_test.js`, проверка Обзора сохранена через явный
  `/overview`).
- Явный выбор «Обзора» тоже запоминается (К-4/1): после клика/перехода на
  `/overview` bare-адрес откроет «Обзор», пока пользователь не выберет другой
  таб.

## Проверки после выката (агентами, не владельцем)

  schema 47 / pending=[], сохранность настроек.
- Живой TMA: дефолт вкладки, клавиатура, память после reload/смены чата,
  свежесть карточка ↔ страница. Локальный Playwright/Browser Use прогон
  (failures=0) **не заменяет** живой TMA.
