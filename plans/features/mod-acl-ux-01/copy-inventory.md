# MOD-ACL-UX-01 — copy inventory (M3, rev2.1, 2026-11-16)

**Назначение:** полный список пользовательских текстов «до → после» для всех 21 карточки,
разделов/вкладок, состояний и ошибок 401/403/404/503 (`MAC-S5-281`), плюс шапка каталога (§10).
Источник «до» — реально отрендеренный deployed `bca18c1e` (структура/тексты; значения stub, не
production) и его `web/index.html`/`web/app.js`. Источник «после» — `design-m3-2026-11-16.md` §7.
Тексты промптов, жанровый текст чекапа и сохранённые пользовательские значения **не изменяются**.

**Ревизия 2.1 (после ревью):** добавлены §10 (шапка каталога, фильтры, счётчик, пустота, загрузка)
и §11 (границы для «Статуса»/«Прав»); «до»-строки сверены с `index.html` (`Найти модуль…`,
`Загружаем каталог модулей…`, `Показано 21 из 21…`, `Есть проблемы`); `source` помечен атрибутом
`desired`; `can_*` — только `permissions.*`.

Обозначения: `—` — строки нет; `[T]` — только в «Технических деталях»; `[C]` — только на chat
scope; `[G]` — только на global scope; `[H]` — только при реальном источнике Истории (§2.4 design).

## 8. Технические детали (только disclosure)

Эти строки не показываются в основном UI (`MAC-S5-277`):

- `Ключ: <pg_key>`; `Env-ось: <ENV_NAME>`; `Gate: <feature>`;
- `Gate source: emergency_env | product_toggle | both`;
- `state.source: chat | global | default`; `global_source`;
- `reason_code`, `pending_restart`, `version`, `updated_at`, `chat_updated_at`;
- `observed_at`, `last_activity_at`;
- `permissions.can_read`, `permissions.can_edit` — единственное место прав (в `gate`/`state` их нет);
- `consent`, `conflict`;

В основном UI — только человеческие `Источник`, `Готовность`, `Причина`, `Измерение`.

## 9. Что сохраняется без изменений

- Термин **«чекап»** и жанровый текст чекапа (`MAC-S5-279`).
- Все пользовательские/авторские промпты, их тексты, ревизии и история версий.
- Существующие названия вкладок `HYBRID SUMMARY`, `LEGACY SUMMARY FALLBACK`, `Кластеризатор`,
  `Писатель`, `Стили обложки`, `Что бот видел`.
- Сохранённые значения `true/false`, отсутствие override = `INHERIT`; ни один просмотр не создаёт
  override.
- Формулировки владельца для Историй, Векторной памяти, Опыта, Случайности.
- Технические имена ключей/групп в API и БД; меняются только UI-подписи.

сон/последний вызов/бюджеты → аналитика/опыт; подписи периодов `24 ч`/`7 д`/`всего`/`сейчас`;
`Последний вызов: нет зарегистрированных данных` + checked-at; запрет псевдоконверсий) и §5
(Права: `Раздел → Модуль → Группа → Параметр`, `Только изменённые`, `Проверить доступ`,
наследование/override, 409 merge/сервер/повтор), плюс редактура `m3-design-freeze.md` §6
(`Общий режим: выключен (новые чаты наследуют)`, `Включён · работа ещё не подтверждена`,
`Сервис временно недоступен; последняя успешная проверка: …` и т.д.).

Что M3 добавляет и фиксирует дословно:

| Место | До | После |
|---|---|---|
| Раздел навигации | `Статус` | `Статус` (без изменений), route `#/status`, не часть каталога |
| Раздел навигации | `Доступы` (существующая поверхность) | `Доступы → Роли и права` страницей, route `#/access/roles` |
| Заголовок страницы прав | — | `Роли и права` |
| Подзаголовок страницы прав | — | `Настройка доступа к разделам и действиям.` |
| Кнопка истории изменений | — | `История изменений` |
| Кнопка проверки | — | `Проверить доступ` |
| Счётчики Status | `0` при 403/503/unknown | `Нет зарегистрированных данных` + причина/checked-at (frozen §4) |

M3 не создаёт для них второй инвентарь и не вводит новых квот/терминов.
