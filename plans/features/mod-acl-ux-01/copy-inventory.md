# MOD-ACL-UX-01 — copy inventory (M3, 2026-11-16)

**Назначение:** полный список пользовательских текстов «до → после» для всех 21 карточки,
разделов/вкладок, состояний и ошибок 401/403/404/503 (`MAC-S5-281`). Источник «до» — реально
отрендеренный deployed `bca18c1e` (структура/тексты; значения stub, не production). Источник
«после» — `design-m3-2026-11-16.md` §7. Тексты промптов, жанровый текст чекапа и сохранённые
пользовательские значения **не изменяются**.

Обозначения: `—` — строки нет; `[T]` — только в «Технических деталях»; `[C]` — только на chat
scope; `[G]` — только на global scope.

## 8. Технические детали (только disclosure)

Эти строки не показываются в основном UI (`MAC-S5-277`):

- `Ключ: <pg_key>`; `Env-ось: <ENV_NAME>`; `Gate: <feature>`;
- `Gate source: emergency_env | product_toggle | both`;
- `state.source: chat | global | default`; `global_source`;
- `reason_code`, `pending_restart`, `version`, `updated_at`, `chat_updated_at`;
- `observed_at`, `last_activity_at`;

В основном UI — только человеческие `Источник`, `Готовность`, `Причина`, `Измерение`.

## 9. Что сохраняется без изменений

- Термин **«чекап»** и жанровый текст чекапа (`MAC-S5-279`).
- Все пользовательские/авторские промпты, их тексты, ревизии и история версий.
- Существующие названия вкладок `HYBRID SUMMARY`, `LEGACY SUMMARY FALLBACK`, `Кластеризатор`,
  `Писатель`, `Стили обложки`, `Что бот видел`.
- Сохранённые значения `true/false`, отсутствие override = `INHERIT`; ни один просмотр не создаёт
  override.
- Формулировки владельца для Историй, Векторной памяти, Опыта, Случайности.
- Технические имена ключей/групп в API и БД; меняются только UI-подписи.
