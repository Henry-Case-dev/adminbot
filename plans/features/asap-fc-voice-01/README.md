   вердикт» (строка 438). Ни полемики, ни разбора логических дыр, ни адаптивной

2. **Отдельная секция «Критический разнос» противоречит новому контракту.**
   Она обязательна по дизайну: директива и заголовок
   (`factcheck_prompts.py:484-493`), семантический gate
   (`:515-589`), разделение и публикация (`factcheck_renderer.py:184-230`),
   блок в трёх сборках (`factcheck_service.py:1516-1520,1580-1583,2299-2306`).
   Новый контракт требует вплетать критику в рассуждение и **не** иметь
   шаблонной секции (§2 `Do not perform a sterile "assessment"…`, §7-11).
   При этом секция — единственный детерминированный guard против выдуманного
   опровержения; при её снятии нужен другой носитель этого запрета (см. §6).
3. **`_points`/`_MAX_POINTS` уже сняты** (`P0-FACTCHECK-CORRECTIVE §7.4`):
   в `services/factcheck_renderer.py` этих символов нет. `_MAX_BOUND_PARTS`

   которое применяется к каждой части (`:136,282-286,443`) — то есть каждая
   часть разбора обрезается независимо от содержания.
4. **Композиция ответа жёсткая**: `headline → body → «Критический разнос» →
   «По утверждениям» → «Источники»` (`factcheck_renderer.py:398-476`), причём
   блок привязок повторяет содержание тела (§7-14).

   экранируется (`:415-416`) при `parse_mode="HTML"` — Markdown модели

   решает это как plain-текст + `- ` перечисления, без Markdown→HTML.

## 4. Волны и порядок (dependency graph)

```

  └── FC-VOICE-CONTRACT ── FC-WRITER-PATH ──┬── FC-RENDERER
```

Почему P0 сериализован по `factcheck_service.py`, `factcheck_prompts.py`,
`prompt_style_blocks.py`, `prompt_registry.py`, `prompt_migrations.py`: правка
канона, сборки и лестницы миграций в разных руках даёт рассогласованный
effective prompt. Гейт проверяет непересечение write-scope только для слайсов
без отношения предок/потомок; пары `FC-RENDERER` / `FC-EVIDENCE-DEPTH` /
`FC-L1-PROFILE` файлов не делят и после P0 идут параллельно.

`FC-L1-PROFILE` зависит от `FC-WRITER-PATH`, потому что делит
`direct_chat_service.py` (делегат `compose_speech_system`) и общие
`prompt_registry.py` / `prompt_migrations.py` (порядок A → B зафиксирован

`direct_l1.py` / `direct_chat_service.py` полосой ER-08-RC / 2.58.148 —
эти файлы помечены `SERIALIZE`.
