## Критерии приёмки
- Для каждого класса сбоя из п.0/п.5/п.6/п.10 в логе есть запись с причиной (не только имя класса).
- Тело ответа внешнего API логируется усечённо и без секретов; egress-тест зелёный.
- Уровни: штатный фоллбэк — WARNING/INFO, реальный сбой — ERROR.
- pytest зелёный; логирование не добавляет сетевых вызовов и не тормозит горячий путь.

## Риски
- **R1 (High):** утечка секрета в лог через payload → маскирование + тест egress (T-2197/T-2202).
- **R2 (Medium):** раздувание логов (journald) → лимит длины и уровни (T-2196/T-2197); согласовать с retention в `disk-space-audit-retention-round1024`.
- **R3 (Medium):** логирование сырых текстов сообщений нарушает приватность → не писать тела пользовательских сообщений.
- **R4 (Low):** шум на ожидаемых фоллбэках → уровни INFO/WARNING.
