## 6. Две живые несогласованности после 2.58.191 (только факты, без правок)

**(а) «последняя попытка 16:42» против `last_attempt.at = 16:27:40Z`.**
Это разные поля разных механизмов, не сдвиг часовой зоны и не пропавшие данные:

| Источник | Значение |
|---|---|
| payload 2.58.191, блок `text_initiative.last_attempt` | `at=1794414460` = **16:27:40Z**, `stop_stage=lease_held`, `run_id=init:-1004482340693:20261111:9926b6d84a` |
| payload 2.58.191, блок `meme.last_attempt` | `at=1794414496` = **16:28:16Z** |
| payload 2.58.191, `text_initiative.readiness` | `next_eligible_at=16:41:54Z` |
| БД `meme_initiative_attempt` | попытки 16:27:40Z (`…8fae1f157347`) и далее непрерывно; в минуте **16:42:00–16:42:59Z — 14 строк** (7 попыток, `daily_quota_reached`) |
| БД `mca_events` / `mca_bot_outputs` в 16:42Z | 4 события / 0 отправок |
| БД по текстовой попытке `init:…9926b6d84a` | 0 строк событий (ранний гейт событий не пишет — ожидаемо) |

Итог: 16:42 — это попытка **мемов** (или, для текста, расчётная граница
`next_eligible_at=16:41:54Z`), а 16:27:40Z — попытка **текстовой** инициативы.
Разница 14 мин 14 с не является часовым поясом (смещения зон кратны 15–60 мин),
оба значения пришли одним и тем же ответом API. Отдельно: в архивном
`release-258191/live-diagnostics-2.58.191.json` метка `captured_at_utc=16:44Z`
не соответствует содержимому (значение мемов `16:28:16` не могло быть самым
свежим в 16:44Z) — это дефект метки времени того архивного артефакта, не
продукта.

**(б) «Последних действий в журнале нет» при существующей попытке.**
Строка не имеет отношения к журналу и не фильтруется ни по окну, ни по чату,
ни по механизму:

- источник строки: `web/index.html:1886-1888` (обзор инициативы) и
  `1035-1042` (шапка модуля) — ветка `v-else` выражения
  `moduleLastEventLine(workspaceModule)`;
- причина пустоты: `moduleLastEventLine` (`web/app.js:22906`) возвращает `''`
  для `mod_initiative`, потому что `moduleHealthView` знает только
  `mod_vision`/`mod_sleep`/`mod_experience`, а `moduleScopeErrorFor` для
  инициативы пуст;
- реальность журнала на том же сервере и чате: `GET /api/initiative/publications`
  → 327 строк за 7 дней, вкладка отрисовала 40 строк, и у самой вкладки
  **другой** текст пустоты — «За выбранный период попыток нет.» (`index.html:3163`).

То есть строка — это подпись шапки модуля, которая никогда не читает ни журнал
попыток, ни его API.
