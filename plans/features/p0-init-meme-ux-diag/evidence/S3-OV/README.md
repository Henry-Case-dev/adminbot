# S3-OV — «Обзор: две карточки с пятью осями» — доказательства

Срез: `S3-OV` эпика `p0-init-meme-ux-diag`. Ветка `init/meme-axes`.
Поверх S1-AXES/S2-ID (`4c59a483`) исправлены пять блокеров независимого ревью
на `d58fbb56`; база для сравнения прогонов — прод-релиз 2.58.188 `c087253d`.

Контракт: `architecture.md` §4/§5, строки `P0IM-OV-CARDS`,
`P0IM-OV-FALSEOFF`, `P0IM-OV-PERCHAT-CAUSE`.

## Что делает обзор

Две равнозначные карточки читают ПЯТЬ осей, посчитанных сервером
(`configuration` / `health` / `readiness` / `last_attempt` / `last_delivery`),
и переводят их в бытовые фразы. Клиент не собирает «включено» из мастер-флага.
Ответ диагностики/настроек применяется только при совпадении `scopeEpoch`
И `payload.chat_id` с выбранным чатом.

## Исправленные блокеры (наблюдаемые строки «до → после»)

1. **Смена чата не чистила карточки.** Было: под шапкой «Чат B» карточка
   показывала снимок чата `-100999` («подтверждено · … · чат -100999 ·
   сообщение 555444»). Стало: `setActiveChat` сразу очищает карточки, журнал,
   фокус попытки и черновик (`iniResetChatScope`), а `memeDiagView` не отдаёт
   снимок, у которого `chat_id` ≠ выбранному чату. На экране — пустое
   состояние до прихода данных ЭТОГО чата.
2. **Истёкший приоритет ручного `/meme` рисовался живым блоком.** Было:
   «отложено: приоритет ручного /meme», «до 17.10.2026, 13:15:00» при
   `manual_priority_active=false`. Стало: полоса показывается только при живом
   дедлайне (флаг бэкенда авторитетнее; без флага — сравнение с серверным
   `checked_at`, а не с часами браузера).
3. **Время без названного основания.** Было: «не раньше 17.10 05:25» при
   пустом `next_basis`. Стало: «время не называется: основание срока не
   записано (штамп 17.10 05:25)»; «не раньше» печатается только вместе с
   основанием.
4. **Попытку нельзя было открыть из карточки.** Стало: кнопка «Показать
   попытку →» в каждой карточке ведёт в существующую «Диагностику» с фокусом
   на ЭТОЙ попытке (`attempt_id` = `<kind>:<job_id|trace_id>`, чат — в
   `X-Chat-Id`). Новых эндпоинтов и хранилищ нет.
5. **Голые коды и схлопнутая доставка.** Было: `silent`, `sent`, «молчание ·
   остановилось: решение», одно «неизвестно» для двух разных состояний,
   «сообщение 0». Стало: молчание — «бот решил промолчать» (это решение, не
   остановка), `sent` — «отправлено», неизвестный код — «код: …»; в журнале
   три разных строки: «доставлено · сообщение N» / «доставка неизвестна» /
   «отправки не было»; `message_id = 0` считается отсутствующим.

## P0IM-OV-HEADER: «этот чат / другой чат / сравнить чаты»

Компактный переключатель в шапке обзора (никакой новой секции): три
состояния, второе читает ДРУГОЙ чат тем же эндпоинтом со своим `X-Chat-Id`.

| Состояние | Что на экране |
|---|---|
| `self` | карточки выбранного чата (как раньше) |
| `other` | те же две карточки, но оси ВТОРОГО чата: «Показан другой чат: **Чат B** — его собственные оси, только чтение. Время в UTC (пояс другого чата здесь не читается)». Ссылки на попытку нет: журнал принадлежит выбранному чату |
| `compare` | два блока (текст, мемы), в каждом — пять осей в двух колонках, подписанных «Чат A» / «Чат B». Время в обеих колонках UTC, значения не складываются и не усредняются; подсветка отмечает только РАЗНЫЕ значения |

Деградация: при одном доступном чате переключателя нет вовсе (проверено:
`switch=false`, `compare=false`, данные чата на месте).

Устаревшие ответы: `iniPeek` применяется только если не сменились
`iniPeekSeq`, `scopeEpoch` и `activeChatId`, цель всё ещё «другой чат», и
`payload.chat_id` равен запрошенному; смена чата/режима чистит снимок сразу.

**Замеры состояния `compare` (живой браузер, выбран чат «Чат A»):**

| Вьюпорт | hScroll | Обрезано | За экраном | Файл |
|---|---|---|---|---|
| 390×844 | 0 px | 0 | 0 | `compare-390x844-top.png`, `compare-390x844-rows.png` |
| 1536×960 | 0 px (−15 = запас) | 0 | 0 | `compare-desktop-1536x960.png` |

Фактический текст сравнения (мемы, 1536×960):
`Сейчас` — «может сработать сейчас — ничего не мешает» / «ждёт: кулдаун,
осталось 1 ч 30 мин»; `Дальше` — «точное время не назначено…» / «не раньше
15.01 09:35 UTC (по собственному кулдауну)»; `Последняя отправка` —
«подтверждено · 15.01 08:03 UTC · чат -100500 · сообщение 4321» /
«подтверждено · 15.01 07:05 UTC · чат -100501 · сообщение 987654».

## Принятые пробелы

* Квота мемов по-прежнему берётся из настроек чата и показывает `reset` в
  ISO-виде — существующая формулировка вне пяти осей.
* Сравнение двух чатов одним экраном (§4: «два независимых payload, без
  безымянного агрегата») — отдельный срез: это новая секция, а срез S3-OV
  запрещает новые секции. Из карточки открывается попытка ЭТОГО чата.
* Пояс чата в стенде не задан (в стабах `/api/config` пусто), поэтому снимки
  показывают честный UTC; в проде пояс читается из `limits.chat_timezone`.
