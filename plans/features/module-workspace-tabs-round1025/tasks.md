## Верхнеуровневые задачи (детализация при старте)
- [ ] Рабочее пространство модуля §46: отдельная страница (например Модули → Проверка фактов); вкладки Обзор/Основные настройки/Синтезатор/Вербализатор/Модели/Лимиты/Тестирование — **только применимые**; генеральный тумблер вверху из **того же** store (F4); все настройки модуля доступны из его workspace; API-ключи не копировать в модуль.
- [ ] Раздел ИИ §47: внутренние страницы — Библиотека промптов, Модели и подключения, Личность и стиль, Имена и алиасы, Умный кэш; не превращать в свалку; настройки памяти → «Память», настройки функции → «Модули».
- [ ] Гибридная библиотека промптов §48: «один промпт — один источник», два маршрута (Модули → … → Синтезатор; ИИ → Библиотека промптов → … → Синтезатор) открывают **один объект**, без независимых копий; desktop (дерево/редактор/описание+переменные+параметры), mobile (список → полноэкранный редактор); **не прятать единственное textarea в аккордеон**; исходный текст промптов сохранять без изменений.
- [ ] Модели и подключения §49: группы (генерация текста/распознавание речи/видео/эмбеддинги/фоновые задачи/изображения); карточка (название/назначение/основная/резервная модель/статус/Проверить/Настроить); сохранить провайдеры/base_url/model/ключи/fallback/тайм-ауты; не менять сохранённую модель при открытии формы.
- [ ] UI прямого чата §84: Модули → Ответы в чате → Модели; desktop — две карточки рядом (L1 Синтезатор / L2 Вербализатор), mobile — вертикально; каждая: провайдер/модель/источник/статус/Проверить; без горизонтального скролла.
- [ ] UI Саммари §85: Модули → Сводки чатов; вкладки Обзор/Подготовка сообщений/Кластеризатор/Писатель/Модели/Лимиты/Тестирование; промпты также через ИИ → Библиотека промптов (один объект).
- [ ] Канон промптов — новый канон + `PREV_*`-слепок + идемпотентная миграция (**ADR-1013-3**) при переносе текстов.
