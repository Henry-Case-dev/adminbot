## Цель
Дать LLM-Синтезатору однозначный указатель на сообщение-триггер: при рендере истории чата в текст для LLM сообщение-команда помечается визуальным тегом
`<<< [ЭТО ТВОЯ ТЕКУЩАЯ КОМАНДА]`, а промпт Синтезатора жёстко запрещает пересказывать этот запрос как событие диалога.
**Физически вырезать сообщение-команду из истории запрещено** — таймлайн и причинно-следственные связи сохраняются.

## Контекст / что уже есть
- Два рендерера истории: `services/summary_xml.py:53` (`XmlGroundingBuilder.build`, `<chat_history>`/`<message>` на `:100`) и `services/canonical_context.py:242` (`format_context_item`; запись `chat_history` — `:105` `CONTEXT_POINTS`).
- Точки сборки контекста: `services/summary_generator.py`, `services/direct_chat_service.py`, `services/factcheck_service.py`.
- Источники промптов Синтезаторов: `services/summary_prompts.py` (`SUMMARY_EDITOR_SYSTEM_PROMPT`), `services/chat_prompts.py` (`CHAT_SYSTEM_PROMPT`), `services/factcheck_prompts.py` (`FACTCHECK_SYSTEM_PROMPT`).
- Канон-контур: `services/prompt_migrations.py` + `plans/docs/canon/**` + `PREV_*`-слепки (ADR-1013-3, атомарная миграция).

## Новое (объём фичи)
- Константа-маркер (единый токен) + поиск сообщения-триггера по `message_id`.
- Проброс `trigger_message_id` от вызывающих точек в оба рендерера.
- Правило в промпты Синтезаторов (summary/direct/factcheck): помеченное сообщение — инструкция, не событие чата.
- Обновление байт-эталонов обоих рендереров.

## Критерии приёмки
- Помеченное сообщение идентифицируется однозначно по `message_id`; при отсутствии id поведение байт-в-байт прежнее.
- Промпт-правило присутствует в трёх Синтезаторах; канон-миграция атомарна и обратима.
- Таймлайн истории не изменён (маркер не удаляет и не переставляет сообщения).
- Полный pytest — 0 failed.

## Риски
- **R1 (High):** маркер ломает байт-тесты обоих рендереров истории → обновить эталоны (T-2103).
- **R2 (Medium):** «маркер» просочится в финальный пользовательский текст → промпт-правило + антиэхо-тест (T-2101/T-2104).
- **R3 (Medium):** неоднозначность, если в окне несколько сообщений с одинаковым id/копий → поиск по `message_id`, тест на дубль (T-2098/T-2104).
- **R4 (Medium):** канон-атомарность (ADR-1013-3) → один коммит (T-2102).
- **R5 (R17/R18):** сырая история/секреты в логах/отчётах → только коды/числа.
