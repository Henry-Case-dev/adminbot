# W3 — итоговый отчёт (asap-speech-arch, §9.2)

Краткая сводка; подробный разбор и сырые данные — `analysis.md` / `protocol.md` / `raw-*.json` в этой папке.

- **Статус:** завершено на реальных provider-вызовах (apinet deepseek-v4-flash), 45 вызовов (ровно бюджет), 0 сообщений в Telegram, serialization перехвачена (FakeBot/spy).
- **Payload:** ровно эффективная ветка Expression доезжает до модели в каждом режиме, system-sha различаются; L1-канон f8ab20121c02, L2 temp=0.7 неизменны между режимами.
- **Поведение:** off — 0/5 мата в собственной речи (из-за модели, не sanitization); frequent — мат в собственной речи присутствует и доходит до «отправки» без вырезания; occasional — в инварианте «примесь без доминирования» (статистика различия с off не набрана); точность (465 м/с), серьёзный регистр, отсутствие повторов — подтверждены; сарказм/абсурд сохранены (ДОП-1).
- **Сериализация:** raw==sent 10/10 сопоставимых ходов.
- **Ограничения (честно):** выборка мини (бюджет 45 = ровно лимит; полный 3×3×10 не покрыт), инициативный текст не снят (L1 выбирала silent/react), s7-цитата с матом не выполнена (P0D-QUOTED остаётся PENDING), реальный Telegram-транспорт не задействован.
- **Биндинг:** EVAL-EGRESS → VERIFIED; P0D-INVARIANTS → VERIFIED; P0-A/P0-B (live-половины, factory+active+реальные L2-вызовы) → VERIFIED; EVAL-MODES / REQ-PROOF-EFFECT / INIT-48H / P0D-QUOTED — остаются честно PENDING (живое/полная матрица).
