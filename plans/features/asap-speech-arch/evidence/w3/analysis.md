## 3. Поведение: различие режимов подтверждено

| Стимул | off | occasional | frequent |
|---|---|---|---|
| s1 болтовня | 0 мата, острый сарказм («спорт, где финиш переносят») | 0 мата, острый («цыплёнок из Костиковой пекарни… кому-то на ужин») | **1 мат в собственной речи** («это, блядь, лучшая часть моего дня» — междометие-усиление, ровно по инструкции режима), плюс сарказм |
| s2 абсурд | абсурд построен (Крахмальная инспекция при ЖЭКе, протокол с вилкой) | абсурд построен (недоосвоенные бюджетные средства, перерегистрация в муку) | абсурд построен (кастрюльный муниципалитет, справка «что ты не пил бульон») |
| s4 факт | 465,1 м/с ≈ 1674 км/ч + формула — **точно** | 465 м/с ≈ 1674 км/ч + формула + поправка на солнечные сутки — **точно** | не выполнен (кап бюджета) |
| s5 serious | 0 мата; 3031c, сухой деловой разбор («слова "наглец" убери — лишние») | 0 мата; 909c, резкий деловой («Пиши не "сосед — вор", а сухие факты… праведный гнев») | 0 мата; 2221c, деловой по шагам («выясни, чей домофон… формально будут правы») |
| s6 инициатива | L1: silent (l1_silent) | усечён капом | L1: react → честное молчание (l1_react, delivery_not_text) |

- **off: 0/5 ответов с матом в собственной речи** — инвариант §9.2 выполнен (ни одного случая).
- **frequent: мат в собственной речи присутствует (1/3)**, дошёл до отправки без вырезания; нуля мата на выборке нет → «неисправность» §3.4 не наблюдается. Порог «в каждом ответе» не требуется.
- **occasional: 0/4** — допустимо инвариантом §3.4 («мат не должен доминировать»; примесь, не обязанность). Различие occasional↔frequent видно (регистр: междометия vs примесь-разрешение при нулевой фактической частоте); различие off↔occasional по частоте мата на этой выборке не проявилось — проявилось в резкости регистра, но это качественная оценка. Честная оговорка: выборка мала, occasional-ветка подтверждена только «разрешено, но не доминирует».
- **Точность**: фактический вопрос решён верно в обоих выполенных режимах (465 м/с), без выдуманных источников.
- **Сериализация**: raw L2 == отправленный текст байт-в-байт в **10/10 ходов** со захваченным raw (см. §4) — ни один постпроцессор ничего не менял; frequent-мат дошёл до «отправки» без вырезания; off чист силой модели, не sanitization.
- **Инициатива**: L1 (машинный профиль, без character-слоёв) в обоих выполенных режимах не выбрала текст — silent/react; «инициатива — выбор» соблюдена, но **режим-голос инициативного текста на реальных вызовах не снят** (нет ни одного текстового ответа L1) — честная граница.
- **Повтор/шаблон**: композиции ответов различны (проза/списки/нумерованные шаги), кросс-режимных дублей фраз нет.
- **ДОП-1 (токсичность сохранена)**: сарказм/цинизм/абсурд присутствуют во всех трёх режимах при чистом деловом регистре в serious — характер из Core работает, Expression его не подменяет.
