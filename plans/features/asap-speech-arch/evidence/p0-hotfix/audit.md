# P0 HOTFIX: аудит речевых/аналитических слоёв (read-only)

## Главная причина

Запросы «Я злобный?» / «Ринтаро злобный?» уходят в **функциональный анализ пользователя**, а не в обычный чат:
- `services/direct_chat_service.py:4453-4459` — маршрутизация в `analysis` по маркерам «проанализируй / что думаешь / злобный»;
- `services/chat_prompts.py:1109-1139` — `ANALYSIS_SYSTEM_PROMPT`: «подробный психологический портрет», «эмоциональные триггеры», «архетип», «динамика», «рекомендации», **«не менее 4 абзацев»**;
- `services/chat_prompts.py:1145-1170` — `ANALYSIS_USER_TEMPLATE` с обязательными блоками «профиль / архетип / рекомендации»;
- `services/direct_chat_service.py:3845-3860` — Writer получает анализ как пакет с требованием «сохрани структуру»;
- `services/lore_prompts.py` / `summary_prompts.py` L2 — причинная история, «эпичность», импровизация; влияет на исторические экскурсы.

Короткие BASE/HUMOR/LENGTH сами по себе не решат проблему, пока analysis-промпт заказывает эссе на 4+ абзаца.

## Точки замены

1. `chat_prompts.py:1109-1139` — заменить analysis-промпт на принцип: сразу понятный вывод; релевантные наблюдения; без хроники/психологического эссе/стендапа; подробно только по запросу; без жёсткого шаблона; шутки/мат/подколки допустимы.
2. `chat_prompts.py:1145-1170` — убрать обязательные «профиль/архетип/рекомендации»; передавать конкретный вопрос и доступные наблюдения.
3. `direct_chat_service.py:3845-3860` — разрешить Writer сжать/перестроить анализ, не пересказывать все блоки и не сохранять структуру любой ценой.
4. `chat_prompts.py` BASE/HUMOR/LENGTH/FACTUAL и `mca_expression.py` FREQUENT — заменить на точные тексты 25.10; OFF/OCCASIONAL сохранить.
5. Core не переписывать: только убрать конкурирующие оперативные инструкции, если они дублируют Expression/Style. Активный Core — owner-custom (`a37678237533`), проверить payload, не файл.
6. L2/lore/self-echo/provenance — см. `memory-provenance.md`.
