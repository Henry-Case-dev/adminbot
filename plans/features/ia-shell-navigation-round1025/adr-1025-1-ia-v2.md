# ADR-1025-1 — Новая информационная архитектура и app shell (IA v2)

- **Статус:** Proposed → (после реализации) Accepted
- **Дата:** 2026-09-20
- **Раунд:** 10.25, фича **F1** (`ia-shell-navigation-round1025`), Эпик 1
- **Связанные:** ADR-1018-6 (nav-матрица), ADR-1024-13 (доставка `ui_flags`), ADR-001 (route-driven «Доступы»), ADR-1016-2 (self-host/CSP), ADR-1024-9/10/11/12 (паттерн env-only `ClassVar` + `ui_flags`)
- **Затрагивает:** `services/param_catalog.py` (nav-метаданные), `config/settings.py`, `web/api/routes.py`, `web/app.js`, `web/index.html`, `web/static/app.css`, `web/static/telegram-init.js`, маркер-тесты
- **ТЗ:** `plans/current_task.md` §4–§7, §68, §70, §71, §79, §116, §117

---

## 1. Контекст

Текущий мини-апп — **плоская навигация**: верхняя полоса из 6 равнозначных пунктов (Статус, Справка, Модули, ИИ, PERMsoc, Доступы), где «ИИ» фактически смешивает три разные сущности (провайдеры/промпты, память/лор/отношения, кэш/имена), а PERMsoc визуально стоит рядом с глобальными разделами, хотя является **локальным** пространством.

Исторически это зафиксировано «menu-freeze» раундов 10.20/10.21 маркер-тестами (`test_frontend_tab_mapping`, `test_webapp_nav_disclosure_ui`, `test_round106_ia_smoke`, `NAV_ORDER`/`TAB_NAV`/`NAV_ITEMS`), чтобы защитить эталон от дрейфа. Для раунда 10.25 ТЗ §4 **явно задаёт новую IA** и прямо **снимает заморозку**: раздел «Память» выделяется отдельно, PERMsoc остаётся локальным (не в глобальных настройках), «Сводка» переименовывается в «Аналитику» и открывается из Статуса, конкурирующая главная «Обзор» запрещена.

Одновременно §6/§7 требуют **раздельных shell’ов**: desktop (sidebar 232 + header 64) при ≥1200 px и mobile (нижняя навигация, без горизонтальной полосы из 7 вкладок) при <768 px.

Дополнительные факты (10.20-UI-rework / 10.21 / 10.22 F2): «headless ≠ Telegram WebView», «объявлено готово, но визуально провалено» — значит закрывать F1 по отчёту нельзя; нужна реальная Chromium-проверка (F10).

## 2. Решение

### D1. Принять новую IA §4 (4 админ-раздела + публичные + локальный PERMsoc)

```
Публичные:   Статус (стартовая, #/), Справка (#/how)
Админ:       Модули (#/modules), ИИ (#/ai), Память (#/memory), Доступы (#/access)
Локальное:   PERMsoc (#/permsoc)
```

- **Статус** — единственная главная и стартовая страница. Отдельного «Обзора» **нет**.
- **Память** — новый отдельный nav-раздел; из «ИИ» уезжают `memory_rag`, `chat_lore`, `relations`.
- «ИИ» сохраняется: промпты, модели и подключения, личность, имена, умный кэш.
- **PERMsoc** — локальный; в глобальные настройки не переносится.
- **«Сводка» → «Аналитика»** (label), открывается из Статуса; наполнение — F6.

### D2. Реализовать IA через nav-метаданные, без изменения каталога

- Δ `ParamSpec`/`GROUPS` = **0**; Δ DDL = **0**.
- В `services/param_catalog.py`: добавить `NAV_MEMORY="memory"`, `NAV_TITLES["memory"]="Память"`, `NAV_ORDER=(modules, ai, memory, permsoc)`; `TAB_NAV`: `TAB_MEMORY_RAG/_CHAT_LORE/_RELATIONS → NAV_MEMORY`.
- Фронтовое зеркало `NAV_GROUP_ORDER/TITLES` (тест паритета) синхронизируется тем же коммитом.
- API `GET /api/access/param_permissions` подхватывает изменение автоматически (строит `nav/nav_title/nav_order` из этих констант).

### D3. Hash-роутинг — канонический дерево + legacy-алиасы

- Канонические маршруты (см. spec §4.1). `#/memory`, `#/memory/rag`, `#/memory/lore`, `#/memory/relations`.
- `tabToRoute` даёт `memory_rag → #/memory/rag` и т.д.; `#/memory` — hub-корень (depth 0), подстраницы — дети (`ROUTE_PARENT`), чтобы TMA `BackButton` работал.
- **Legacy-алиасы** `#/ai/memory → #/memory`, `#/ai/lore → #/memory/lore`, `#/ai/relations → #/memory/relations` (+ уже существующие). Старые ключи остаются и в `ROUTE_TO_TAB` (валидность), и в `ROUTE_ALIAS` (`replaceState` в канон).
- Мусорный/неизвестный hash → `#/` без падения (`normalizeRoute → null → initialRoute`).

### D4. SUPERSEDE menu-freeze раундов 10.20/10.21

Снимаются инварианты «navbar = ровно 6 пунктов», «sidebar запрещён», «`NAV_ORDER` = 3 раздела». Соответствующие маркер-эталоны **обновляются атомарно** с кодом:

- Backend: `test_frontend_tab_mapping.py` (`test_nav_order_and_titles`, `test_tab_nav_helper`), `test_param_catalog.py` (счётчики — остаются равны, но проверяются как инвариант).
- Frontend-маркеры «6 пунктов / нет sidebar»: `test_webapp_parity_smoke.py`, `test_webapp_hubs_matrix_ui.py`, `test_webapp_round1020_ui.py`, `test_webapp_ui_rework_round1020.py`, `test_webapp_round108_ui.py`, `test_webapp_nav_disclosure_ui.py`, `test_round106_ia_smoke.py`.
- JS: `routing_test.js`, `round1020_ui_test.js`, `round1021_ui_audit_test.js`.

**Правило атомарности:** код + обновлённые эталоны — в одном коммите/цикле. «Подгонка эталонов» (ослабление ассертов вместо отражения фактической IA) запрещена (Scanner 10.23/10.24).

### D5. Kill-switch `IA_V2_ENABLED` (env-only `ClassVar`, default ON)

- Паттерн ADR-1024-13: `ClassVar` в `config/settings.py`, вне `param_catalog`, доставка через `GET /api/me.ui_flags` (только bool).
- Фронт: computed `iaV2 = this.uiFlag('IA_V2_ENABLED')` (default `true`).
- **OFF → прежний navbar байт-в-байт.** Для этого legacy-константы `NAV_ITEMS`/`HUBS` и разметка `.navbar-band` **сохраняются литерально неизменными**; `navItems`/`hubCards` ветвятся по `iaV2`. Sidebar/bottom-nav при OFF не рендерятся.
- Возврат ручки: env `IA_V2_ENABLED=true` или `git revert`. Тест обоих состояний обязателен (иначе флаг декларативен — урок 10.22/10.23).

### D6. Раздельные shell’ы (§6/§7) и адаптивность (§70)

- Breakpoints: `320–767 mobile`, `768–991 tablet`, `992–1199 compact`, `≥1200 desktop`.
- Desktop ≥1200: `<aside class="app-sidebar">` ≈232 px (Статус, Справка, разделитель, Модули/ИИ/Память/Доступы, внизу отдельно PERMsoc), header ≈64 px, контент; формы 1200–1440, широкие графики шире, длинные textarea не на 2560.
- Mobile <768: компактный header, селектор области под заголовком (F3), одна колонка, `.bottom-nav` (админ: Статус/Модули/ИИ/Ещё; пользователь: Статус/Справка), шторка «Ещё» (Справка/Память/Доступы/PERMsoc/Профиль). **Никакой горизонтальной полосы из 7 вкладок.**
- Без горизонтального скролла страницы; touch ≥44×44; `container queries` для компонент-зависимых раскладок.

### D7. TMA-интеграция

Расширить `web/static/telegram-init.js`: `BackButton` (show/hide/onClick), `viewportStableHeight`, `safeAreaInset`/`contentSafeAreaInset` → CSS-переменные. CSP-safe, без inline.

### D8. Сохранность — по построению

- Δ каталога=0, Δ DDL=0, API аддитивен; UI не пишет при открытии форм; никаких новых дефолтов/скрытых миграций.
- Доказательство: baseline-фикстура (`sorted(pg_key)`, `{group_id: tab_id}`, счётчики) + тест равенства множеств (`test_ia_inventory_round1025.py`).
- Виджеты Статуса и логи сохраняются; PERMsoc локален; Справка не меняет тексты/стиль; RBAC не меняется.

## 3. Порядок миграции (фазы)

1. **Wave 0 (F8):** инвентарь, карта виджетов, бэкап, freeze baseline-фикстуры.
2. **Фаза A (backend nav):** `param_catalog` nav-метаданные + атомарные backend-тесты.
3. **Фаза B (флаг/доставка):** `IA_V2_ENABLED` + `ui_flags` + тесты.
4. **Фаза C (shell/IA/роутинг):** `app.js`/`index.html`/`app.css`/`telegram-init.js` + атомарные фронт-тесты + новые тесты F1.
5. **Фаза D (проверка):** JS-гейты, `pytest`, реальный Playwright/Chromium §71, OFF/ON, скриншоты.
6. **Фаза E (передача):** карта «старые→новые экраны»; бэкап сохраняется до утверждения владельцем.

Ступени общих файлов: `services/param_catalog.py`: **F1 → F8 → F4/F5/F7**; `web/**`: **F1 → F2 → F3 → F4 → F5 → F6 → F7 → F11 → F9 → F10**.

## 4. Последствия

### Положительные
- Понятная IA: публичное / административное / локальное; «Память» перестаёт быть спрятанной внутри «ИИ».
- Desktop получает полноценный shell; mobile — нативную нижнюю навигацию вместо сжатого desktop.
- Матрица прав автоматически группируется по новым разделам.
- Безопасный откат (kill-switch + `git revert`) без потери данных.

### Отрицательные / издержки
- Ломается «menu-freeze» → требуется атомарное обновление ~13 тестовых файлов (учтено).
- Введён новый класс сущностей — desktop sidebar (ранее запрещён). Осознанно по §6.
- Некоторое дублирование констант (legacy + V2) на время переходного периода — снимается после стабилизации.

### Ограничения
- F1 **не** улучшает визуал (Liquid Glass — F2) и **не** переделывает состав виджетов Статуса (F11).
- F1 **не** реализует логику селектора области (F3), только место под него в shell.
- Наполнение «Аналитики» и ExecutionGraph — F6.

## 5. Рассмотренные альтернативы

| Альтернатива | Почему отклонена |
|---|---|
| Оставить плоские 6 пунктов, добавить «Память» седьмым | Прямо нарушает §4/§6/§7; «Память» должна быть подразделом админ-навигации, а не равноправной вкладкой |
| Ввести vue-router | Нарушает zero-build/CSP-инвариант; существующий hash-роутер достаточен |
| Полный новый набор констант без legacy | Потеря быстрого OFF-отката «байт-в-байт»; kill-switch стал бы декларативным |
| Перенести PERMsoc в глобальные настройки | Прямой запрет §4/§60 |
| Создать главную «Обзор» | Прямой запрет §4 (конкурирующая главная) |
| Переименовать hash `#/oversight` → `#/analytics` как breaking | Ломает стабильные deeplinks/тесты без выгоды; меняем только label |

---

## 6. Инварианты (не нарушать)

1. Δ `ParamSpec`/`GROUPS`/`REGISTRY` = 0; Δ DDL = 0.
2. Ни одно значение/локальное переопределение/ключ/промпт/право не теряется.
3. `status`/`info` доступны всем; остальные — по серверному RBAC.
4. CSP `script-src 'self'`: без inline-скриптов/стилей (гейт `vue_mount_test.js`).
5. `IA_V2_ENABLED` OFF → прежний navbar байт-в-байт.
6. Порядок роутеров `bot.py` не трогается. `plans/current_task.md` не коммитится; секреты не цитируются (R17/R18).
7. Виджеты Статуса и логи сохраняются; PERMsoc остаётся локальным.

---

## 7. Проверка решения (definition of done ADR)

- `IA_V2_ENABLED` реально переключает UI (тест обоих режимов).
- Backend и фронт nav-метаданные совпадают (паритет-тест).
- 100% `TABS` достижимы в новой IA (авто-тест).
- Реальная Chromium-матрица §71 без горизонтального скролла и обрезаний.
- OFF-режим воспроизводит прежнее меню.
