## 1. B2 residual — skipped-события в calls/p50

**Причина:** `_self_diag_stats` считал `calls = len(subset)` и длительности по
ВСЕМ событиям, хотя `_SELF_DIAG_SKIP_STATUSES` уже помечал
`cooldown/denied/busy/no_gate/disabled` как не-измерение. Успешный чекап + кулдаун
давали заниженный/искажённый p50, который показывается в UI.

**Фикс (`web/api/routes.py`, только статистика):** skipped-строки исключены из
`calls`, `durations`, `by_stage.calls`; закрытые исходы (complete/partial)
считаются по измеренным; добавлено аддитивное `triggered` = общее число
событий. `partial_share` — по измеренным.

**RED на `cbb52d66` (репрод, те же данные):**

```text
{'calls': 2, 'complete': 1, 'skipped': 1, 'p50_ms': 450.0, 'p95_ms': 855.0}
# ключа 'triggered' нет
```

**GREEN на `d5e97727`:**

```text
triggered=2, calls=1, complete=1, partial=0, skipped=1,
p50_ms=900, p95_ms=900, partial_share=0.0, by_stage[0].calls=1
```

`inspect_runtime/degraded` по-прежнему `partial` (не «успех»),
`by_stage.failed=1`. Тесты: `TestB2ResidualSkippedCalls` (2).

## 2. B3 residual — статус/закрытие blocked-валидацией

**Причина:** `handlers/checkup.py::emit_checkup_validation_event` читал
`.report` у `diagnostic_policy.Publication` (такого атрибута нет) → статус всегда
`unknown`; событие эмитилось ДО проверки `publication.allowed`, поэтому
заблокированная проверка давала `checkup_output_validated` и закрывала gap
успешной доставки (`measured=true, value=0`).

**Фикс:**

- `handlers/checkup.py`: статус — `publication.status` (`clean`/
  `partially_redacted`/`blocked`/`denied`); хелпер сразу возвращает `None` для
  `not publication.allowed`; вызов перенесён ПОСЛЕ ветки `publication.blocked`
  (перед фактической отправкой). Заблокированная проверка события не даёт.
- `web/api/routes.py::_self_diag_validation_coverage`: для чекапа считаются
  только `checkup_output_validated` со статусом `clean`/`partially_redacted`
  (исторические/битые `blocked`-строки gap не закрывают).

**RED на `cbb52d66`:**

```text
success checkup + blocked checkup + checkup_output_validated/blocked
→ {"value":0,"measured":true,"reason":"enforcement_measured",
   "deliveries":{"checkup":1},"validated":{"checkup":1},"gaps":{}}
handler: events == [('checkup_output_validated','unknown'),
                    ('checkup_output_validated','unknown')]
```

**GREEN на `d5e97727`:**

```text
→ measured=false, value=null, reason=validation_not_correlated,
  deliveries={"checkup":1}, validated={"checkup":0}, gaps={"checkup":1}
handler: [('checkup_output_validated','partially_redacted')]  # blocked не эмитится
```

Парная разрешённая проверка (`report_sent` + `checkup_output_validated/clean|
partially_redacted`) → `measured=true, value=0, gaps={}`. Тесты:
`TestB3ResidualBlockedValidation` (3).
