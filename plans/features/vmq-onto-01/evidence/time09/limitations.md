# VMQ-TIME-09 — ограничения и честные границы evidence

1. **Нет live-прогона.** Production не деплоился и не читался (условие
   задачи). Реальный ход с `mca07_retrieval.trace_id` и сверка SQL↔UI
   остаются post-deploy агентской проверкой. До неё строка остаётся REVIEW,
   при отсутствии хода — `delivered_awaiting_evidence`.
2. **Старые ходы без trace_id.** В событиях до деплоя `mca07_retrieval`
   не связан с ходом: UI честно показывает Writer-часть и «Событий retrieval
   с привязкой к этому ходу нет». Это поведение покрыто unit-тестом, но
   в проде не наблюдалось.
3. **`period_selection` практически не durable.** `emit_stage_event(...,
   "selection")` не проходит контракт событий (outcome вне ALL_OUTCOMES),
   поэтому защитный фильтр API проверен синтетической строкой `mca_events`.
   Реальный producer-путь фильтр не получает — двойного счёта нет.
4. **Усечение selection** воспроизведено приведением реальной durable-строки
   к состоянию `truncated=true` (RAG/эпизоды удалены, `memory_period` пуст),
   а не переполнением упаковщика на 1800 байт. Проверяется именно отсутствие
   подстановки `{}` и честная подпись.
5. **Browser Use — blocked.** `BU_CDP_URL=http://127.0.0.1:9222` недоступен:
   нет выделенного Chrome с `--remote-debugging-port=9222`. Playwright-прогон
   (1280/390/320, 66/66) не отменяется; Browser Use не заявляется как
   выполненный.
6. **Playwright-стабы.** `/api/*` — детерминированные стабы из реальных
   payload-схем, не production DB. Реальные данные/чат проверяются после
   деплоя.
7. **Retention `mca_events`.** События могут быть вычищены — evidence
   реального хода нужно снять сразу после первого ответа.
8. **Cap `retrieval[]`.** В ответе ≤6 вызовов (первые по `ts`); более
   поздние при экзотическом сценарии не показываются. Для одного хода
   (основной + периодный добор) это не достигается.
9. **JS full: 4 pre-existing падения** (`asap6_wave2_ux_tabs`,
   `evol_cog_scene`, `round1025_ia_routing`, `ur_ui_settings`) — те же на
   чистом worktree базы `f68e7631d`; к TIME-09 не относятся и не чинились.

    (routes-инвентарь) не переиздавался.
