## 1. Решение и предикат

```python
PERIOD_REPLACE_SOURCES = frozenset({
    "query_year", "request_intent", "plan_act", "request_mode", "memory_scope"})
def period_replace_allowed(intent, policy):
    scope = normalize_memory_scope(policy).value
    if scope == "operative": return False
    if scope == "historical": return True
    return intent.source in PERIOD_REPLACE_SOURCES
```

`query_marker` (словарная эвристика) в множество НЕ входит. `resolve_period_intent`
и `_HISTORY_MARKERS` не менялись (M2/Slice C overview зависит от них).
Удалены: `is_current_state_query`, `_PERIOD_CURRENT_MARKERS`,
`PERIOD_DROP_CURRENT_STATE`, guard, `topic_parity/topic_years/topic_common_stems`
и их ключи. N3 закрыт по построению.

## 4. L1 `memory_scope` на пяти запросах — ИЗМЕРЕНИЕ НЕВОЗМОЖНО

Обязательное измерение на копии не выполнено по технической причине:
* локальный `.env` не содержит ключа LLM (`Authorization: Bearer ` пуст),
  реальный L1-вызов падает `LLMTransportError` для A1/A1P/P1/P2/P3
  (`l1-measure.json`, только коды ошибок);
* в копии прод-БД нет durable L1-плана: `mca_events` не содержит `L1_PLAN`
  (только `SUMMARY_L1_*`), `llm_usage_events`/`turn_traces` отсутствуют;
  поле `memory_scope` в durable plan_meta появилось только этим коммитом,
  поэтому исторических значений нет.

Честный статус: **какой `memory_scope` L1 выдаёт на A1/A1P/P1/P2/P3 —
UNKNOWN**. Это отдельная находка (evidence gap), а не повод вернуть словарь.
Ни один тест/вывод не опирается на догадку о L1.
