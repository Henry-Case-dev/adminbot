# Решение владельца: широкий контекст фактчека включён по умолчанию (25.10.2026)

Источник: сообщение владельца в root-чате.

## Решение

1. Режим широкого контекста фактчека (`flags.factcheck_wide_context` /
   `FACTCHECK_WIDE_CONTEXT_ENABLED`) должен быть **включён по умолчанию**.
2. Переключатель должен быть доступен владельцу в админке: **Модули → Фактчек**
   (существующая группа `flags_module_factcheck`, вкладка `mod_factcheck`).
3. Окно контекста — существующее: 200–500 сообщений, дефолт 300
   (`limits.factcheck_wide_context_messages`), с якорями тейков.
4. Выключение переключателя остаётся штатным способом отката без рестарта.

## Что это меняет

- `FACTCHECK_WIDE_CONTEXT_ENABLED` в `config/settings.py` — default `True`.
- `services/factcheck_context.py::wide_context_enabled()` — fallback `True`, если
  hot-ключа нет.
- Если в `bot_settings` уже лежит `false`, унаследованный от прежнего дефолта, —
  одноразовая идемпотентная миграция поднимает его до `true`; после этого владелец
  может выключить тумблер вручную, и это значение не перетирается.
- Описание в каталоге параметров: «по умолчанию включён», окно 200–500 (дефолт 300).

## Проверки

- Новый дефолт: без сохранённого значения режим включён.
- Миграция `false → true` идемпотентна, повторный запуск ничего не меняет.
- Ручное выключение в UI сохраняется и применяется без рестарта.
- Тумблер виден в «Модули → Фактчек».
- Широкий контекст реально используется в фактчеке (не только флаг).
