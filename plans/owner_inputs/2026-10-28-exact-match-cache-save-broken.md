# P0 CORRECTIVE: рубильник Exact Match Cache не сохраняется в админке + аудит декоративных переключателей

**Основание:** сообщение владельца 28.10.2026 со скриншотом production (2.58.139).

**Факт владельца:** в админке (Модули → Умный кэш) изменение рубильника «Exact Match Cache» и нажатие «Сохранить изменения» даёт ошибку «Сохранено 0 из 1; не сохранено: Exact Match Cache». Рубильник не сохраняется.

**Требование владельца:**
1. Исправить сохранение рубильника Exact Match Cache.
2. Проверить остальные параметры и рубильники админки: правильно ли они работают, реально ли изменяют состояние, или это декорация.

**Контекст скриншота:** на экране также поле «Срок жизни умного кэша, сек» (`limits.smart_cache_ttl_sec...`, значение 1800) и группа «Умный кэш: рубильник» (Exact Match Cache — мгновенные ответы на точные повторы), тост «Изменено: 1» и «Не сохранено: Exact Match Cache», кнопка «Сохранить изменения».

**Код:** прод 2.58.139 (release/p0-2026-10-26, бамп 1e438e3a + COR-фиксы b5e25966-линии).
