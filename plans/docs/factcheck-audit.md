4 рекомендации «вне скоупа» (кандидаты в `backlog.md`):
1. Жёсткий вердикт-формат в промпте («фейк / правда / полуправда / вырвано из контекста / инфы нет») + обязательные источники/даты из выдачи.
2. Параллельный каскад Tavily+Exa вместо последовательного (сейчас худший случай 5+10+15=30с).
3. Кэш проверок claim→hash→TTL ~1ч (нормализация lower/strip/стоп-слова).
4. Query expansion (подзапросы/DDG-суггесты для длинных утверждений).
