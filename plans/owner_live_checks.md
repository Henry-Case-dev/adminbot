# Проверки для владельца (информационно, НЕ блокер)

Правило (20.10.2026): **живые тесты в чате выполняет владелец сам**. Агенты запускают только технические проверки без сообщений в чат. Список ниже — что имеет смысл посмотреть, когда удобно. Ответы/результаты нужны только по желанию; на движение очереди это не влияет.

## 1. CFG-04 — мобильные формы (MiniApp)
Открыть админку в Telegram на телефоне:
- внизу одна кнопка «Сохранить изменения»; чип в шапке показывает «N · не сохранено» и не нажимается;
- с открытой клавиатурой панель не перекрывает поле ввода, последнее поле доступно;
- длинные технические ключи раскрываются по нажатию, есть «копировать»;
- повернуть телефон с несохранёнными изменениями — ввод и позиция сохраняются;
- закрыть с несохранёнными — появляется честный вопрос-подтверждение.

## 2. ADD-EXP — режимы мата («Речь» → «Как выражаться»)
- «Эпизодически»: поговорить в разных контекстах — мат иногда, без особого повода, но не постоянно.
- «Часто»: мат свободно и регулярно, в большинстве неформальных реплик; без насильных вставок и без повтора одного шаблона.
- «Без мата»: своих матерных слов нет; цитаты с матом не искажаются.
- Исключения всегда: фактчек, сводки, цитаты — без форсирования; прямая просьба «без мата» уважается.
- Статус: директивы переписаны на короткие прямые (owner 20.10); проверка — за вами, когда удобно.

## 3. Vision — длинный скриншот
Отправить боту документом длинный PNG-скриншот с мелким текстом; в ответе — осмысленное распознавание (ключевые строки), а не «не удалось». Известное ограничение: бесплатная модель иногда возвращает мусор на тяжёлых кадрах — это честная ошибка, не «успех».

## 4. Пост-генерация
Сгенерировать картинку: описание должно соответствовать самой картинке (не промпту), доставка — отдельным сообщением. Если анализ «в ожидании» — это честный статус (бюджет 20 с).

## 5. Ностальгия (SCEN-B)
Когда в чате долго тихо — проверить, приходит ли ностальгическое сообщение само (инициатива). Ничего делать не нужно, только наблюдение.

## 6. Единый характер — фактчек и сводки
Попросить фактчек и сводку/статью: голос должен быть тем же персонажем (не «нейтральный робот»), при этом факты, ссылки, структура и цитаты — без искажений. Мат — по выбранной интенсивности, без вставок внутрь цитат.
