## Инварианты pass'а (сквозные)

- `plans/current_task.md` не изменять (указание + R17/R18); источник — только verbatim-снимок.
- Фикс — внутри существующего embedding control plane (ADR-1028-7 D1, AM-1): **нет второго GraphRAG, второго реестра поколений, второго activation API**; «заглушки» запрещены текстом владельца.
- Δ DDL: цель 0; если @Architect по RCA решит иначе — только additive по политике DDL (идемпотентно, PG no-op, данные не теряются).
- R17: ключи/секреты не логировать (только alias/{configured,last4}); `.env` не трогать.
- Kill-switch'и новых механизмов — env-only, default-ON, OFF = бит-в-бит прежнее поведение (прецедент ASAP-4 §8.2).
- Полный pytest перед каждым коммитом, 0 регрессий (2 known pre-existing round1026 failures).
- Продолжение rebuild — платные живые вызовы: владелец запросил их явно (блок 1), это суть pass'а, отдельного owner-гейта не требуется; честность приёмки — no-false-acceptance.
- Отчёт/метрики — без выдуманных успехов; то, что не подтвердилось на проде, не заявляется.
