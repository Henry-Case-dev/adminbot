4. **Envelope результата полон (5 полей):** найденные факты + источники + степень подтверждённости (если доступна) + временной контекст + признак отсутствия данных — каждый элемент результата представим по этим полям. **REQ-A6-08; SC-A6-08, SC-A6-20; T-3617.**
5. **Неподтверждённое ≠ факт:** предположения не выдаются за установленные факты; степень подтверждённости передаётся честно; отсутствие данных помечается явно, а не «заполняется» домыслами. **REQ-A6-09; SC-A6-09, SC-A6-20; T-3617, T-3619.**
6. **Капы без «сотен сообщений»:** `max_items`/внутренние капы ограничивают выборку; сотни сообщений в результат не подмешиваются. **REQ-A6-11; SC-A6-11; T-3616, T-3618.**
7. **Без больших кусков личной переписки в ответе:** итоговый ответ не содержит крупных цитат приватной переписки (только краткие подтверждающие факты/ссылки-источники). **REQ-A6-12; SC-A6-12; T-3618, T-3619.**
8. **Системная личность бота не меняется:** стилизация — только временная, под конкретный ответ; личность другого пользователя не подменяет системную. **REQ-A6-13; SC-A6-13; T-3621.**
9. **Память ≠ фактчек:** память подтверждает факт высказывания, фактчек проверяет содержание; фактчек поиском похожих сообщений не подменяется; расширение набора фактчек-инструментов **вне scope** (см. U2 — по умолчанию НЕ расширять). **REQ-A6-15; SC-A6-15; T-3619, T-3621.**
