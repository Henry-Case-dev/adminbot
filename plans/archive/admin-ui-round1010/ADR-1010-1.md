# ADR-1010-1 — ЛС: сон/ностальгия/саммаризация OFF (data-change + default)

- **Статус:** Accepted (@Architect, 12.09.2026, Step 2)
- **Контекст:** владелец требует выключить сон, ностальгию и саммаризацию для ВСЕХ текущих активных ЛС и для новых ЛС по умолчанию. Хранилище — PG `chat_profiles.chat_params` (JSONB). Ноль новых PG-DDL.

## Решение

**Ключи (единый набор для скрипта и дефолта новых ЛС):**
- `gates.dream = false`, `gates.nostalgia = false` — per-chat килсвитчи воркеров (`feature_gates.gates_enabled`).
- `overrides["memory.dream_enabled"] = false`, `overrides["memory.nostalgia_enabled"] = false` — модульный/UI-уровень (per_chat категория `memory`).
- `overrides["flags.summary_enabled"] = false` — модуль «Саммаризация».
- `overrides["flags.chat_running_summary_enabled"] = false` — runtime-гейт бегущего конспекта ЛС (гасит возможные ранее включённые `true`; базово и так DM-default-OFF).

**Запись:** только через `chat_params.set_chat_params` (транзакция + `chat_lore_history` + NOTIFY); полные merged-словари namespace'ов (метод заменяет namespace целиком).

**Дефолт новых ЛС:** `ensure_scope_profile(dm=True)` вставляет v-1-лейаут с `gates={dream:false,nostalgia:false}` и четырьмя `overrides=false` (существующий `INSERT ... ON CONFLICT DO NOTHING`). Групповой путь не трогаем.

**Скрипт:** `scripts/disable_dm_heavy_modules.py`, по умолчанию dry-run, `--apply` пишет snapshot (`--snapshot-out`, только overrides/gates) ДО записи, `--restore` для отката, `--chat-id` для staged. Идемпотентен: повторный dry-run = 0 изменений.

**Не трогаем:** `bot.py` (F-14, direct-chat гейт `flags.summary_enabled`), router order, `media/`, `.env`, схему PG.

## Альтернативы
- Гидрировать `chat_params` SQL-ом напрямую (JSONB-апдейт) — отклонено: теряется история/NOTIFY/оптимистик-протокол `set_chat_params`.
- Полагаться на DM-дефолт `chat_summary_enabled` без явного override — отклонено: не гасит уже записанные явные `true`.

## Последствия
- Плюс: детерминированное OFF, единый источник значений, идемпотентность, откат снапшотом.
- Минус: у активных ЛС появляются явные `false` (не секреты); при желании владельца включить модуль — обычный toggle в UI.
