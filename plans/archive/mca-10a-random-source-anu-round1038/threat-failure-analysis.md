# MCA-10a `mca-10a-random-source-anu` — threat & failure analysis (T-4965, Risk R3)

**Фича:** `mca-10a-random-source-anu`; **Risk: R3** (подтверждение планового `mca-round1027-plan.md:205`). **Дата:** 05.10.2026, Step 2 @Architect. **Основание R3:** внешний провайдер (ANU) + секрет в контуре + новая durable-схема v27 с crash-семантикой выдачи + видимое владельцу состояние активации/fallback + политика, влияющая на автономное поведение. Отказ может привести к утечке ключа, ложному «quantum работает», двойному расходу значений, неограниченному росту данных или блокировке чата. Денежный контур не затрагивается (K5 OFF), ядро истинности/прав не рандомизируется. Митигации завязаны на spec §/задачи; проверка — focused-тесты и live T-4986.

## Сценарии отказа (поведение при сбое)

- **ANU недоступен/таймаут:** breaker/backoff, чат не блокируется; запас → PRNG (fallback ON) или отложенное необязательное (fallback OFF); direct-путь без изменений; причина видна (A19).
- **Ключ отсутствует/неверен/квота:** видимый блокер только квантовой интеграции; остальные функции работают; активация — сразу после исправления, без релиза (A28/GEN-R11).
- **DB locked/ошибка записи журнала:** draw fail-open на резервном пути (PRNG/детерминированный default) с честной причиной; bounded-очередь журнала не растёт бесконечно; значения без повторной выдачи (THR-5/THR-10).
- **Миграция v27 не применилась:** fail-closed backup-guard (mca-14), сервис не активирует новые таблицы; deploy останавливается; повтор идемпотентен (no-op) (spec §13.7).
- **Рестарт/деплой:** режим и настройки сохраняются (bot_settings); запас/watermark/квота durable; PRNG-поток после рестарта меняется — честно (сохраняется выбор режима, не поток) (spec §2, §3).

## Вывод

R3 подтверждён; все High-угрозы имеют проверяемые митигации в задачах T-4966–T-4987. Ложное объявление квантовой активации исключено конструктивно (только реальная валидная партия + self-check; live — PENDING OWNER). Вторые механизмы/каналы не создаются.
