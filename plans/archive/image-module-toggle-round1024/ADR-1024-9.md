# ADR-1024-9 — Отдельный модуль «Генерация изображений» (F5)

> **Статус:** proposed → применяется в раунде 10.24.
> **AMEND:** ADR-1023-5 §D5 (карточка изображений внутри «Прямого чата»).
> **Слой:** каталог (`services/param_catalog.py`) + web (`web/app.js`).
> **Human Gate №1** закрыт владельцем (UPD3 №1): menu-freeze снят **для этого пункта**.

## Контекст

Раунд 10.23 (F5, ADR-1023-5 §D5) добавил фичу генерации изображений и тумблер
`IMAGE_GENERATION_MODULE_ENABLED` в группе `flags_module_images`, но приписал группу
к вкладке **«Прямые ответы» (`TAB_MOD_DIRECT`)** — «9-й инструмент прямого чата».
В витрине «Модулей» карточки изображений не появилось.

Владелец (UPD2 п.3) считает это «потерянным тумблером»: отдельная крупная фича
должна управляться из «Модулей». UPD3 №1 официально разрешил вынести её отдельным
пунктом и снял `tma-menu-freeze` ровно для этого пункта.

Ограничение: каждая конфиг-группа обязана иметь **ровно одну** вкладку
(`_TAB_BY_GROUP`-аудит), а счётчики `REGISTRY/GROUPS/_TAB_BY_GROUP` запинены тестами.

## Решение

### D1. Новая конфиг-вкладка `mod_images` (nav «Модули»), группа переносится

`flags_module_images` **переносится** из `TAB_MOD_DIRECT` в новую вкладку
`TAB_MOD_IMAGES`. Это даёт вкладку, но **не** добавляет новую группу/ключ —
Δ каталога раунда остаётся минимальным.

### D2. Провайдер-настройки остаются в «LLM Провайдеры»

`models_images`/`keys_images` (адрес/модель/ключ/GET-режим) **не** переносятся на
`mod_images`: у провайдера ровно один дом (`llm_providers`, блок `image_generation`).
Это предотвращает дублирование владения полями (и конфликт с F11/F12, которые
правят тот же блок). Вкладка `mod_images` отвечает за **модуль** (главный тумблер),
а не за подключение провайдера.

### D3. Δ каталога фиксирована

| Метрика | Δ |
|---|---|
| `REGISTRY` | 0 |
| `GROUPS` / mapped | 0 |
| `_TAB_BY_GROUP` | 0 (смена вкладки у существующей группы) |
| `TAB_RULES` / `TAB_NAV` / `CONFIG_TAB_TITLES` | +1 (`mod_images`) |
| Витрина `MODULES` (JS) | +1 (13-я карточка) |

Итог с Part 1 F7: `REGISTRY 458`, `GROUPS 97`, `_TAB_BY_GROUP 95`, config-вкладок
**21**, витрина **13**.

### D4. Default ON глобально

`IMAGE_GENERATION_MODULE_ENABLED` уже `default True`; разрешение
`chat → global → default(True)`, per-chat override не сеем.

### D5. Иконка — переиспользование из сабсета

Добавить новый глиф (`image`) = правка `build/icon_codepoints.json`,
`subset_unicodes.txt`, пересборка WOFF2 и тест `ICON_NAMES` (37→38). Ради одной
карточки это неоправданный риск. Поэтому переиспользуем существующую иконку из
сабсета (`grid_view`). Долг: при следующей пересборке шрифта можно завести
отдельный `image`-глиф (не блокирует фичу).

### D6. menu-freeze

Исключение — **ровно один** пункт. Всё остальное меню не двигается;
ступень `TAB_SECTION_ORDER` — append-only (после `mod_budgets`).

## Последствия

**Плюсы:** фича управляема из «Модулей»; каталог почти не растёт; «один дом» для
провайдера; пин-тесты обновляются предсказуемо.
**Минусы/долг:** тумблер перестаёт быть «в контексте прямого чата» (сознательно);
иконка неидеальна (см. D5); счётчики в 4 тестах требуют синхронного обновления.
**Rollback:** вернуть `flags_module_images` в `TAB_MOD_DIRECT`/`git revert`;
флаг `IMAGE_MODULE_CARD_ENABLED` OFF скрывает карточку (`visibleModules`)
**и вкладку** (диплинк `#/modules/images` → `#/modules` в `applyRoute`,
активация блокируется в `setTab`; RBAC приоритетнее kill-switch). При OFF
главный тумблер в UI недостижим (группа — «один дом» на `mod_images`);
возврат ручки — env-флаг ON или `git revert` (review iter1: ложное
утверждение о достижимости через `mod_direct` удалено; review iter2:
`visibleTabs` — dead computed, UI-гейтом не является).

## Альтернативы

| Альтернатива | Почему отклонена |
|---|---|
| Оставить в `mod_direct` | прямо отклонено владельцем (UPD2 п.3) |
| Добавить новую **группу** изображений на новой вкладке | лишний рост `GROUPS`, дублирование владения `flags_module_images` |
| Перенести и провайдер (`models_images`/`keys_images`) на `mod_images` | дублирует дом провайдера, конфликт с F11/F12, ломает `test_llm_providers_covers_models_and_keys` |
| Добавить `image`-глиф | пересборка шрифта/сабсета + тест 37→38 — неоправданный риск ради косметики |
| Клиентский хак без каталога | нарушил бы `_TAB_BY_GROUP`-аудит и пин-тесты |
