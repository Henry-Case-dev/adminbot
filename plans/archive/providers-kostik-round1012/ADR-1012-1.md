# ADR-1012-1 — Развязка base_url провайдеров, формат списка фраз Костика, owner-блок PERMsoc

- **Раунд:** 10.12 (`providers-kostik-round1012`)
- **Статус:** ✅ ACCEPTED (@Architect, Step 2) — обязывает @Builder.
- **Контекст:** `plans/current_task.md` §1–§3; `tasks.md` (@PM); `plans/reports/round10.11_scanner_audit.md`.
- **Связанные требования:** T-1382 (item 1), T-1397 (item 3), OPEN-Q1…Q6.

## 1. Решения

### D1. Развязка base_url main vs embeddings (item 1)
`models.llm_base_url` перестаёт быть общим для direct-чата и primary-эмбеддингов.
- Новый cat-faithful параметр `models.embedding_base_url` (`settings.EMBEDDING_BASE_URL`, default `https://apinet.cloud/v1`).
- `LLM_BASE_URL` (direct) code-default → `https://nano-gpt.com/api/v1`.
- Read-path: `LLMClient` получает `embed_base_url` (DI из `bot.py`, 4 точки), `_post(base_url=…)`; `embed()` ходит на embed-base, chat — на chat-base; `status_service.emb_main` — embed-base.
- **Альтернативы:** (a) читать embed-base только внутри `__init__` без DI — отвергнуто: теряется явная точка конфигурации и усложняется тестируемость; (b) отдельный embed-ключ — отложено в OD-1 (scope item 1 = base_url).
- **Последствия:** «Прямые ответы» и «Эмбеддинги» независимы; `models.*` остаются `per_chat=False`.

### D2. Фикс 422 — на клиенте, серверный гейт не ослабляется
Глобальные (`per_chat === false`) ключи сохраняются global-путём: `api()` получает опцию `global`, `saveBlock`/`saveConfigItem` не шлют `X-Chat-Id` для таких ключей. Серверный 422 (`routes.py:414-417`) и DM read-only (R10.5-2) сохранены.
- **Альтернатива:** серверная делегация global-ключей из chat-скоупа — отвергнута (T-1388: «серверный гейт не ослаблять»; размывает RBAC).

### D3. Owner-блок `kostik` + под-флаг `flags.kostik_enabled`
Создаётся owner-блок `kostik` (PERMsoc). Тумблер блока — новый под-флаг `flags.kostik_enabled`, `DEFAULT_SUB_FLAGS[...] = True` (сохранение поведения), `PermsocModule('kostik').sub_flag_key` выставлен.
- **Альтернатива:** тумблер без ключа / переиспользование master — отвергнуто (шаблон всегда рисует переключатель; master уже занят «Общим»).

### D4. Хранение фраз Костика — один JSON-параметр + виджет `list`
`reactions.kostik_replies` (`type=json`, `widget=list`), массив строк, code-default = 14 фраз (4 владельца + 10 новых). Handler читает `hot.get(...)`, пустой список → молчание. Новый компонент `list-editor` (плотные строки, add/delete).
- **Альтернатива:** индексированные ключи — отвергнуто (рост каталога, хрупкость); CSV/textarea — отвергнуто (нет отдельных полей/удаления).
- **Частота:** существующий `limits.kostik_reply_probability` остаётся; группа `limits_kostik` claim'ится в блок Костика; новый cooldown не вводится.
- **Follow-up (ревью 10.12):** фразы #5/#12 из первой редакции заменены
  на adult-to-adult («ты хоть смазку купил…» / «я же взрослый мужик») —
  исключение minor-coded фрейминга; spec §3.3 синхронизирован с shipped.

### D5. OpenRouter display-name разделяется, base_url/ключ — нет
`models.openrouter_transcribe_display_name` (новый, STT) и `models.openrouter_display_name` (видео); общие `models.openrouter_base_url`/`keys.openrouter_api_key` сохраняются с UI-note (один аккаунт OpenRouter).
