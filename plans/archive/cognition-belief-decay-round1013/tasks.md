## 0. Цель

Убеждения перестают быть вечными: без подкрепления новыми фактами они теряют вес, уходят в архив,
но могут быть «воскрешены» тремя механизмами (векторный резонанс, Сон-Реаниматор, активация по графу).

## 1. Требования (дословно из ТЗ §4 + §4.1)

- [x] Если `belief` не подкреплялся новыми сырыми фактами **>6 месяцев** (настраиваемо) — `weight`
      снижается на **0.1 каждый месяц**.
- [x] При `weight < 0.3` убеждение переходит в статус **`archived_belief`** и не подаётся в активный
      контекст без прямого `dig_into_lore`.
- [x] **4.1.a Векторный резонанс:** архивные убеждения **не исключаются** из векторного поиска RAG,
      но получают пенальти к score **−0.3**. Если сходство пробивает порог — факт попадает в контекст,
      вес восстанавливается до базового («воскрешение»).
- [x] **4.1.b Сон-Реаниматор:** перед синтезом нового убеждения кластер свежих фактов векторно сверяется
      с архивом; при сильном совпадении синтез отменяется (экономия), старое убеждение восстанавливается
      с обновлённой датой.
- [x] **4.1.c Активация по графу:** при росте частоты связки 2–3 узлов в окне L1 связанные архивные факты
      поднимаются в горячий кэш без вызова `dig_into_lore`.
