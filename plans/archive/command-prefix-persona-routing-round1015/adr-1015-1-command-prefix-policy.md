# ADR-1015-1 — Политика обязательного префикса функциональных команд (без рубильника)

- **Статус:** Принято, **итерация 2** (Step 2 @Architect, 14.09.2026). Заменяет редакцию итерации 1 (флаг `flags.command_prefix_enabled` отклонён владельцем, `current_task.md` UPD §1).
- **Раунд:** 10.15, фича F6 `command-prefix-persona-routing-round1015` (T-1593)
- **Контекст:** функциональные команды (`search`/`youtube`/`web`/`checkup`/`download`) срабатывают без обращения (regex/субстринги) → ложные срабатывания в обычном тексте; LLM-ответы конфликтуют с функциональными командами. С 10.14 введено имя персоны. Владелец отказался от отдельного рубильника: фича должна работать «из коробки».

## Решение

1. **Отдельного флага НЕТ.** Триггер системы — **непустое `active_persona.name`** (глобальный sync-кэш `bot_persona.get_cached_global_name()`, гейт `flags.persona_enabled`).
   - **Имя непусто:** префикс = имя (+ эвристические склонения при `len ≥ 3`); дефолтные ботворды `бот`/`ботик`/`ботяра` **отключаются**.
   - **Имя пусто:** префикс = ботворд-семейство `бот`/`ботик`/`ботяра`; дефолтные триггеры остаются.
2. **Канонический реестр (UPD §2):** 17 префиксных триггеров (search 3 / youtube 4 / web 4 / checkup 3 / download 3) + **bare-исключения** `чекап`, `фактчек` (одно слово). Разделитель префикса: пробел / `,` / `:` / `!` / дефис.
3. **Приоритет/«не в LLM»:** порядок роутеров `bot.py` не меняется (search 0d / youtube 0e / web 0f / checkup 0g до direct_chat 0h). Для download (4e, ПОСЛЕ 0h) и отключённых модулей `direct_chat` делает **yield (UNHANDLED)** при `prefix + канонический триггер` → пропагация D49 доносит сообщение до 4e. Триггер без цели консьюмится нейтральной фразой.
4. **reply/mention/@username** — без обязательного префикса (приоритетнее, не меняются).
5. **Мягкий переход:** пустой глобальный дефолт ⇒ ботворд-ответы живых чатов сохраняются; меняется только функциональный путь (bare-триггеры больше не работают — цель фичи). Откат = `git revert` + очистка поля Имя.

## Альтернативы и отклонения

- **Флаг-рубильник `flags.command_prefix_enabled` (итерация 1):** **ОТКЛОНЁН владельцем** — «фича работает всегда из коробки, ручных включений нет».
- **Новый роутер/перенос download перед direct_chat:** отклонено — порядок роутеров `bot.py` неизменяем; выбран аддитивный yield в direct_chat.
- **Per-chat имя в sync-фильтре:** отклонено — блокирующий PG-запрос на каждое сообщение.
- **Словарь склонений в каталоге:** отклонено — эвристика достаточна, Δ=0.
- **Сохранение legacy-алиасов сверх канона:** отклонено (UPD §2 «именно эти»); снятые алиасы перечислены в spec F6-U1.

## Каталог-Δ

**Δ = 0** (новые ключи не вводятся).

## Последствия и rollout

- Ручного включения нет; поведение зависит от поля Имя. Пустой глобальный сид = мягкий переход.
- Progressive delivery неприменим (нет рубильника). Мониторинг: логи `triggered` функциональных воркеров vs доля LLM-ответов; всплеск «нет цели» — маркер ложных срабатываний.
- F7 (гайд) описывает канонический реестр и правило обращения.

## Инварианты

Порядок роутеров `bot.py` (0a…0h, 4e) не менять (только DI-kwargs), R16/R17, sync-путь без блокирующих PG, `media/`/`.env` не трогать.
