# ADR-1021-6 — UI-аудит реальным браузером: порядок Puppeteer → Playwright → честный отказ

- **Статус:** **Accepted** (UPD владельца после Human Gate, раунд 10.21)
- **Дата:** 18.09.2026, раунд 10.21
- **Контекст:** F6 `ui-audit-puppeteer-round1021`, T-1990…T-2000
- **Связано:** ADR-1020-* (UI-rework/UPD3), scanner-отчёт `plans/reports/round1020_ui_rework_scanner_audit.md`

## 1. Контекст

ТЗ требует автономный UI/UX-аудит через Puppeteer MCP. Владелец сообщил, что **пофиксил Puppeteer MCP**
(UPD, строка 150) → его нужно **реально попробовать первым**; при недоступности/ошибке — Playwright+Chromium,
иначе честная фиксация. В 10.20 отчёт о готовности UI оказался **галлюцинацией** (проверка по коду/грепом).
Нужен метод, который физически рендерит страницу и даёт проверяемые доказательства.

## 2. Решение (UPD)

1. **Порядок инструментов (строго):** сначала **реально попытаться** вызвать **Puppeteer MCP**
   (`puppeteer_navigate`, `puppeteer_screenshot`, `puppeteer_evaluate`); если недоступен/ошибка —
   **Playwright ≥1.40 + Chromium** (`requirements.txt:27-28`, `playwright install chromium --with-deps`);
   если упали оба — **честно зафиксировать в `UI_AUDIT_REPORT.md`, что визуальный аудит не выполнен**
   (сырые ошибки). **Запрещено выдумывать результаты/делать вид, что инструменты сработали.**
   Фиксируется как **риск R1** (headless ≠ WebView).
2. **Контракт доказательств (реальный рендер):** дефект подтверждается только `getComputedStyle`/
   `getBoundingClientRect`/`input.value`/`animationDuration`/console/скриншотом. **Grep-строки в исходниках
   не являются доказательством.** Отчёт без реального рендера — невалиден.
3. **Регресс-защита 5 дефектов UPD3:** отдельный `tests/js/round1021_ui_audit_test.js` с зондами
   (glass, grid ≥2 трека, маска, градиент, **sticky**) + **инвариант меню 25/6/12**. В этом раунде
   закрывается **M-1 sticky 88px** (полноэкранный config).
4. **`UI_AUDIT_REPORT.md`** (корень репо, по ТЗ) — фиксированный формат (spec §6), включая честный статус инструментов.
5. **R17/R18:** только маска `••••••••••••`/фейковые значения; чистка логов/скриншотов; R18-скан (`sk-…`, `ghp_…`, `AKIA…`, `AIza…`).
   Секреты/хост-креды из ТЗ не цитируются.
6. Меню/навигация — **инвариант, не менять** (25 вкладок / 6 NAV_ITEMS / 12 модулей).

## 3. Обоснование

- Прецедент 10.20-UPD3: Playwright Python API + реальные `tailwind.css`/`app.css` дали независимые
  CSSOM-замеры (Scanner-отчёт), которые вскрыли M-1 (sticky 88px), пропущенный «проверкой по коду».
- Галлюцинация 10.20 прямо показала: приёмка «по grep/по отчёту» недостоверна.

## 4. Альтернативы

| Альтернатива | Вердикт |
|---|---|
| Puppeteer MCP | **Использовать первым** (UPD: владелец его пофиксил); недоступность фиксируется честно, а не замалчивается. |
| Проверка по коду/grep | Дискредитирована в 10.20; запрещена как доказательство. |
| Скриншот-диффы без замеров | Ловят визуал, но не `backdrop-filter`/grid-треки/binding; комбинируем с CSSOM-зондами. |
| Реальный WebView-эмулятор | Нет в окружении; риск R1 остаётся и фиксируется в ограничениях. |

## 5. Последствия

- Δ каталога = 0; флага нет; откат — `git revert`.
- Новые тесты в `tests/js/`; отчёт `UI_AUDIT_REPORT.md` проходит R18-скан.
- Известные открытые Low/Medium UPD3 (M-1 sticky 88px, L-1 `@focus select` на не-секретных,
  L-2 silent-no-op маски на WebView, L-3 `@supports` padding) — учесть, не переоткрывать закрытое;
  M-1 рекомендуется закрыть в этом раунде.
