## 1. Цель

Провести **реальный браузерный** сквозной аудит мини-аппа (не по коду вслепую), немедленно чинить дефекты и
зафиксировать результат в `UI_AUDIT_REPORT.md`.

**Боевая задача:** поднять локальный сервер фронтенда, пройти **все** разделы (Сводка, Справка, Модули, ИИ, Доступы),
открыть **ВСЕ** модалки и кликнуть по шестерёнкам расширенных настроек.

**Фокус инспекции:**
- Геометрия/отступы: съезжающие блоки, перекрытия, кривые margin/padding.
- Liquid Glass: настоящее матовое стекло (`backdrop-filter: blur(...)` + правильный `rgba`), а не простая прозрачность.
- CSS Grid: карточки растягиваются по сетке, а не в одну кривую колонку.
- Data binding: маски `••••••••` для существующих настроек vs пустые поля.
- Градиент: ускорить анимацию + оранжевый спектр.
- Консоль браузера: JS-ошибки, варнинги React, упавшие запросы.
