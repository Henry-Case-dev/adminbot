# F10 — §78 UI-прогон секретов (T-3113)

> **Тип:** живой UI-прогон Chromium (не только чек-лист). Инструмент:
> `tools/ui_round1025_secrets_ui.py` (переиспользует сервер/стабы матрицы,
> ADR-1025-24 D5). Артефакт: `tools/_ui_round1025_secrets_ui.json`.
> **R17:** реальные секреты не выводятся; в отчёте — только маска/предикат.

## Что проверено на реальном `web/index.html` + `web/app.js`

| Требование §78 | Результат |
|---|---|
| Ключ существует → маска отображается | `.secret-field[data-secret-configured="1"]` найден; `maskText = ••••••••0000` (8 '•' + last4), бейдж-индикатор |
| Значение не подставляется в input | `.secret-field__input.value == ""` (маска — display-индикатор, §50) |
| Ключ не изменён → не перезаписывается | сохранение сентинела маски → **0 write** |
| Ключ заменён → новая маска | реальный ключ → **ровно 1 write**, payload = новое значение |
| **Строка маски НЕ уходит в API** | сентинел (12×`•`, U+2022) и композит (`12×•` + `0000`) распознаны `hasSecretMask`; `POST /api/config` — **0** с маской; среди всех payload'ов строки маски нет |

Guard (R31/UPD3-fix): `SECRET_MASK = '\u2022'×12`; `hasSecretMask(v)` = «строка
содержит сентинел»; `saveKeyItem` отклоняет маску/композит (`return false`,
write не выполняется).
