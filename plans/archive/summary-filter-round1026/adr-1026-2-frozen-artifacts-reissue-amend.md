# ADR-1026-2 — AMEND ADR-1025-21 D6: переиздание замороженных артефактов round1025 F8 при санкционированном Δ каталога

- **Статус:** Accepted (Step 2b @Architect, 23.09.2026)
- **Фича:** S1 `summary-filter-round1026`
- **Связано:** ADR-1025-21 **D6** (frozen-инварианты F8), ADR-1026-1 **D1** (санкция Δ каталога 459→467)
- **Триггер:** блокер **B-1** @Reviewer (`review.md`): суперсессия переиздала frozen-артефакты F8 без санкции («AMEND: нет» в ADR-1026-1).
- **Основание:** D2 ADR-1025-21 прямо допускал дрейф каталога через `--check`-маркер; F8 — read-only enabler, а не вечный байт-замок каталога.

## Решение

**Санкция выдана.** Переиздание замороженных артефактов F8 при **санкционированном** Δ каталога — штатная процедура; **откат не требуется** (механическая корректность и неизменность инвариантов подтверждены независимо @Reviewer и @Scanner).

**Процедура (repin + regenerate + recount):**
1. **Repin** строгого `sha256`-пина `services/param_catalog.py` на новые байты.
2. **Регенерация** `plans/docs/param-registry-round1025.{tsv,meta.md}`, `screen-map-round1025.md`, `widget-map-round1025.md` через read-only `tools/gen_param_registry_round1025.py`; `--check` остаётся байт-идемпотентным (exit≠0 при расхождении).
3. **Recount/дельта:** REGISTRY/Settings/categorized/GROUPS/`_TAB_BY_GROUP`/`TAB_RULES`; дельта **411→467 = 56** (была 48); исторические 459/48 сохраняются как baseline/provenance в `.meta.md`.
4. **Тесты:** обновить `tests/fixtures/round1025/f8_baseline.json` и ассерты `tests/test_round1025_f8_registry.py` (обновление, **не** отключение) + динамические «459» в генераторе.

**Инварианты остаются строгими:** `pg_db.py`/`routes.py` — byte-freeze не тронут; `sha256`-пин — строгий (ребазирован, не ослаблен); counts — строгое равенство; множества ключей не теряются; секреты — только `{configured,last4}`.

## Альтернативы

- **Вернуть F8 в архив / оставить 459** (и сделать S1 env-only) — отклонено: противоречит §87/§89/§107/T-3139 (нужны каталог, UI, hot, per-chat) и лишает S1 санкции D1.
- **Ослабить байтфризы/пины** — отклонено: инварианты D6 сохраняются без изменений.

## Последствия и контракты

- F10 (`tools/config_snapshot_diff.py`) и F11 (карта виджетов) читают **актуальные** артефакты; `--check`-маркер — источник истины для дрейфа.
- Изменяется только provenance/counts замороженного аудита, **не** его правила; ADR-1025-21 **D1–D5/D7 не меняются**, меняется только **D6** (добавляется правило переиздания).
- Затронутые требования S1: REQ-S1-04 (§87 ключи/Δ каталога), инвариант §12.4 спеки; блокер B-1 закрывается этой санкцией.
