## 1. Контекст и цель

Владелец: (п.5) «В разделе Статус объедини блоки Сердцебиение, Бот и Сервер в один визуальный блок, убери строчки режим и версия»; (п.4) «поле ввода поиска графов связей в мобильном виде очень большое по ширине и высоте — нужно значительно уменьшить; в десктопном виде слишком длинное, почти на всю ширину».

**Цель:** аккуратный компактный раздел «Статус» без потери информации (кроме явно лишней строки) и без регрессов графа/поиска.

## 3. Требуемое поведение

1. «Сердцебиение» + «Бот» + «Сервер» — **один визуальный блок** (единая карточка с внутренними секциями); на мобиле — вертикально, на десктопе — секции рядом/колонками; вёрстка не разъезжается.
2. Строка «Режим … · версия v…» **удалена** полностью (и «Режим», и «версия»).
3. Поле поиска по графу: на мобиле — **значительно меньше** по ширине и высоте; на десктопе — **не на всю ширину** (ограниченная ширина).
4. Логика поиска/подсветки/сброса вида не затронута; JS-гейты чистые.
5. API-контракт «Статуса» **не изменяется** (`bot.mode`/`bot.version` остаются в ответе — R16).
6. `prefers-reduced-motion`/EKG-анимация, self-host vis-network, CSP — не задеты.
