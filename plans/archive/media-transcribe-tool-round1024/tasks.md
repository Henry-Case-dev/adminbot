## Цель
Владелец зафиксировал (UPD5 №3) **разделение инструментов по функциям**:
- «Что на видео», «Че за видос» и подобные запросы — это запрос на **саммаризацию (выжимку)**.
- «транскрипт» — отдельная команда именно для **транскрибации**: принудительно повторяет транскрибацию ГС/кружка, если авто-транскрибация не сработала, и так же работает для любого видео — в т.ч. для YouTube отдаёт **голый транскрипт аудио курсивом**.

Из этого: в tool calling два чётко определённых инструмента (**выжимка** и **транскрибация**), чтобы LLM по запросу пользователя сама выбирала сырой транскрипт или выжимку; канон инструментов **9→10**.

## Критерии приёмки
- В tool calling два различимых инструмента: **выжимка** и **сырой транскрипт**; LLM выбирает нужный по определению.
- Команда «транскрипт» принудительно повторяет транскрибацию ГС/кружка и работает для любого видео; для YouTube — голый транскрипт аудио курсивом.
- «Что на видео»/«че за видос» и подобные дают **выжимку**, а не сырой транскрипт (и наоборот).
- Канон инструментов = **10**; рассинхрон I2 закрыт; `active_tools`/`factcheck_tools` не сломаны.
- Полный pytest — 0 failed; `git diff --check` чист.
