# ADR-1022-4 — Саммари: Редактор (Markdown-выжимка) → Рассказчик

- **Статус:** **Accepted** — решение владельца UPD3 (18.09.2026); уточнено Step 2b @Architect (18.09.2026)
- **Фича:** F4 `system2-summary-two-call-round1022`
- **Тип:** backend/LLM + канон промптов
- **Связано:** ADR-1020-2 (архив ≠ свежее), R11 v4 (саммари-канон), ADR-1013-3, ADR-1021-3, F6

## Context

Текущий саммари — один вызов (`summary_generator.py:204-241`), куда RAG-контекст подмешивается
целиком (`:164-168`), и «Архивная справка» приклеивается сбоку даже когда нерелевантна. ТЗ
требует физически разделить «отбор» и «рассказ». Инварианты: R11 (plain-text, токсичный стиль),
стриминг/чанки, `{username}`-постфикс (добавляет код).

## Decision

1. **Stage 1 — Редактор.** Вход: сырая история + RAG-факты (S + `_compose_user_content`). Выход:
   **чистая Markdown-выжимка** событий; нерелевантные исторические факты **выбрасываются**;
   системные теги/`fact:ID`/`msg:ID` запрещены. Markdown — внутренний формат.
2. **Stage 2 — Рассказчик.** Вход: **только** digest. Выход: связный **plain-text** (R11, без
   markdown/списков/эмодзи), стиль `STYLE_BLOCKS_SUFFIX`. Не «пришивает» факты сбоку.
3. **Доставка не трогается:** стриминг/чанки (`:380-475`) и `_ensure_shiz_postfix` без изменений;
   меняется только участок до `text`.
4. **Fallback:** невалидный digest/таймаут Stage-1 → одиночный путь 10.21. Kill-switch
   `SYSTEM2_SUMMARY_ENABLED` (env-only `ClassVar`, default ON, Δ каталога = 0).
5. **Канон-миграция атомарна:** `SUMMARY_EDITOR_*` + `SUMMARY_NARRATOR_*` + `PREV_*` +
   `PROMPT_MIGRATIONS` + `plans/docs/canon/**` + тесты одним коммитом (ADR-1013-3).
6. **Validator Loop (UPD3 §3):** Рассказчик вызывается через
   `services/negative_constraints.verbalize_validated` (`max_retries=2`); при клише ответ
   бракуется и перегенерируется; при исчерпании — лучший вариант (fail-open; пусто → 10.21).
   Клише кодом **не** вырезаются (вето владельца); regex-стрип — только теги.

## Consequences

- Архивная справка перестаёт приклеиваться нерелевантно (отбор отделён от рассказа).
- +1 LLM-вызов; латентность растёт (стриминг скрывает частично).
- Появляется риск «эхо markdown» из Рассказчика — митигируется промптом + тестом (при
  необходимости — лёгкий code-strip, решение Д-6).

## Alternatives

- **Оставить один вызов, добавить инструкцию «фильтруй архив»** — отклонено: инструкция не
  гарантирует, RAG всё равно в контексте рассказчика.
- **Передавать Рассказчику digest + сырую историю** — отклонено: нарушает изоляцию.

## Cost ×2 / бюджет / латентность

+1 вызов. Бюджет: `limits.summary_max_context_tokens` (Редактор) + короткий лимит digest.
Латентность: +1 round-trip. Приемлемость — Д-6.

## Kill-switch / Fallback / Rollback

- **Kill-switch:** `SYSTEM2_SUMMARY_ENABLED=false`.
- **Fallback:** невалидный digest/таймаут → 10.21.
- **Rollback:** флаг OFF / `git revert` + обратная канон-миграция.

## Canon migration

**Обязательна (ADR-1013-3), атомарно с F6→F3→F4→F5.** Слепки `PREV_R1021_SUMMARY_SYSTEM_PROMPT`,
`PREV_SUMMARY_SYSTEM_PROMPT` сохраняются.
