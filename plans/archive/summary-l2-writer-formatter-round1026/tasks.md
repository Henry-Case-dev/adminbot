## Приёмочные инварианты S5 (нарушение = НЕ принято)
1. **L2 — отдельный слой** (§81/§82/§97): своя модель/провайдер/системный промпт/параметры/fallback; «не выбрано» → глобальная основная модель (наследование ≠ аварийное резервирование). Общий промпт с L1 запрещён.
2. **Ровно 2 физических LLM-вызова** на Саммари (L1 + L2); третий — блокер. Врезка заменяет Stage-1/Stage-2 (AMEND ADR-1022-4, effective S5; ADR-1026-7 **D5**); изоляция слоёв/fallback single/доставка/kill-switch/validator-loop сохранены; **`await_count==2` для обоих путей** (ON на моках, OFF байт-в-байт).
3. **Вход L2 = пакет фактов §96** (S4): контент-секция без `service`; сырой лог повторно не передаётся. `empty`/`invalid`/`error`/`not_built` пакета → L2 **не вызывается** (§95/§106).
4. **§97-качество (ADR-1026-7 D1/D4):** никакого стиля повседневной переписки; инструкции на сленг/беглую речь/бессвязный поток/мемы удалены; умеренная ирония допустима; приоритет — точность; **цитаты не выдумываются, реплики не приписываются** (инструкции промпта + детерминированная пост-валидация: нет нормализованного совпадения с пакетом → снятие кавычек; именованная атрибуция → fail-closed `invalid`/`quote_attribution`).
5. **§98-структура (D2):** один выразительный H1; вступление (если уместно); события отдельными абзацами; логичный порядок; необязательное заключение; **≤1 жирный смысловой акцент на абзац** (отсутствие акцента допустимо); событие не придумывается ради заголовка; лимиты — `title` ≤200/одна строка, абзацев ≤ `limits.max_summary_parts` и ≤498 блоков, абзац ≤900.
6. **§99/§101/§102 (D1/D2):** L2 отдаёт **структурированный документ** (не произвольный HTML); форматтер `services/summary_article_formatter.py` (чистый код, 0 LLM) → настоящий H1 в основном пути `sendRichMessage`; только `img/h1/p/b`; `sanitize_outgoing` → `html.escape(quote=True)` (порядок обязателен); **экранирование** `& < >`, кавычки, Unicode, эмодзи, ссылки; rich ≤32000 симв.; доставка — явный `content_format="html"` (default `"auto"` = байт-в-байт).
7. **§105 plain-fallback (D2):** H1 → жирный (`format_plain_html`), абзацы/совместимые акценты; разбивка по границам абзацев (≤4096); финальный даунгрейд `format_plain_text` без разметки; текст не теряется и не обрезается молча; OFF-путь `_deliver_plain`/`_send_chunked` — вне diff.
8. **§106 fail-closed (D6):** некорректный результат L1/пакета → L2 **не вызывается** (`L2_SKIPPED`); L2-провал → **без legacy-фолбэка** (3-й вызов), публикации нет; различать `SUMMARY_GENERATION_FAILED`/`COVER_GENERATION_FAILED`/`RICH_MESSAGE_SEND_FAILED`/`TEXT_FALLBACK_FAILED`; без бесконечных повторов. Обложка не создана → публиковать текст.
9. **§104 не трогать:** `generate_image`/обложка/`compose_cover_image_prompt`/порядок публикации/механизм прикрепления — без изменений; `cover_prompt` — транзит из `service`-секции пакета.
10. **Гейт D4 (ADR-1026-7 D5):** врезка за kill-switch `SUMMARY_HYBRID_L2_ENABLED` (env-only, **default False**) + hot-first `flags.summary_hybrid_l2_enabled`, per-chat через `_chat_limit`; OFF-путь **байт-в-байт** прежний; S5 верифицируем без владельца (ON — на моках); реальный ON — гейт S6/S10 + live-приёмка Эпика 1.
11. **Логи аддитивны (R17):** числа/коды/id/host; без ключей/текстов/сырых ответов/промптов; `run_id` формально — S7.
