# ADR-1025-21 — Реестр параметров/карты как committed-артефакты + read-only генератор/snapshot-diff

- **Статус:** Accepted (Шаг 2 @Architect, 23.09.2026)
- **Фича:** F8 `parameter-registry-widget-map-round1025` (Эпик 1, read-only enabler)
- **Спека:** `plans/features/parameter-registry-widget-map-round1025/spec.md`
- **Контекст:** §1–§3, §117 п.1–4 `plans/current_task.md`; baseline HEAD `a40f244`, `APP_VERSION` 2.58.15, каталог 459/98/96/21/418.

## D1 — Где хранить реестр и карты: committed-артефакты, не endpoint.

**Решение.** Канонические артефакты — файлы в `plans/docs/` (`param-registry-round1025.tsv` + `.meta.md`, `screen-map-round1025.md`, `widget-map-round1025.md`). API-эндпоинт **не создаётся**. `plans/docs/canon/` не используется (там байт-в-байт эталоны промптов «НЕ редактировать»).

**Альтернативы.** (A) Генерируемый файл — отклонён как единственный источник (не версионируется/не ревьюится); (B) live-endpoint `/api/config/registry` — отклонён: новый рантайм-код, расширение API-контракта, риск CSP/тестов/нагрузки; ТЗ прямо просит «не создавать ненужную инфраструктуру».

**Следствия.** Артефакты ревьюируемы, версионируемы, читаемы F9/F10/F11. Нет Δ каталога/DDL. Минус — ручное обновление, закрывается D2 (`--check`).

## D2 — Генератор: read-only, вне рантайма, `tools/`, с `--check`.

**Решение.** `tools/gen_param_registry_round1025.py` — read-only, stdlib + импорт `services.param_catalog`; вход дополнительно `inventory.tsv` (411, сверка/дельта); детерминированный вывод без timestamp; `--check` (exit≠0 при расхождении с committed-файлом) включается в маркер-тест. Провенанс (HEAD/версия/счётчики) — в `.meta.md`.

**Альтернативы.** Ручное ведение реестра — отклонено (расхождение с кодом/устаревание). Прямая запись из рантайма/CLI в БД — отклонена (нарушает read-only enabler).

**Следствия.** Реестр не «застывает»: при будущих фичах прогон генератора/`--check` ловит дрейф. Дельта 411→459=48 эмитится явно.

## D3 — Структура карт и правило полноты.

**Решение.**
- Карта экранов: `old_screen → param_key → new_screen (IA §4) → read_api → write_api → ui_visibility`; `ui_visibility ∈ {visible, hidden, api-only}`, где `hidden` — из `ParamSpec.hidden`, `api-only` — есть в API/каталоге, но нет в UI (**≠ сохранено**).
- Карта виджетов: `old_widget → data_source → new_location → preserved_actions → ui_visibility`.
- **Инвариант «ни один параметр не остался без места»:** множество ключей карты ⊇ `REGISTRY` (459); неизвестный параметр → секция `registry-only` реестра. `secret`/`hidden` фиксируются в реестре (поля `secret`/`hidden`/`ui_visibility`).

**Альтернативы.** Хранить hidden/secret только в прозе — отклонено (нет машинной сверки полноты).

## D4 — Бэкап + diff: формат по 8 срезам, R17-safe, ключ→значение.

**Решение.** Переиспользовать существующий механизм (теги `pre-round1025-f8` + `var/backups/f8-round1025-<ts>/` + `.env.bak.round1025-f8`; `manage.py --backup-dir`/`db_backup`). Снапшот — JSON на срез с ключом по **`pg_key`/`chat_id`** (не по display-name). Секреты → только `{configured,last4}`; сырьё не пишется никуда. Diff-инструмент `tools/config_snapshot_diff.py` — read-only, вне рантайма, классификация по ключам. В git — только отчёт-статусы `plans/reports/round1025_f8_config_diff.md`. 8 срезов §3: глобальная, чаты, ЛС, PERMsoc, промпты, модели, подключения, роли/разрешения. Метод переиспользуется **F10**.

**Альтернативы.** Новый механизм бэкапа — отклонён (ТЗ: «использовать существующий»). Diff по именам — отклонён (переименование ключей незаметно).

## D5 — Deploy: NOT_APPLICABLE.

**Решение.** F8 не меняет рантайм (`services/**`, `web/**`, `handlers/**`), БД, каталог и ассеты. Скрипты `tools/` не импортируются рантаймом. → **T-3019 = NOT_APPLICABLE** (без рестарта/миграций). Прод-`git pull` поведение не меняет.

**Альтернативы.** Deploy «на всякий случай» — отклонён: противоречит «не создавать ненужную инфраструктуру», лишний риск.

## D6 — Инварианты и доказательная планка.

Δ DDL=0 (SQLite `user_version=12`), Δ каталога=0 (`param_catalog.py` не в диффе; 459/98/96/21/418), CSP/zero-build, read-only, R17. Тесты: полнота 459/459; дельта 411→459=48; отсутствие открытых секретов; идемпотентность `--check`; diff без реальных изменений; неизменность роутов и `APP_VERSION`. §117 п.1–4 = 4 артефакта.

## D7 — Совместимость и версия.

§52–§66/F0–F7 не трогаются; артефакты аддитивны. **`APP_VERSION` НЕ бампается** (остаётся 2.58.15): bump нужен только для cache-bust отдаваемых ассетов, а F8 их не меняет. F9 читает реестр, F10 — метод snapshot+diff, F11 — карту виджетов.

## Риски / последствия

- Устаревание артефактов — закрыто `--check`-маркером (Low).
- Разрастание `plans/docs/` — короткие навигационные файлы, не логи (Low).
- Утечка секрета — маскирование + независимая Scanner-проверка R17 (Critical-риск, контролируется).
