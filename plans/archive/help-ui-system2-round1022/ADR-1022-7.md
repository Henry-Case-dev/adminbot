# ADR-1022-7 — Справка v4: правила вёрстки, «транскрипт vs выжимка», блок System 2

- **Статус:** Accepted (Step 2 @Architect, 18.09.2026)
- **Фича:** F7 `help-ui-system2-round1022`
- **Тип:** контент/UI (код-канон) + frontend `web/**`
- **Связано:** ADR-1020-8 (Справка v3), ADR-1016-3 (версионирование канона), D224/R44-1 (байт-синхрон), ADR-1013-3

## Context

ТЗ требует переписать раздел «Справка»: команды в `<blockquote>`, только `<h1>`/`<h2>`, без
точек/запятых/«или» между примерами; объяснить транскрипт vs выжимку; убрать п.11 «Безлимиты»;
добавить блок «Как бот думает (System 2)». Аудит уточнил: React-компонента нет; контент — код-канон
`DEFAULT_INFO_TEXT` (v3, `info_service.py:147-214`) + PG `content.info_how_it_works` + Vue-рендер
`index.html:2592`. Текущая вёрстка использует `h1/h2/h5/h4/b/i`; правила ТЗ означают полную
переписку секций команд.

## Decision

1. **Полная переписка** `DEFAULT_INFO_TEXT` (v4) под правила ТЗ: только `<h1>`/`<h2>` для
   заголовков, команды — в `<blockquote>`, без точек/запятых/«или» между примерами.
2. Обязательный состав: транскрипт (`Бот, транскрипт`) vs выжимка (`Бот, поясни за видос`,
   `Бот, о чем видео`); **удалить п.11 «Безлимиты»**; **новый блок «Как бот думает (System 2)»**
   без деталей реализации.
3. **Канон-миграция (D224 + ADR-1013-3):** `INFO_CANON_VERSION` 3→4; v3-слепок в
   `KNOWN_INFO_SNAPSHOTS`; байт-тест `DEFAULT_INFO_TEXT` ↔ `info_text.md`; идемпотентная PG-миграция
   `content.info_how_it_works` (известный v3 → v4; неизвестный прод-текст → force-delivery с `prev_html`).
4. **Санитайзер/рендер:** `sanitizeHtml` (DOMPurify default) разрешает blockquote/h1/h2 — отдельный
   allowlist не добавляем, но обязателен рендер-тест и CSS `.info-html blockquote`.
5. Структура вкладок/меню не меняется. Флагов нет; Δ каталога = 0.

## Consequences

- Справка становится единообразной и актуальной; канон v4 зафиксирован и воспроизводим.
- Появляется обязанность синхронизировать 3 артефакта (код ↔ `info_text.md` ↔ PG) при каждой
  будущей правке — уже покрыто байт-тестом.
- Текст про System 2 придётся сверить после реализации F3–F5 (риск R4).

## Alternatives

- **Точечно поправить блоки, оставив h4/h5** — отклонено: нарушает правило ТЗ «только h1/h2».
- **Хранить Справку только в PG (убрать код-канон)** — отклонено: ломает D224/сид/миграцию.
- **Добавить allowlist DOMPurify** — пока не требуется (дефолт уже разрешает нужные теги);
  оставлено как contingency.

## Cost ×2 / бюджет / латентность

Не применимо. Бюджет: одноразовая PG-миграция (идемпотентная, DML-only, без DDL).

## Kill-switch / Fallback / Rollback

- **Kill-switch:** `POST /api/info/reset-canon` (RBAC `edit_info`).
- **Fallback:** неизвестный прод-текст сохраняется в `prev_html`, не затирается.
- **Rollback:** `git revert` + обратная канон-миграция (v4→v3, `INFO_CANON_VERSION=3`).

## Canon migration

**Обязательна (D224 + ADR-1013-3):** бамп `INFO_CANON_VERSION`, новый слепок, синхрон
`info_text.md`, идемпотентная PG-миграция, байт-тест и тест v3→v4.

## Human Gate — ЗАКРЫТО владельцем (UPD3 §4)

- **Д-11** → **полная переписка** по регламенту (`<blockquote>`, только `<h1>`/`<h2>`, без
  точек/запятых/«или» между примерами, транскрипт vs выжимка, убрать п.11 «Безлимиты»);
  `h4`/`h5`-вёрстка не используется; System-2-блок — без деталей реализации.
