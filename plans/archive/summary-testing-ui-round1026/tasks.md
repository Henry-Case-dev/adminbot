## Приёмочные инварианты S9 (нарушение = НЕ принято; трассировка: §ТЗ + ADR-1026-8)
1. **Маршрут §113 (ADR-1026-8 D1):** вкладка **«Тестирование»** (`#/modules/summary/testing`) — tab-id **уже объявлен** (`WORKSPACE_TABS.mod_summary`), **новый не вводится**; форма = выбор чата + временного окна + кнопка «Проверить пайплайн»; Telegram-команда **не вводится**.
2. **Backend (D1):** новый роутер `web/api/summary_test.py` (включается в `web/app.py`); `web/api/routes.py` — **вне diff**; флаг `SUMMARY_TEST_UI_ENABLED` (env-only ClassVar, default ON); OFF → 404 на API + секция UI скрыта.
3. **Dry-run: 0 публикаций (D2).** За тестовый прогон **ни один** публикующий вызов не выполняется (`send_rich_message`/`send_text`/`sendMessage`/`build_cover_media`/`_deliver_*`/`_send_*`/`_plain_fallback`); «Предпросмотр Rich Message» — **локальный** `format_rich_html`/`format_plain_html`, не отправка.
4. **Dry-run: 0 изменений памяти (D2).** Запрещены `summary_memory.*`, `memorize_facts`, `remember_user_fact`, `memorize_self_reply`, `get_window_messages`, `_build_running_summary`, досье/граф-записи, `INSERT/UPDATE/DELETE`; окно — **read-only** `db.get_smart_window`; S1/S2 — чистые функции.
5. **`generate_image` (§113/§104, D3):** в тестовом режиме **не вызывается**; отдельное подтверждение — только `POST /api/summary/test/{test_id}/cover {confirm:true}` через **существующий** `generate_image_verbose` (0 LLM-вызовов), превью — `GET .../cover-image` (no-store, серверный temp-файл задания); модель/провайдер/ключи/промпт обложки — **не трогать**.
6. **ON-путь только внутри dry-run (D2):** тест напрямую вызывает `run_l1`/`run_l2` (не зависят от kill-switch); глобальный `SUMMARY_HYBRID_L2_ENABLED`/per-chat override **не читаются и не пишутся**; ровно **2** физических LLM-вызова; OFF-путь живого пайплайна — **байт-в-байт**.
7. **Показ артефактов §113 (D3):** исходные сообщения → результат фильтра → кластеры L1 (§95) → пакет §96 → статья L2 (§98/§99) → **Rich + plain** (§105); артефакты — **реальные** объекты S1–S5; усечение срезами (`totals`/`has_more`, per-message cap 2000 символов, пагинация `offset/limit`).
8. **Метрики §112 (D3):** исходных/после фильтра/восстановленных, процент отсева, тем, токены L1/L2, стоимость L1/L2, общая, время, статус обложки, **статус публикации «не публиковалось (dry-run)»**. Источник — `llm_usage_events` (PG) по `correlation_id` + `llm_pricing`; неизвестная стоимость → **«Нет данных»** (не `$0`); безлимит (`-1`-sentinel) → **«Без лимита»**.
9. **API (D4):** `POST /run` → 202 `{test_id,status:"running"}` (`asyncio.create_task`) + опрос `GET /{test_id}`; store — **in-memory** (TTL 15 мин, ≤20, **без persistence/DDL**); rate-limit ≥10 с на `(user,chat)`; повтор/параллельный тот же `(user,chat)` → 409; ≤2 одновременных → 429; права — **global admin**, `chat_id` валидируется против доступных областей (reuse `GET /api/access/chats`).
10. **Fail-closed §106 (D5):** коды `TEST_WINDOW_EMPTY`/`TEST_L1_*`/`TEST_PACKAGE_NOT_DELIVERABLE`/`TEST_L2_*`/`TEST_LLM_UNAVAILABLE`/`TEST_FORMAT_ERROR`/`TEST_NO_GENERATOR`; публикации/записи нет; без бесконечных повторов; «Ошибка Саммари» без деталей запрещена (§109).
11. **Границы (D6):** S6 (публикационный адаптер) — **GATED**, не вызывать; `run_id`/log viewer → **S7** (используется существующий `correlation_id`); ExecutionGraph → **S8** (узлы не создаются, только аддитивные `SUMMARY_TEST_*`); §85 — вне S9.
12. **Инварианты проекта (D7):** **Δ DDL=0**; **Δ каталога=0** → **F8 НЕ переиздаётся (N/A)**; CSP/zero-build; **R17/R18**; §104/`generate_image`/обложка/XML/`routes.py` — вне diff; 0 новых внешних зависимостей.
13. **Deploy (D8):** **ДА — bump `APP_VERSION` 2.58.24 → 2.58.25** + `README.md` + cache-bust; перед деплоем — минимальные §114-тесты; подтвердить, что `SUMMARY_HYBRID_L2_ENABLED` **не** включён глобально; hot-OFF — `SUMMARY_TEST_UI_ENABLED=false`; откат — тег `pre-round1026-s9` + `git revert`.
14. **Сценарии §114 (spec §9):** SC-01…SC-15 — параллельные разговоры, короткие важные ответы, длинные сообщения, `reply_to`, упоминания, почти пустой лог, невалидный JSON L1, ошибка LLM, ошибка обложки, Rich с H1, plain fallback; тестовые результаты **не публикуются**.
