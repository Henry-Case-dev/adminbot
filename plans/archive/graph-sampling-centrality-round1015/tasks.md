## 0. Цель

Заменить случайную (`ORDER BY degree DESC` с фактически случайным составом при равных degree /
отдачу разрозненных узлов) выборку графа на связную: топ-50 узлов по **Degree Centrality**,
затем **все смежные** к ним узлы и рёбра; **сироты** (узел без единого ребра внутри итоговой
выборки) исключать из JSON. Это чинит «сетку из разрозненных точек» на фронте (`vis-network`).

**Текущее состояние (Step 0):** `services/database.py:3610-3665` `graph_snapshot` уже фильтрует
`degree >= 1`, сортирует `ORDER BY degree DESC, id ASC` и режет cap `max_nodes`/`max_edges`;
константы API `web/api/memory_agi.py:58-59` (`GRAPH_MAX_NODES=120`, `GRAPH_MAX_EDGES=240`);
эндпоинт `web/api/memory_agi.py:500-520`. Проблема: cap применяется к «сырым» узлам ДО раскрытия
окрестности, и результат не гарантирует связность.
