# ADR-1015-2 — Выборка графа памяти: Degree Centrality + окрестность + очистка сирот

- **Статус:** Принято (Step 2 @Architect, 14.09.2026)
- **Раунд:** 10.15, фича F1 `graph-sampling-centrality-round1015` (T-1549)
- **Контекст:** `graph_snapshot` (`services/database.py:3610-3665`) отдавал разрозненные узлы: cap `LIMIT max_nodes` применялся к «сырым» узлам до раскрытия окрестности; `_graphSignature`-фронт рисовал сетку без связей; техдолг S10.13-14 (висячие рёбра после cap).

## Решение

1. **Degree Centrality = неевзвешенное число инцидентных рёбер** (каждое ребро один раз, `origin != 'bot_direct_reply'`, chat-скоуп). Не сумма `weight`: топология важнее малых целочисленных весов; детерминизм.
2. **Сиды = топ-`seed_nodes` (=50)** по `degree DESC, id ASC`. `seed_nodes` — **код-константа** `GRAPH_SEED_NODES` в `web/api/memory_agi.py` (каталог-Δ=0; прецедент `GRAPH_MAX_NODES/EDGES` из ADR-1013-2).
3. **Раскрытие окрестности:** все узлы, инцидентные сидам (оба направления), + все рёбра с **обоими** концами внутри итогового набора.
4. **Очистка сирот:** узел без единого ребра ВНУТРИ выборки (после edge-cap) исключается; повторный фильтр рёбер не требуется (оба конца ⊆ node-set).
5. **cap `120/240` — финальный**, применяется ПОСЛЕ раскрытия и очистки; `truncated` честный.
6. **`degree` сохраняется** в JSON-узле (зависимость фронта `_graphSignature`).

## Альтернативы и отклонения

- **Взвешенный degree (Σ weight):** отклонено — усложняет SQL, не меняет топологию, эмоциональнее к шумным весам.
- **Обрезка до крупнейшей компоненты:** отклонено (F1-Q3) — теряются реальные под-сообщества; все достижимые из сидов компоненты сохраняются.
- **Каталог-ключ `memory.graph_top_seed_nodes`:** отклонено — не требует рантайм-тюнинга, лишний Δ каталога.
- **Коррелированный `COUNT(*)` на узел** (текущий код): устранён — `GROUP BY` по UNION индексированных выборок; ожидаемый план `SEARCH edges USING INDEX idx_edges_*`.

## Последствия

- Контракт `/api/memory/graph` совместим (только уточнение состава; `limits` без изменений). Каталог-Δ=0, DDL нет, read-only.
- Производительность: O(E) на запрос при `chat_id=None` (только global admin, polling 15с). При росте — кандидат на кэш (вне скоупа).
- Закрывает S10.13-14.
