# ADR-1022-2 — Рендер `limits.summary_aliases`: доказать shape, затем симметричная защита

- **Статус:** Accepted (Step 2 @Architect, 18.09.2026)
- **Фича:** F2 `urgent-summary-aliases-ui-round1022`
- **Тип:** frontend `web/**` + read-only диагноз
- **Связано:** FR-28/3.5.2 (KV-редактор), R16 (id — ключ), R17 (секреты)

## Context

Поле «Словарь алиасов имён» (`limits.summary_aliases`) пустое в UI. Step 0 подтвердил:
данные в PG **целы** (объект из 38 записей), per-chat override нет. Значит причина — рендер.
Аудит показал цепочку `PG(jsonb) → ConfigCache.normalize_value → /api/config → app.js →
kv-editor.sync()`. Узкое место: `kv-editor.sync()` (`app.js:6334-6343`) принимает **только
object**, а фронт при `widget='keyvalue'` строку-JSON не парсит (`app.js:3543-3552`).
`_cast_to_type` для `json` (`param_catalog.py:2146-2156`) при двойном кодировании вернёт
**строку**, что даёт ровно наблюдаемый симптом.

ТЗ предлагает restore из бэкапа — но это перезапишет свежий объект. ТЗ упоминает
«React/Vue компонент» — в проекте React нет, есть Vue-рендер `index.html`.

## Decision

1. **Сначала доказательство, потом фикс.** T-2028 фиксирует READ-ONLY фактический
   `type`/`widget`/`typeof value`/`keys_count` для `SUMMARY_ALIASES`. Без подтверждения
   гипотезы изменения не вносятся.
2. **Restore из бэкапа запрещён** (данные целы).
3. **Симметричная защита:**
   - backend — для `keyvalue` отдавать объект (распаковка строки-JSON до dict; при неудаче
     пустой объект + WARNING), не задевая остальные `json`-виджеты;
   - frontend — `kv-editor.sync()` принимает object **или** строку-JSON (`JSON.parse`).
4. **Cache-bust** для устранения stale JS.
5. `services/param_catalog.py` — read-only; **Δ каталога = 0**.

## Consequences

- Симптом устраняется независимо от того, строка или объект приходит (защита с двух сторон).
- Добавляется обязанность регресс-проверки остальных `json`/`list`-виджетов.
- Возможен «двойной фикс» (и backend, и frontend) — оправдан как защита от регрессии
  сериализации в будущем.

## Alternatives

- **Только frontend-парсинг** — дешевле, но не защищает других потребителей `/api/config`.
- **Только backend** — не покрывает stale/иные фронты (TMA WebView).
- **Restore из бэкапа (ТЗ)** — отклонено, уничтожит свежие 38 записей.

## Cost ×2 / бюджет / латентность

Не применимо (frontend; +1 `JSON.parse`). Регресс-бюджет: JS-UNIT-гейты без изменений Δ каталога.

## Kill-switch / Fallback / Rollback

- **Fallback:** при неудачном `JSON.parse` — пустой список (текущее безопасное поведение).
- **Rollback:** `git revert` (web-only). Данные не трогаются.

## Canon migration

**Не требуется.**

## Human Gate — ЗАКРЫТО владельцем (UPD3 §4)

- **Д-4** → данные в БД **есть**; обязателен **фикс рендера JSON-объекта на фронте**
  (`kv-editor.sync()` принимает object **или** строку-JSON); backend-распаковка строки-JSON
  остаётся defense-in-depth; **restore из бэкапа запрещён**.
