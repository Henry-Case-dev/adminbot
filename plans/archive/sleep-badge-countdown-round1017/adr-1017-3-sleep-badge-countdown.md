# ADR-1017-3 — Бейджи Сна: источник «сейчас», формат остатка, поведение `enabled=false`

> **Статус:** Accepted (Step 2 @Architect, 14.09.2026). **Раунд:** 10.17. **Фича:** F3 `sleep-badge-countdown-round1017` (T-1685).
> **Связано:** `status-graph-ui-relocation-round1015` §3а (оконная семантика), UPD3 стр. 158.

## 1. Контекст

После 10.15 бейджи вне фазы показывают **целевой час** (`«Сон через 11:00»`) и «выключен». UPD3 требует: вне фазы — **остаток до начала**, в фазе — **время окончания**; «выключен» убрать; эмодзи не трогать; окна 10.15 сохранить.

Открытые вопросы @PM: формат остатка, точность, поведение `enabled=false`, tick.

## 2. Решение

1. **Источник `now` — серверный `cognition.generated_at`** (уже отдаётся `memory_agi.py:545`). Не локальные часы устройства (устойчиво к рассинхрону TZ/времени клиента).
2. **Формат остатка — компактный `Xч Yм` / `Yм`** (`2ч 15м`, `15м`, `0м`): короткий для мобильного бейджа, совпадает с DoD PM. Округление **вниз** до минут; кламп `>=0`.
3. **`enabled === false` не показывает «выключен».** Согласно UPD3 бейдж показывает остаток, но **без свечения** (`badge-muted`) — сохраняется требование 10.15 «нейтральный текст, если активной фазы нет». Активная фаза при `enabled=false` невозможна (окно гасится), кроме фактического `running`.
4. **Активная фаза:** класс со `glow` (dream `badge-ok glow`, deep `badge-info glow`), текст `до HH:MM` через существующий `fmtClock(active_until)`.
5. **Эмодзи не меняем** (`☀️/🌙/🌅/🌌`); «Лимит сна исчерпан» (dream) сохраняем.
6. **Без живого tick-таймера.** Остаток обновляется на каждом рендере от `generated_at`; «пробуждение» — по существующему polling `cognition/status`. Уменьшает объём правок и риск утечки интервалов.

## 3. Рассмотренные альтернативы

| Вариант | Вердикт |
|---|---|
| `now = Date.now()/1000` | **Отклонён:** рассинхрон с серверным `_in_hour_window`/`next_*` |
| Формат `2:15` / `осталось 2ч` | **Отклонён:** двоеточие спутать с временем; «осталось» удлиняет бейдж |
| Секундная точность | **Отклонён:** шум/лишние рендеры без пользы |
| `enabled=false` → «выключен» (оставить) | **Отклонён:** прямо противоречит UPD3 |
| `enabled=false` → скрыть бейдж | **Отклонён:** теряется информация о расписании; UPD3 требует остаток |
| Живой `setInterval` tick | **Отклонён в этом раунде:** дублирует polling, риск утечки; при желании — отдельная задача |
| Аддитивное поле API `seconds_left` | **Отклонён:** усложняет API и дублирует `generated_at`+`next_*` (достаточно арифметики на фронте) |

## 4. Последствия

- (+) Единый серверный `now`; минимальные правки во фронте (2 функции + 1 хелпер); API не меняется.
- (+) Оконная семантика 10.15 не затронута; эмодзи/классы совместимы.
- (−) Остаток может «застыть» между poll-ами (до нескольких минут) — принято как несущественное для фазового бейджа.
- Инварианты: каталог Δ=0, SQL/DDL нет, порядок роутеров `bot.py`, R17.
