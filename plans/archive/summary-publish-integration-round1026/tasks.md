## Приёмочные инварианты S6 (нарушение = НЕ принято; трассировка §ТЗ + ADR-1026-11 D1–D10 + SC-01…SC-20 спеки)
1. **SC-01 — reuse `sendRichMessage` (§100/D1/D2/D4):** публикация — через **существующий** `send_rich_message`; summary-rich = `html` (ровно одно поле `InputRichMessage`); второго rich-механизма нет; `telegram_send.py` — **вне diff** (reuse без изменений). **REQ-S6-01; T-3438, T-3453.**
2. **SC-02 — «обложка сверху → H1 после изображения» (§101/D2/D3):** rich-путь (ON и OFF): `<img>` → **`<h1>title</h1>`** → `<p>`; H1 **не подменяется жирным**; обложка остаётся сверху; в plain настоящего H1 нет; источник заголовка — детерминированно (spec §5.3: digest → первая короткая строка → первое предложение → нет заголовка; тело не обрезается; выдуманный заголовок запрещён). **REQ-S6-02; T-3439, T-3449.**
3. **SC-03 — §102 абзацы/акценты/экранирование (D2/D4/D7):** абзацы `<p>`, ≤1 `<b>` на абзац; только `img/h1/p/b`; без неподдерживаемых тегов; без смешивания HTML и MarkdownV2; экранирование `& < > " '`, Unicode, эмодзи, ссылок; **L-R1026S5-5** закрыт (`sanitize` в `chunk_plain_blocks`, порядок sanitize → clean → escape; байт-тест «egress-guard — no-op на выводе `format_rich_html`»); **L-R1026S5-6** исправлен (`'` внутри слова — не кавычка). **REQ-S6-03/-10; T-3440, T-3449.**
