## Приёмочные инварианты MCA-04b (нарушение = НЕ принято)

1. **Три режима включены:** новые данные; восстановление при востребованном чтении старой записи; фоновый проход по архиву. Последний — чтобы не изучать только популярные темы. **MCA04-R5; T-3895, T-3896, T-3897.**
2. **Единый контракт full rebuild:** область `chat/subject`, заданный диапазон, `snapshot boundary`, версия экстрактора, устойчивый курсор. **Live-window limit ≠ предел пересборки**; новые сообщения после границы снимка догоняются инкрементально. **MCA04-R8; T-3893, T-3895.**
3. **Учёт полноты субъекта:** собственные сообщения участника + надёжно разрешённые упоминания другими + reply-контекст; отбор только по имени/автору недостаточен; **короткие ответы не отбрасываются механически по длине** («да» подтверждает факт из вопроса; без контекста — не факт); для бесшумных — идентичности всего нужного scope, не только ростер говорящих. **MCA04-R8; T-3893.**
4. **Batch-состояния различимы:** `queued/running/paused/interrupted/failed/completed` (или эквивалент). **Budget exhaustion, недоступность модели, parse error, отмена, рестарт ≠ «всё обработано»**; неполные диапазоны остаются в очереди; **`processed` не подменяется `total`** при финализации; **отключение/неисчерпание бюджета-настройки не подменяет статус** на `completed`. **MCA04-R8/MCA04-R6; T-3894, T-3898.**
5. **Checkpoint/идемпотентность/сортировка:** checkpoint продвигается **после фиксации**; повтор после сбоя идемпотентен (перезапуск не удваивает связи); сортировка **стабильным ключом** (`(timestamp, id)` или эквивалент), **без OFFSET** по изменяющимся миллионам строк. **MCA04-R5/R8; T-3894, T-3897.**
6. **Никакого «архив в RAM / одним промптом»:** порции до 500 сообщений с дальнейшим делением по токенам/эпизодам; результаты извлечения — на диск по batch; иерархический синтез по субъекту и периодам; новый live-batch **обновляет** накопленную картину, не заменяет её портретом последних 300 сообщений. **MCA04-R5/R8; T-3897, T-3898.**
7. **Приоритет прямых ответов, backlog на диске:** фоновая пересборка не блокирует direct-flow; 1 активный LLM batch на чат; конфигурация увеличиваема по ресурсам; **проход уже разрешён** (не требует повторного согласования) и resumable. **MCA04-R5; T-3897, T-3898.**
8. **Embeddings:** не перевекторизовывать без установленной необходимости; сравнивать только внутри совместимого fingerprint; при недоступной старой модели — сохранять старый индекс и лексические/метаданные пути; перестройка несовместимого индекса — **отдельный resumable job с причиной**; активация нового поколения — single-writer (N-MCA07-1). **MCA04-R5/R6; T-3907.**
9. **Исправление накопленных данных:** новые правила **не очищают** старые `confirmed` автоматически; безопасная повторная классификация производных, исправление subject, отделение общих знаний от личных фактов; **исходные сообщения, ручные правки и защищённые сведения сохраняются**; записи без восстановимого источника → `unknown`/quarantine, **не** ложное подтверждение и **не** удаление всей памяти. **MCA04-R9; T-3899.**
