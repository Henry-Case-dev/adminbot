## Приёмочные инварианты MCA-02 (нарушение = НЕ принято)

1. SafeFetcher: разрешены только HTTP/HTTPS; URL нормализован; **встроенные credentials запрещены**. **MCA02-R1; T-3802.**
2. Блокируются `localhost`/private/link-local/reserved и адреса инфраструктурных **metadata endpoint** (IPv4 **и** IPv6). **MCA02-R1; T-3803.**
3. Проверяется **каждый redirect** и **фактически используемый адрес подключения** (предварительная DNS-проверка + независимый resolve недостаточны против rebinding). **MCA02-R1; T-3803.**
4. Для медиа-подпроцессов/yt-dlp/прокси и обходящих SafeFetcher клиентов — **эквивалентный контроль** назначения или сетевой **egress** (защита одного `httpx`-клиента не защищает весь процесс). **MCA02-R1; T-3804.**
5. Доверенные API провайдеров и локальные служебные соединения — **отдельная конфигурация** (глобальный запрет внутренней сети не ломает их). **MCA02-R1; T-3803.**
6. Потоковые лимиты переданных **и распакованных** байтов, `timeout`, параллелизм; `len(response.content)` после полной загрузки **недостаточен**; большой stream блокируется **без полного чтения в RAM**. **MCA02-R1; T-3804, T-3810.**
7. Крупные видео — **отдельный профиль загрузки на диск** (совместим с нынешними рабочими размерами); лимит HTML-страницы к видео не применяется. **MCA02-R1; T-3804.**
8. Ошибка возвращает **код, стадию и понятную причину**; секретные query-параметры URL, cookies, proxy credentials **маскируются**. **MCA02-R1, GEN-R14/R17; T-3805.**
9. **Cookies/профиль не удаляются**, если это нарушает скачивание/транскрибацию/субтитры/выжимку; исключение из упаковки **не** удаляет файл на сервере; при невыясненной зависимости — `cleanup_deferred_dependency_unverified`, runtime-файлы остаются. **MCA02-R2, GEN-R13; T-3808.**
10. Проверяется **авторизованный** видеосценарий (субтитры/скачивание/транскрибация/выжимка), а не только публичный ролик. **MCA02-R2; T-3809.**
11. Действующие сессии автоматически не отзываются; при подтверждённом раскрытии — сообщить владельцу, сохранив работоспособность; **значения секретов не в отчёт**. **MCA02-R2; T-3808, T-3814.**
12. Deploy `DEFERRED_TO_RELEASE`; kill-switch env-only default ON, OFF = паритет baseline; сеть вне транзакции записи. **T-3806, T-3812, T-3813.**
