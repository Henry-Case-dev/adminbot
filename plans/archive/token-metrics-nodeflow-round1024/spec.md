# Spec: token-metrics-nodeflow-round1024 (F3)

> Раунд 10.24 (UPD2 п.1) · P1 · UI/web · Владелец: F3 · Ступень `web/**`: **1-я**
> **ADR:** ADR-1024-7 (AMEND ADR-1023-7 UI-объём)
> **Сквозной слой:** `plans/features/round1024-web-architecture.md`

## 1. Цель

Заменить «плоские бейджи» последнего вызова в разделе «Сводка» на **настоящее
визуальное дерево вызова (Node Flow)**: `[Запрос юзера] → [Синтезатор
(Вход/Выход/Цена)] → [Вербализатор (Вход/Выход/Цена)] → [Итог]`. Плюс — осмысленный
«График расходов». Нейминг — чистый русский.

| API `GET /analytics/usage/latest` → `{correlation_id, ts, steps[], total}`; `steps[]` = `{ts,module,step,tool_name,source,model,input_tokens,output_tokens,tokens_estimated,cost_usd,price_known}` | `web/api/analytics.py:139-170` |

**API менять не нужно** — данных достаточно. Δ DDL = 0, Δ каталога = 0.

## 3. Требуемое поведение

### 3.1. Структура дерева (детерминированно из `steps[]`)

1. **Корень** — `[Запрос юзера]` (нода-источник, без чисел; подпись — время `ts`/«последний вызов»).
2. **Слой Синтезатор** — нода шага `stage1`. Показывает **Вход / Выход / Цена**.
3. **Инструменты** — шаги `tool` отображаются отдельными под-нодами, прикреплёнными
   к Синтезатору (tool-ветка), подпись `Инструмент: <tool_name>`.
4. **Слой Вербализатор** — нода шага `stage2`. Показывает Вход / Выход / Цена.
5. **Итог** — конечная нода с суммой `total` (токены + цена).
6. **Не-двухслойные вызовы** — если в `steps[]` нет `stage2` (или набор неполный):
   - `single` → линейная цепочка `[Запрос юзера] → [Один вызов] → [Итог]`
     (без ложного ветвления «Синтезатор→Вербализатор»);
   - `image` → `[Запрос юзера] → [Изображение] → [Итог]` (цена/токены обычно 0 —
     показывать «—»/`0`, если `price_known=false`);
   - смешанный набор строить по фактическим шагам, каждый нераспознанный `step`
     — отдельная нода-«плашка» без рёбер ветвления.
7. **Пусто/ошибка** — `steps = []` → «Вызовов ещё не было». Ошибка сети/API →
   fail-open, блок не ломается (текущая логика `catch → null` сохраняется).

### 3.2. Что на каждой ноде

- Заголовок: человекочитаемая метка слоя (`Синтезатор`, `Вербализатор`,
  `Инструмент: <name>`, `Один вызов`, `Изображение`).
- Строки: **Вход** (`input_tokens`), **Выход** (`output_tokens`), **Цена** (`cost_usd`).
- Точное число токенов — `fmtExactTokens` (пробел-разряды), оценка → пометка «оц.»
  при `tokens_estimated=true`; при `price_known=false` — «цена неизвестна» вместо `$0`.
- Итоговая нода — суммарные вход/выход/цена из `total`.

### 3.3. Визуализация (CSS)

- Дерево — **CSS Grid/Flexbox**, без JS-библиотек графов и без CDN.
- Рёбра — CSS-псевдоэлементы (`::before/::after`) либо тонкие `div`-коннекторы;
  ветвление Синтезатор→Инструменты — вертикальный список под-нод справа/снизу.
- Адаптив для узкой TMA: на `< 420px` — вертикальный стек, рёбра скрываются,
  порядок сохраняется.
- Уважать `prefers-reduced-motion` (если есть анимация появления — отключить).

### 3.4. График расходов

- Заголовок «График расходов»; селекторы `День/Неделя/Месяц` — как есть.
- Столбики — уже существующие `tokenSeriesBars()`, но с **подписями оси** (первый
  и последний бакет, либо подписи под столбиками при узком наборе), tooltip —
  существующий `title` (`bucket · цена · вызовы`). CSS, без чарт-библиотек.
- Пустое состояние: «За период данных нет».

### 3.5. Нейминг (обязательный)

| Было (мусорный) | Стало |
|---|---|
| «Token Metrics» / «последний вызов · графики» | **«Аналитика токенов»** |
| строка бейджей «Слой 1 → Слой 2 → Итого» | блок **«Последний запрос (Дерево вызова)»** |
| столбики без подписи | **«График расходов»** |

Технический жаргон (`stage1/stage2/correlation_id`) наружу не выводится.

## 5. Контракты

- **Вход:** только `GET /api/analytics/usage/latest` и `/summary` (без изменений).
- **`tokenFlowTree()`** возвращает: `{ nodes: [{id, kind:'root'|'synthesizer'|'tool'|'verbalizer'|'result'|'single'|'image', title, input, output, cost, estimated, price_known, note}], edges: [{from,to}], hasBranch: bool }`.
- **RBAC:** блок виден только `isGlobalAdmin` (как сейчас).
- **Fail-open:** любой сбой API/данных → пустое состояние, без исключений в рендере.
- **R17:** наружу только числа/токены/цены/имена инструментов; без промптов.

## 6. Тесты

- **JS (`tests/js/round1024_nodeflow_test.js`, node):**
  - двухслойный набор `[stage1, stage2]` → узлы root/synthesizer/verbalizer/result,
    рёбра `root→synthesizer→verbalizer→result`, `hasBranch=false`, сумма = `total`;
  - `[stage1, tool, stage2]` → tool-нода прикреплена к synthesizer (ветвление);
  - `[single]` → `root→single→result`, **нет** ложного verbalizer;
  - `[image]` → `root→image→result`, `price_known=false` → «цена неизвестна»;
  - пустой `steps` → пустое состояние; `tokens_estimated=true` → «оц.»;
  - `node --check web/app.js`.
- **Python:** `test_webapp_analytics_api` без изменений (API не трогаем);
  smoke-маркер: русские подписи присутствуют в `index.html`, англо-жаргон
  («Token Metrics») отсутствует.
- **Гейт:** `tests/js/vue_mount_test.js` зелёный (нет новых inline-скриптов).

## 8. Критерии приёмки

- Дерево читается как граф (узлы + рёбра), а не как строка бейджей.
- У Синтезатора/Вербализатора показаны Вход/Выход/Цена; есть итог.
- Не-двухслойные вызовы не рисуют ложную ветку.
- Подписи — «Аналитика токенов», «Последний запрос (Дерево вызова)», «График расходов».
- Пустые данные/ошибка не ломают блок; адаптив на узкой TMA.
- JS-гейт зелёный; pytest не затронут; Δ DDL=0, Δ каталога=0.

## 9. Флаг и откат

- Флаг `TOKEN_FLOW_NODEFLOW_ENABLED` (env-only `ClassVar`, **default ON**) через
  `GET /api/me.ui_flags`; OFF → прежние бейджи.
- Откат: флаг OFF / `git revert`. Миграций нет.
