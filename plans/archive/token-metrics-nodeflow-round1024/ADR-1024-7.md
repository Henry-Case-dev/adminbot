# ADR-1024-7 — Node Flow последнего вызова System 2 (F3)

> **Статус:** proposed → применяется в раунде 10.24.
> **AMEND:** ADR-1023-7 (UI-объём «Token Metrics» признан «текстовыми строками, а не дашбордом»).
> **Слой:** web (`web/index.html`, `web/app.js`, `web/static/app.css`). Δ DDL=0, Δ каталога=0.

## Контекст

В раунде 10.23 (F7/ADR-1023-7 §2.8) в «Сводке» появился блок «Token Metrics»: строка
плоских бейджей `«Слой 1: N т.» → «Слой 2: M т.» → Итого $X` + простейшие столбики.
API `web/api/analytics.py` отдаёт полноценный `steps[]` (`module/step/tool_name/
input_tokens/output_tokens/cost_usd/price_known/tokens_estimated/source`), но UI
использует только сумму токенов на шаг и не показывает вход/выход/цену по слоям.

Владелец (UPD2 п.1) отклонил это как дашборд: «это просто текстовые строки… нужно
нормальное визуальное дерево (Node Flow)». Требование — чистая русская терминология.

Ограничение платформы: TMA-страница работает под CSP `script-src 'self'`, Vue 3
подключается **self-host** (zero-build, runtime-компилятор in-DOM); `tests/js/
vue_mount_test.js` жёстко запрещает inline-исполняемые скрипты и внешние CDN.
Значит, любая JS-библиотека графов либо нарушит CSP, либо потребует self-host и
увеличит бандл.

## Решение

1. **Только CSS для графа.** Дерево строится из семантической структуры (root/synth/
   tool/verbalizer/result) обычными `div`-нодами; рёбра и ветвление — CSS
   (Grid/Flexbox + `::before/::after`/тонкие коннекторы). Никаких graph-библиотек,
   никаких CDN. Это сохраняет CSP-инвариант и вес бандла.
2. **Структура — детерминированная проекция `steps[]`** (см. spec §3.1), а не
   «две колонки всегда»:
   - двухслойный вызов (`stage1`→`stage2`) даёт ветвление с tool-под-нодами;
   - `single` (fallback-путь) и `image` дают линейную цепочку без ложного
     «Синтезатор→Вербализатор»;
   - нераспознанные шаги — отдельные плашки.
3. **Нода = Вход/Выход/Цена** + пометки «оц.» (`tokens_estimated`) и «цена
   неизвестна» (`price_known=false`). Это ровно то, что владелец просил у слоёв.
4. **Нейминг:** «Аналитика токенов» / «Последний запрос (Дерево вызова)» / «График
   расходов»; технический жаргон (`stage1`, `correlation_id`) наружу не выводится.
5. **API не меняется** — данных уже достаточно; изменение чисто read-side UI.
6. **Kill-switch** `TOKEN_FLOW_NODEFLOW_ENABLED` (env-only, default ON) через единый
   `ui_flags` (ADR-1024-13); OFF → прежние бейджи байт-в-байт.

## Последствия

**Плюсы:** настоящий дашборд-виджет; нулевой риск для CSP/бандла; API и телеметрия
нетронуты; `physical-two-call-pipeline` не затронут (только чтение).
**Минусы/долг:** ручная CSS-вёрстка рёбер менее гибкая, чем библиотека (при будущем
усложнении графа потребуется пересмотр); адаптив на очень узких экранах даёт
упрощённое (стековое) представление — сознательно.
**Тесты:** JS-юнит на `tokenFlowTree()` (двухслойный/tool/single/image/пусто) —
плоские бейджи больше не считаются «готово».

## Альтернативы

| Альтернатива | Почему отклонена |
|---|---|
| Лёгкая JS-библиотека графов (mermaid/cytoscape/d3) | CSP/CDN-запрет или self-host + рост бандла; overkill для 3–5 нод |
| CSS Grid + `<canvas>` | требует JS-отрисовки рёбер; нет выигрыша над CSS-коннекторами |
| Оставить бейджи, добавить вход/выход текстом | прямо отклонено владельцем («не дашборд») |
| Менять API (отдавать готовое дерево) | нарушает «сначала UI-объём» и R16-минимализм; API уже полон |
