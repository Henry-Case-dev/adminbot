# ADR-1022-1 — Боевой rebuild досье целевого чата: вариант «а» (окно 180 дней) + confirmed-cleanup с JSONL-архивом, без снятия инварианта сырой истории

- **Статус:** **Accepted** — решение владельца UPD3 (18.09.2026); оформлено Step 2b @Architect (18.09.2026)
- **Фича:** F1 `urgent-rebuild-dossiers-target-chat-round1022`
- **Тип:** data-migration / CLI + ops
- **Связано:** ADR-1021-5 (rebuild/sanitize), ADR-1013-3 (канон-миграции), ADR-1020-5 (снапшот/retention), N10.21-2, F8 (ADR-1022-8)
- **Карта гейта:** `plans/features/round1022-human-gate-map.md`

## Context

ТЗ UPD2 требовало «жёстко запустить» `manage.py memory rebuild-dossiers` для чата
`-1002661910336` и «снять любые инварианты, мешающие очистить сгенерированный мусор».
Аудит кода показал: (1) guard целевого чата — opt-in, а не запрет; (2) инвариант сырой
истории и есть механизм «кроме удаления истории»; (3) новый Critical-риск over-delete, т.к.
rebuild удаляет производные **до** пере-сборки, а пере-сборка читает только окно (было 168 ч).

UPD3 (после Human Gate) утвердил **вариант «а»**: жёсткая очистка **confirmed**-мусора,
привязанного к участникам, с предварительным JSONL-архивом, затем двухслойная пересборка
по **180-дневному** окну. Диагностика подтвердила: карточку «Досье» формирует
`get_persona_card` (`database.py:4410-4437`) по `target_user = name AND status='confirmed'` —
именно эти строки и есть видимый мусор.

## Decision

1. **Инвариант сырой истории сохраняется неприкосновенно.** `RAW_HISTORY_TABLES`,
   `assert_derived_table`, `_guarded_delete` не трогаются (Д-2).
2. **`--target-chat`** — операторский shortcut для `--chat <LEGACY_TARGET_CHAT_ID>
   --allow-target-chat`; `--all` целевой чат по-прежнему исключает.
3. **Окно боевого прогона — 180 дней (4320 ч)** по умолчанию (Д-3). `effective_window =
   max(args.window_hours, ceil((now − oldest_created_at)/3600) + 24)`; `--window-hours 0` —
   без ограничения по времени (в пределах `max_msgs`). Отчёт: `window_hours_used`, `source_age_days`.
4. **confirmed-cleanup (новое, UPD3 §1).** Новый примитив
   `cleanup_confirmed_dossier_facts(...)` в `services/memory_rebuild.py`. **Скоуп удаления ровно:**
   `chat_id = :chat AND kind = 'fact' AND status = 'confirmed' AND target_user IS NOT NULL AND
   target_user != ''` (+ `target_user = :name` для F8). **Границы:** beliefs/paradigms
   (`kind='belief'`) не трогаются; `nodes`/`edges` не мутируются; `persona_dossier_overrides`
   не трогаются; `smart_messages`+FTS/vec неприкосновенны; факты из `source_ids` живых
   убеждений исключаются (`protected_belief_sources`). Удаление — строго после JSONL-архива и
   сверки `candidates == archived`.
5. **Инвариант результата:** `reset > 0 & rebuilt == 0` → reason `rebuild_empty`, WARNING,
   ненулевой exit.
6. **Устойчивость:** чтение через снапшот SQLite (Backup API), запись в живую БД (WAL/
   `busy_timeout`) с bounded-бэкоффом; LLM-таймаут → bounded-retry + частичная деградация на чат.
7. **Fail-closed:** без авто-бэкапа и `candidates == archived` DELETE не выполняется.
8. **Порядок:** мемы/портреты (JSONL→DELETE) → confirmed-cleanup (JSONL→DELETE) → pipeline(180 дней).

## Consequences

- Боевой прогон даёт **видимый** эффект в «Досье» (мусорные confirmed-факты участников уходят).
- Появляется обязанность выводить/хранить `window_hours_used`, `source_age_days`,
  `confirmed_cleaned`, `confirmed_protected_belief_sources`.
- Принят риск R7 (удаление валидных confirmed-фактов) — компенсирован JSONL-архивом,
  защитой belief-провенанса и rollback-снапшотом F8; **beliefs/paradigms и nodes/edges не затронуты**.
- Swap-порядок («извлечь → заменить») по-прежнему не внедряется (большой рефактор).

## Alternatives

- **Только `status IN ('chat_meme','dossier_portrait')`** (прежний скоуп) — отклонено UPD3:
  не убирает видимый в карточке confirmed-мусор.
- **Удалять `kind='belief'` скопом** — отклонено: ломает мета-слой/парадигмы.
- **Полностью снять guard целевого чата** — отклонено: ломает защиту и противоречит инварианту.
- **Swap-порядок (извлечь → удалять)** — сильнее, но крупный рефактор; отложено.
- **Восстанавливать `source` belief-фактов (`unconfirmed`) вместо защиты** — отклонено:
  меняло бы мета-слой; выбран принцип «не удалять провенанс».

## Cost ×2 / бюджет / латентность

Не «×2» к 10.21 (тот же двухслойный F1-пайплайн), но линейна по окну. Бюджет —
`--limit`/`window_hours_used`. Логи — только числа/коды (R17). Латентность — десятки минут;
запуск под контролем оператора.

## Kill-switch / Fallback / Rollback

- **Kill-switch:** команда не запускается.
- **Fallback:** `--dry-run` — read-only counts.
- **Rollback:** авто-бэкап `memory_rebuild_*.db` + JSONL-архивы (мемы/портреты/**confirmed**);
  код — `git revert`. Инвариант `manual-overrides-immutable` упрощает откат.

## Canon migration

**Не требуется** (CLI/движок, не PG-сид-канон). Канон-миграции F3–F6 — отдельно.

## Human Gate — ЗАКРЫТО владельцем (UPD3)

- **Д-1 (запускать сейчас?)** → **Да**, вариант «а»; страховка — бэкап + JSONL + post-check.
- **Д-2 (инвариант сырой истории?)** → **Не снимается.**
- **Д-3 (окно?)** → **180 дней** (4320 ч), `effective_window` сохранён, `--window-hours 0` = всё.
