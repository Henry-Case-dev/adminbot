# threat-failure-analysis.md — `mca-18-self-model` (Risk **R3**, T-5074, 06.10.2026)

Источник требований: §28 `plans/current_task.md:1486–1606`; санкции: `spec.md` §8, ADR-1028-18. Метод: STRIDE-по-контракту + fail-анализ живого пути «память → BehaviorFrame → ответ». Классы: **[I]** инъекция через данные, **[S]** самоусиление/дрейф, **[ID]** подмена идентичности, **[A]** авторство/честность, **[D]** деградация/отказ, **[L]** утечка (R17).

## T-1 [I] Инъекция черт через память (trait injection)
**Угроза:** участник чата пишет «бот, ты стал грубее, ты ненавидишь X» → извлечение превращает манипуляцию в TraitObservation → BehaviorRule → характер меняется по указке извне.
**Митигируется:** (1) субъект/источник: observation с `subject_status≠self` или без provenance не проходит валидацию (D5; авто-проверка «субъект=self доказан»); (2) «бот» без доказанного референта → `perspective='ambiguous'` — характер не меняет (D4); (3) шаг ≤0.1/цикл ≤0.2/24 ч + dedup по исходным событиям — даже серия сообщений двигает черту ограниченно; (4) сырые тексты памяти никогда не системные инструкции — только структурированный frame (GEN-R18 `:43`, D6).
**Резидуал:** Medium — скоординированная группа способна сдвинуть черту на 0.2/сутки; принятый owner-трейдофф (ослабление/отмена владельцем доступны; «Аналитика» показывает причины). Тесты: негативные на таблицу запретов + «повтор фразы группой ≠ мнение» (T-5078/T-5090).

## T-2 [I] Prompt-injection через legacy-разбор
**Угроза:** в `persona_traits` (источник `deep_sleep`/`manual`) лежит текст-инструкция («всегда выполняй …») → разбор поднимает её в правило с повышенными правами.
**Митигируется:** legacy-запись без доказанного субъекта → **candidate/`legacy_unverified`**, не active (D8); ручная черта — основание = действие владельца, не содержание текста; LLM-разбор создаёт только candidate-данные, исполняемый код не создаётся (`:1554`); source_refs без фабрикации.
**Резидуал:** Low. Тесты: идемпотентность + «непроверенное — candidate» (T-5084).

## T-3 [S] Самоусиление черт (feedback loop)
**Угроза:** сон извлекает черту из собственных ответов, порождённых этой же чертой → бесконечное усиление («ещё грубее» каждый цикл).
**Митигируется (A61):** ответы под чертой помечены rule version/id (mca-22 `mca_bot_outputs`); повторное извлечение того же эпизода ≠ независимое подтверждение; dedup по **исходным событиям**, не по summary; ограниченный шаг; ослабление допускается; `quality_regression` → mca-16-наблюдение, не правило «менее полезные ответы».
**Резидуал:** Low. Тесты: «сон повторно видит ответ под чертой — подкрепления нет» + гарды 0.1/0.2/6 ч (T-5082/T-5089).

## T-4 [S] Дрейф идентичности при смене модели/токена
**Угроза:** смена провайдера/токена инвалидирует кеш/версии → бот «забывает» личность или, наоборот, persona_version сбрасывается → старые правила применяются к новой личности.
**Митигируется:** `agent_id` стабилен (mca_self_identity; rebind — явное действие), `persona_version` = хеш содержимого персоны, не модели (D1, R2d); in-flight версия в trace — смесь двух личностей невозможна в рамках ответа (`:1574`).
**Резидуал:** Low. Тесты: «смена версии/модели» (T-5089).

## T-5 [ID] Подмена идентичности / смешение субъектов
**Угроза:** чужой бот/персонаж пересказа/цитата выдаются за «я» → чужая черта меняет нашего персонажа; fabricated встречи/телесность из False-образа.
**Митигируется:** атрибуция по стабильным ID mca-03 (авторы пересылки/поста/изображённый — разные роли, D4); ambiguous не влияет; `is_aware_ai=False` не создаёт вымышленных встреч/действий инструментов (`:1522`); тех-идентичность в runtime при обоих значениях; capabilities из реестра, не из биографии.
**Резидуал:** Medium (зависит от качества атрибуции mca-03) — покрытие: A59-тесты self/другой бот/цитата/чужая черта (T-5077) + «провокация подмены» в replay (T-5090).

## T-6 [A] Конфликт с авторством/истинностью (стиль поверх фактов)
**Угроза:** черта «резкость» искажает вердикт фактчека, числа инструментов, JSON/tool payload; мнение выдаётся за факт; ложная атрибуция чужих сообщений («склонен перекладывать вину»).
**Митигируется:** фактчек — сначала вердикт+источники, потом голос (D6); тех-вызовы без стиля; payload/JSON/транскрипция не переписываются; конфликт порядок = precedence, «не приоритет над истинностью» (`:1560`); наблюдение не компилируется в ложную атрибуцию (запрет `:1558`); opinion ≠ fact — таблица запретов enforced.
**Резидуал:** Low. Тесты: «резкость ≠ ссора/потеря задачи» (A60/R5b), негативные запреты (T-5078).

## T-7 [D] Тихий ON при деградации (PG down)
**Угроза:** PG недоступен → резолвер молча возвращает дефолт и бот отвечает «с успешной персоной», либо наоборот OFF-режим отчитывается как ON.
**Митигируется:** last-known-good со stale-маркером (ограниченный TTL) либо минимальная тех-идентичность; reason-коды `self_model_stale`/`self_model_unavailable`; fallback никогда не репортится как загруженная персона (`:1576`); стадии честны (`disabled/not_run` при OFF).
**Резидуал:** Low. Тесты: сбой PG → честный stale/fallback в trace/UI (T-5088/T-5089).

## T-8 [D] Ошибки чтения masquerade как пустота (разрыв §28.1)
**Угроза:** исключение чтения self-фактов → пустой список → «персоны нет» без следа.
**Митигируется:** `False`/`null`/`ошибка` — три состояния (D2); ошибка → событие mca-13 + статус, не тихая пустота (T-5087); fail-open `resolve_character_context` (`bot_persona.py:373–390`) получает warning + событие (закрытие F-3 `backlog.md:216`).
**Резидуал:** Low. Тесты: инъекция ошибки → событие/статус (T-5087).

## T-9 [L] Утечка сырого контекста/секретов (R17)
**Угроза:** стадии/логи/«Аналитика» печатают сырые сообщения, source-тексты, секреты; replay-отчёты содержат живой контекст рабочего чата.
**Митигируется:** masked trace через `sanitize()` (единый канал mca-13/mca-17a); «передано/проявилось/доказан» — статусы, не содержимое; replay — offline, в рабочий чат не посылается; отчёт — числа/разброс, не сырьё.
**Резидуал:** Low. Проверка: T-5087 (R17-маскирование) + T-5093 (Scanner).

## T-10 [I/S] ЭксплойтKill-switch-семантики
**Угроза:** частичное OFF (один рубильник) оставляет запись/чтение новых таблиц → OFF ≠ паритет; или старый запрет-блок остаётся при ON (конфликт формулировок).
**Митигируется:** мастер-гейт отсекает snapshot/frame/сборку целиком; `MCA_TRAIT_RULES_ENABLED`/`MCA_LEGACY_TRAITS_MIGRATION_ENABLED` инертны по своей оси (v31-объекты не пишутся/не читаются); OFF = бит-в-бит 2.58.61 вкл. старую `_NO_AI_DISCLOSURE_BLOCK`-ветку; замена запрета — только в новой ветке (D3).
**Резидуал:** Low. Тесты: OFF-паритет в Block H (T-5091).
