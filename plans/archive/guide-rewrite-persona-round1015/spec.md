## 4. Доставка в прод-PG (F7-Q1, ключевое)

`_seed_info_key` (`services/config_cache.py:208-230`) сидит только при ОТСУТСТВИИ ключа → правка файла **не обновит** прод. Решение — **идемпотентная DML-миграция** (без DDL):

В `services/info_service.py` зафиксировать слепок `PREV_DEFAULT_INFO_TEXT` (текущий канон) — рядом с новым `DEFAULT_INFO_TEXT`.
В `services/config_cache.py` (вызов в `ConfigCache.init()`, рядом с `:139-140`) добавить `_migrate_info_how_it_works_v1015()`:
```python
async def _migrate_info_how_it_works_v1015(self) -> None:
    """F7: старый канон (== PREV_DEFAULT_INFO_TEXT) → новый; ручные правки не трогаем."""
    current = self._settings.get(_INFO_KEY)
    if not isinstance(current, dict):
        return
    html = current.get("html")
    if not isinstance(html, str) or not html.strip():
        return
    if html.strip() != PREV_DEFAULT_INFO_TEXT.strip():
        logger.warning("[config_cache] info_how_it_works изменён вручную — миграция пропущена")
        return
    value = {"html": DEFAULT_INFO_TEXT,
             "updated_at": datetime.datetime.now(datetime.timezone.utc).isoformat(),
             "updated_by": settings.ADMIN_USER_ID}
    await self.set(_INFO_KEY, value, "content")
    logger.info("[config_cache] migrated content.info_how_it_works (F7)")
```
- **Идемпотентность:** после первого прогона `html == DEFAULT_INFO_TEXT` ≠ `PREV_*` → повторный запуск no-op.
- **Ручные правки неприкосновенны:** `html` не совпал со слепком → WARNING + пропуск.
- **Ноль PG-DDL** (только `config_cache.set`). `.env`/`media/` не трогать.
