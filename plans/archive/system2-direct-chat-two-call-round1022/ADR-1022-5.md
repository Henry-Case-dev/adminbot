# ADR-1022-5 — Direct Chat: Синтезатор тулов (JSON) → Вербализатор поверх tool-цикла

- **Статус:** **Accepted** — решение владельца UPD3 (18.09.2026); уточнено Step 2b @Architect (18.09.2026)
- **Фича:** F5 `system2-direct-chat-two-call-round1022`
- **Тип:** backend/LLM (tool-loop) + канон промптов
- **Связано:** ADR-1020-7 (degradation/strip), ADR-1020-6 (lore HTML-доставка), ADR-1021-3, ADR-1013-3, F6, R17

## Context

Прямой чат отдаёт финал tool-цикла, в котором «каша» выводов инструментов (Exa/RAG/API)
влияет на ответ и потенциально протекает. ТЗ требует: Синтезатор тулов → чистая JSON-справка,
затем Вербализатор, видящий только справку. Инварианты: degraded-путь, `round_limit`,
детерминированная `lore_compiled`-доставка, порядок роутеров `bot.py`, R17 (нет секретов в
промптах/логах).

Аудит: `ToolLoopResult` уже несёт `tool_context` (сырые выводы) и `tool_trace`
(`tool_loop.py:48-73`, `:169-171`), а обработка degraded/`lore_compiled` локализована
(`direct_chat_service.py:750-773`).

## Decision

1. **System 2 включается только при реально вызванных тулах** (`tool_trace` непуст) и успешном
   tool-финале.
2. **Stage 1 — Синтезатор тулов:** вход — сообщение юзера + **санитизированный** `tool_context`
   + сводка `tool_trace`; выход — строгий JSON (§2.2 spec). CoVe-черновик допускается и срезается.
3. **Stage 2 — Вербализатор:** вход — **только** валидированный JSON; выход — финальный ответ
   (plain), стиль `STYLE_BLOCKS_SUFFIX`.
4. **Fallback:** невалидный JSON/таймаут Синтезатора → финал tool-loop; `degraded`/`lore_compiled`
   — существующие ветки без изменений.
5. **R17:** маскирование секретов/токенов в `tool_context` до промпта; содержимое не логируется.
6. Kill-switch `SYSTEM2_DIRECT_ENABLED` (env-only `ClassVar`, default ON, Δ каталога = 0).
7. Канон-миграция атомарна (ADR-1013-3), `chat_prompts.py` + `PREV_*` + `plans/docs/canon/**`.
8. **Validator Loop (UPD3 §3):** Вербализатор вызывается через
   `services/negative_constraints.verbalize_validated` (`max_retries=2`); при клише ответ
   бракуется и перегенерируется; при исчерпании — лучший вариант (fail-open), пусто/ошибка →
   финал tool-loop. Клише кодом **не** вырезаются (вето владельца).

## Consequences

- Ответ опирается на чистую справку, а не на сырые логи; утечки тегов/токенов минимизированы.
- Стоимость в tool-сценарии растёт до ≈6 вызовов (было ≤4); требуется bounded-таймауты.
- Появляется обязанность R17-санитизации `tool_context` (новый слой).

## Alternatives

- **Синтезировать всегда (в т.ч. без тулов)** — отклонено: лишний вызов там, где нечего синтезировать.
- **Передавать Вербализатору сырые tool-выводы + справку** — отклонено: нарушает изоляцию.
- **Встроить синтез в tool-loop как отдельный раунд** — отклонено: размывает контракт и риск
  для порядка раундов; синтез оставлен снаружи цикла.

## Cost ×2 / бюджет / латентность

tool-loop (≤4) + 2 вызова. Бюджет — существующие лимиты direct-чата + per-stage таймауты.
Порог «когда синтезировать» (§2.3 п.1) снижает среднюю стоимость — решение Д-6.

## Kill-switch / Fallback / Rollback

- **Kill-switch:** `SYSTEM2_DIRECT_ENABLED=false` → 10.21.
- **Fallback:** невалидный JSON/таймаут → финал tool-loop.
- **Rollback:** флаг OFF / `git revert` + обратная канон-миграция.

## Canon migration

**Обязательна (ADR-1013-3), атомарно F6→F3→F4→F5.** `DIRECT_SYNTHESIZER_*` + `DIRECT_VERBALIZER_*`
+ `PREV_*` + `PROMPT_MIGRATIONS` + `plans/docs/canon/**` + тесты.
