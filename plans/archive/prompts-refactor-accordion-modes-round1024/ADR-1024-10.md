# ADR-1024-10 — Промпты: без аккордеонов, fallback-предохранитель, табы в карточках (F6)

> **Статус:** proposed → применяется в раунде 10.24.
> **AMEND:** ADR-1023-8 (раскладка вкладки «Промпты», дефолт режима).
> **Слой:** web + каталог + `services/prompt_style_blocks.py`. Δ каталога = 0, Δ DDL = 0.
> **Human Gate №2** закрыт владельцем (UPD3 №2): дропдаун сохраняется как fallback,
> дефолт `casual`.

## Контекст

Раунд 10.23 (F8/ADR-1023-8) ввёл на вкладке «Промпты» секции «Синтезатор/Вербализатор»
и **отдельную карточку** «Вербализатор: режимы» с табами `Casual/Serious/Deep Research`
и дропдауном «Режим по умолчанию» (дефолт `serious`). Длинные Stage-1/2 промпты были
помечены `advanced` и свёрнуты в `<details class="advanced">` («Расширенные системные [N]»).

Владелец (UPD2 п.4) назвал это «катастрофой верстки»: аккордеоны с одним `textarea`
бессмысленны; табы режимов должны жить в контексте модуля, а не отдельной секцией.
Первоначально владелец просил **удалить** «Режим по умолчанию», но **UPD3 №2**
изменил решение: это **не** дефолт штатного роутинга, а **предохранитель** при сбое.

Риск-центр: ключ `prompts.verbilizer_default_mode` мог бы незаметно «перехватить»
динамический выбор режима Синтезатором. Это надо исключить контрактом и тестами.

## Решение

### D1. Убрать аккордеоны только на «Промптах»

`sec.advanced` рендерится в общем grid с `sec.basic`, без `<details>`. CSS
`details.advanced` и его поведение на `llm_providers` **не трогаются**. Это снимает
«одно поле в свёрнутом списке» без влияния на прочие вкладки.

### D2. Дропдаун — «Резервный режим (Fallback)», дефолт `casual`

- Переименование UI + title_ru каталога.
- Код-дефолт `VERBILIZER_DEFAULT_MODE: "serious" → "casual"`.
- `_syncPromptModeFromConfig` при пустом/битом значении → `casual`.
- Ключ **сохраняется** (Δ каталога = 0).

### D3. Строгий fallback-контракт (главное решение)

`compose_verbalizer_system(base, response_mode)`:
- валидный `response_mode` из Stage-1 → используется **он**; ключ дефолта **не читается**;
- отсутствующий/невалидный `response_mode` → **только тогда** `_resolve_default_mode()`
  (ключ, дефолт `casual`).

Это фиксирует текущую реализацию (`prompt_style_blocks.py:242-244`) как **инвариант**:
«предохранитель срабатывает только на сбойном пути». Тесты обязаны доказать оба плеча.

**Проводка (review iter1, High).** Изначально сбойный сигнал не доходил до собрания:
`system2_handoff.normalize_response_mode()` коэрсил невалид/пусто в `"serious"`, и
ветка `_resolve_default_mode()` была недостижима из прода. Исправлено:
`normalize_response_mode()` теперь возвращает `""` (сигнал «режим не выбран»), а
решение принимает `compose_verbalizer_system` через ключ-предохранитель. Дефолт
аргумента `response_mode` в `compose_verbalizer_system` и `SummaryDraft.response_mode`
приведён к `""` (без второго источника правды). Интеграционные тесты доказывают оба
плеча на реальной проводке direct-chat / factcheck / summary.

### D4. Табы режимов — внутрь карточек модулей

Табы + textarea выбранного режима рендерятся в каждой карточке, где есть
`stage === 'verbalizer'`, **над** полем Вербализатора. Отдельная карточка группы
`prompts_verbilizer` как набор табов убирается; её ключи редактируются из карточек.
Режим остаётся **общим** (шаренным) — правка влияет на все модули (это и есть
одна режимная политика, а не per-module). Fallback-дропдаун рендерится **один раз**
в шапке вкладки, чтобы один ключ не редактировался из нескольких мест.

### D5. Kill-switch

`PROMPTS_UI_V2_ENABLED` (env-only, default ON) через `ui_flags`; OFF → **только
раскладка** 10.23 (аккордеоны, отдельная карточка режимов). Код-дефолт `casual`
безусловен и флагом НЕ откатывается; значение `serious` возвращается лишь полным
`git revert` фичи.

## Последствия

**Плюсы:** читаемая вкладка; режимы в контексте модуля; fallback изолирован от
штатного роутинга; Δ каталога = 0; анти-клише-монитор не затронут.
**Минусы/долг:** один и тот же режимный `textarea` доступен из нескольких карточек
(шаренный; ожидаемо, но требует понятной визуальной связи); шаблон «Промпты» заметно
переписывается.
**Атомарность:** код-дефолт `casual` + каталог title + тесты — одним коммитом.

## Альтернативы

| Альтернатива | Почему отклонена |
|---|---|
| Удалить дропдаун «Режим по умолчанию» | **отменено владельцем** (UPD3 №2): нужен предохранитель |
| Оставить дефолт `serious` | UPD3 №2 явно требует `casual` |
| Сделать режим per-module | большая Δ-каталога (ключи на модуль) и разъезд режимной политики; не требуется |
| Рендерить fallback-дропдаун в каждой карточке | дублирование редактирования одного ключа, риск рассинхрона |
| Оставить аккордеоны, просто раскрывать по умолчанию | владелец требует убрать «бессмысленные сворачивающиеся списки» |
