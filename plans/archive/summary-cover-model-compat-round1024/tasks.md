## Критерии приёмки
- Обложка саммари генерируется с **любой** OpenAI-совместимой моделью (`flux`/`gptimage`/`ideogram`/…); откат на текст — только при реальной невозможности, с причиной в логах.
- **Нет** хардкод-карты `модель → параметры`; payload — строго по стандарту, без `size` и прочих ломающих полей.
- Кнопка **«Проверить подключение»** отправляет тестовый промпт и показывает тост с успехом или **сырым текстом ошибки**.
- Подтверждено, доходит ли стиль обложки до модели; финальный промпт логируется (обезличенно); вывод зафиксирован.
- pytest зелёный; прямой чат не сломан.

## Риски
- **R1 (High):** снятие `size` изменит качество/поведение у некоторых провайдеров → тесты на нескольких моделях; обложка работает по умолчанию (без `size`).
- **R2 (High):** расширенное логирование промпта может раскрыть пользовательские данные → только обезличенно/усечённо (R17).
- **R3 (High):** сырой текст ошибки в тосте может содержать чувствительное → показывать настоящую причину, но без секретов (ключ не выводить) (R17/R18).
- **R4 (Medium):** усечение промпта уберёт смысл → усекать стиль последним, сохранять visual prompt.
- **R5 (Medium):** «тихий откат» для юзера остаётся, но логи обязаны быть полными (принцип п.11).
