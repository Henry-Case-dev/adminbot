# ADR-1021-3 — Negative constraints, асимметрия и канон-миграция (ADR-1013-3)

- **Статус:** **Accepted** (UPD владельца после Human Gate, раунд 10.21)
- **Дата:** 18.09.2026, раунд 10.21
- **Контекст:** F3 `de-robotization-negative-constraints-round1021`, T-1962…T-1970
- **Связано:** **ADR-1013-3** (правило канон-миграций), ADR-1021-2 (общий коммит фактчека), F1

## 1. Контекст

Ответы синтетичны из-за RLHF-тропов. Хуже: текущий канон **сам предписывает** ровно то, что ТЗ
запрещает — «дай понять, что уже проверял … не повторять дважды» (**16 совпадений** в 5 файлах,
см. spec F3 §2.1). Значит нужна не только правка констант, но и **канон-миграция PG** (иначе прод
останется на старом каноне).

## 2. Решение

### 2.1 Блоки промптов (список финализирован владельцем)
Во все отвечающие модули добавляются два блока:
- **A «АНТИ-БОТ»** — прямой запрет фраз **«как ИИ»**, **«надеюсь, помог»**, зеркальных перепалок
  **«нет, ты»**, **списков с буллитами**, **морализаторства**, а также **«ты уже спрашивал /
  ты спрашиваешь это уже N раз»** (из исходного ТЗ); плюс «не X, а Y», троекратные перечисления, «мораль» в конце.
- **B «АСИММЕТРИЯ»** — чередование длины предложений, сознательный игнор части набросов, одна метафора
  вместо шаблона, без завершающего вопроса.

### 2.2 Канон-миграция (ADR-1013-3), атомарно одним коммитом
1. Правка актуальных констант в `factcheck_prompts.py`, `search_prompts.py`, `summary_prompts.py`,
   `web_prompts.py`, `youtube_prompts.py`, `chat_prompts.py`, `checkup_prompts.py`.
2. Новые слепки `PREV_*_R1021` (текущий прод-канон) для каждого изменённого PG-ключа.
3. `services/prompt_migrations.py` — новые ступени `PREV_*_R1021 → new`.
4. `plans/docs/canon/architecture.md` + `backlog.md` — эталон-блоки.
5. Тесты-снапшоты + `test_prompt_migrations.py`.

**Полный список ключей миграции:**
`prompts.direct_chat_system_prompt`, `prompts.factcheck_system_prompt`, `prompts.search_system_prompt`,
`prompts.summary_system_prompt`, `prompts.compress_system_prompt` (если затронут блоком),
`prompts.webpage_system_prompt`, `prompts.youtube_system_prompt`, `prompts.youtube_video_system_prompt`,
`prompts.checkup_system_prompt`.

### 2.3 Что НЕ трогаем
- `services/lore_prompts.py:115,323` — «сохранённая ранее история» (легитимный UPD-механизм, не троп).
- `services/dossier_prompts.py`, `services/dream_prompts.py`, `services/nostalgia_prompts.py` — воркеры.
- `INFO_CANON_VERSION` — в коде отсутствует, к промптам не применимо.

## 3. Обоснование (research)

- AI-отпечаток = структурная симметрия, а не словарь: https://github.com/matteoroversi/anti-ai-rhetoric
  (4-проходный процесс: draft → cut filler → break symmetry → add rough edge).
- Каталог tells и предупреждение не «геймить burstiness»: https://github.com/ssamba1/untell/pull/8.
- RLHF reward-модели выучивают шаблон-предпочтения: https://aclanthology.org/2025.findings-acl.1237.pdf —
  поэтому запрет нужно формулировать как процесс ревизии, а не список слов.

## 4. Альтернативы

| Альтернатива | Вердикт |
|---|---|
| Только negative constraints без снятия конфликтующей фразы | Промпт противоречит сам себе → модель выбирает троп. Отклонено. |
| Обернуть блоки A/B во флаг | Невозможно: канон-PG либо старый, либо новый; флаг даст рассинхрон. Отклонено. |
| Массово переписать tone/мат | Вне скоупа ТЗ (10.20 сохранял tone) и рискует сломать ожидаемый владельцем стиль. Отклонено. |

## 5. Последствия и откат

- Δ каталога = 0 (промпты уже в каталоге).
- Прод-PG обновится идемпотентной миграцией (`migrate_prompt_canons`).
- **Откат нетривиален:** `git revert` вернёт константы, но PG останется на новом каноне → **обязателен
  обратный шаг миграции** (`PREV_R1021 → old`), **обратный скрипт сохраняется** (Д9=да) в runbook @DevOps.
- R11/R2-риск: утечка снятого канона из кэша — проверить инвалидацию `ConfigCache` и `smart_cache`.

## 6. Решения Human Gate (UPD)

- **Д7 → да:** объём канон-миграции (ключи + файлы) идёт одним атомарным коммитом с F2.
- **Д8 → список запретных фраз финализирован владельцем** (строка 131): «как ИИ», «надеюсь, помог»,
  зеркальные «нет, ты», списки с буллитами, морализаторство + «ты уже спрашивал / ты спрашиваешь это уже N раз».
- **Д9 → да:** обратный миграционный скрипт сохраняется сразу (runbook @DevOps).
