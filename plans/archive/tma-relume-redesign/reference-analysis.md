## 1. Что это

Сторонний сайт, сгенерированный **Relume** — статический экспорт-мокап админ-панели
Telegram Mini App для нашего бота. Язык — русский, тексты — реальные описания фич
бота (PERMsoc, Славик/Костик/Оля/Леха, сон/ностальгия, лор чата, RBAC-роли).
Использовать ТОЛЬКО как дизайн-референс. В git не коммитится (T-1066).

## 4. Черновой маппинг «референс → mini-app» (уточняется в T-1072)

| Референс | Текущая вкладка/группа |
|----------|------------------------|
| Статус сервера и бота | `status` (метрики/графики/логи) |
| Настройки AI (хаб) | `MENU_LABELS.ai` (5 секций-вкладок) |
| LLM Провайдеры | `llm_providers` (models_main/keys_llm/fallback) |
| Промпты | `prompts` |
| Лимиты | `limits` (токены/кулдауны/бюджеты/температура-select) |
| Память | `memory_rag` + частично `relations`/`people_names` |
| Сон и Ностальгия | `memory_dream` + `memory_nostalgia` (в референсе — 1 страница) |
| Функции PERMsoc | `permsoc` (карточки модулей) |
| Модули | `modules_feats` + `modules_switches` |
| Кастомные модули | часть `modules_feats` / `reactions_triggers` |
| Как это работает | `info` |
| Доступы и Роли | `access` + матрица ролей (`web/api/roles.py`) |
| Матрица ролей | `access` (param_permissions) |
| Локальные админы чата | `chat_profile` (chat_admins) |
| Управление администраторами | `access` (bot_admins/роли) |

**Наблюдение:** референс и текущий мини-апп описывают один и тот же набор фич;
различие — в **навигационной модели** (многостраничные роуты + hub-карточки vs
единая SPA с меню-секциями) и в **визуальном слое**.

## 5. Дизайн-токены (первичный снимок — доводится в T-1069)

- **Шрифты:** `--font-family-heading`/body = **Inter** (400/500/600); иконки —
  Material Symbols Outlined/Rounded/Sharp.
- **Схемы:** `scheme-3`, `scheme-4` (navbar = scheme-4); `--scheme-background`.
- **Палитра (первично):** base `#000000` / `#ffffff`; акцент `#14CBB6`
  (`--button-fill`); текст `#070707`/`#161616`.
- **Формы:** `--radius-small`, `--button-radius`, `--border-width: 1px`,
  input/button radius, paddings `.5–1.25rem`.
- **Лейаут:** `--body-max-width: 35rem`, секционные paddings крупные (desktop) /
  `4.75rem` (≤991px); поддержка `prefers-reduced-motion`.

## 6. Компонентные паттерны (доводится в T-1070)

- Fixed navbar (лого слева, меню справа) + hub-карточки подразделов.
- KPI-плитки метрик (Аптайм, CPU, RAM, Диск, Ошибки со старта).
- Графики-плейсхолдеры + панель логов с копированием строк.
- Карточки модулей: имя + описание + статус + триггеры + бюджет (вкл/выкл).
- Таблица «Матрица ролей» (роль × параметр → чтение/запись/скрыто).
- Маскировка ключей / статусы провайдеров.
