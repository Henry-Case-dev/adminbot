## §43 «Ожидает применения» — N/A (обоснование)

**Статус: не применимо (унаследовано от F3).** Конфигурация — **read-through**: `ConfigCache` (in-memory) + PG/`chat_params`; `GET /api/config` (`web/api/routes.py:398-540`) сразу отдаёт **эффективное** значение (`chat_source` override → `global_value` → default), запись — `POST /api/config` + NOTIFY. Отдельного applied-state с отложенным применением сервер не имеет → показывать «Ожидает применения» нечего (иначе выдуманное состояние, запрещено §43). F4 обязана **не добавлять** такой индикатор; факт.состояние = эффективный `value` + `configItemNotice` при реальном расхождении. **Пересмотр — только если @Architect в ADR-1025-14 докажет обратное по коду (тогда отдельная задача).**
