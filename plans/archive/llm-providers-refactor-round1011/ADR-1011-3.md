# ADR-1011-3 — Ось X графика «История доступности ключей»: linear-time без адаптера

- **Статус:** Accepted (@Architect, 12.09.2026)
- **Пункт ТЗ:** 3 (график разорванных чёрточек).
- **Связано:** ADR-1010-2 (render-only lanes, сетка 300с, `api_payload`
  неизменен) — наследуется полностью.

## Контекст

- Библиотека: Chart.js 4 (CDN, `web/index.html:3040`); **date-adapter НЕ
  подключён**.
- Текущий конфиг: `type:'line'`, категориальная ось (labels `HH:MM`),
  `stepped:true`, но `spanGaps:false` (`web/app.js:3533-3536`) → на
  разреженных данных линия рвётся на отдельные «чёрточки».
- ADR-1010-2 запрещал `type:'time'` + adapter (новая зависимость, вес,
  TMA/offline-риск) и смену серверного контракта.

## Решение

1. **Сетку 300с/`MIN_BUCKETS`/окно-от-конца оставить** (ADR-1010-2),
   `api_payload` не трогать.
2. **Данные датасета** — точки `{x: bucket*1000, y: laneValue|null}` (ms),
   отсутствующий бакет = `{x, y:null}`. Два поля-режима: `xMin`/`xMax`
   из сетки.
3. **`spanGaps:true`** (заменить `false`) — пропуски «тянутся» от статуса к
   следующему опросу; `stepped:true` сохраняется.
4. **X-ось** — `{ type:'linear', min:xMin, max:xMax, ticks:{ callback:
   v→HH:MM(new Date(v)) } }`. Это реальная числовая временная шкала
   (пропорциональные интервалы), но **без chartjs-adapter** → работает
   offline/в TMA WebView и не меняет зависимости.
5. `parsing:false` используется вместе с явными `{x,y}`. Если живой QA
   покажет, что `y:null` при `parsing:false` не даёт разрыва, Builder
   emit-ит только присутствующие точки (шаг по-прежнему «тянется» до
   следующей, `spanGaps:true` остаётся как маркер AC).

## Отклонено

- **`type:'time'` + `chartjs-adapter-date-fns`** — новая CDN-зависимость,
  offline/TMA-риск (ADR-1010-2 подтверждает).
- **Dense-сетка на сервере** — смена leak-safe контракта `api_payload`;
  запрещено.
- **Scatter/Timeline** — не даёт ступенчатого статуса без переписывания
  маппинга; Line+spanGaps+stepped проще и покрыт тестами.

## Последствия

- Плюс: непрерывная ступенчатая линия на разреженных данных; честная
  временная ось; ноль новых зависимостей; контракт API не изменён.
- Минус: форма `keyHistoryChartModel` меняется (labels → точки `{x,y}`) →
  JS-юниты `tests/js/routing_test.js:586-660` обновляются осознанно;
  render-маркеры `stepped:true`/`legend` сохраняются.
- Feature flag не требуется; rollback = `git revert`.
