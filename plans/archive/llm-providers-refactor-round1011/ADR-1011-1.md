# ADR-1011-1 — «Проверить» использует сохранённый ключ, не нарушая R17

- **Статус:** Accepted (@Architect, 12.09.2026)
- **Пункт ТЗ:** 1 (поле ключа провайдера).
- **Контекст:** при уже сохранённом ключе поле в UI пустое (маска только в
  `placeholder`), фронт шлёт `api_key: ''`, бэкенд отвечает
  `not_configured / «ключ не задан»`. Владелец просит буквально «показывать
  ключ в поле, если он присвоен». Показ сырого секрета нарушает R17
  (`plans/project.md` §Секреты; `web/api/routes.py:194-203` `_mask_secret`).

## Решение

1. **Бэкенд-резолв (источник истины):** `services/llm_probe.probe_block` при
   пустом/отсутствующем `api_key` подставляет **сохранённый** ключ блока из
   горячего конфига (`hot.get(pg_key, settings_default)`). Карта
   `block → pg_key` покрывает: `direct_main`, `direct_fallback`,
   `transcribe_groq`, `transcribe_openrouter`, `video_summary_openrouter`,
   `video_fallback`, `embeddings*`, `search_keys:tavily|exa`, `media_share`.
2. **UI (R17-безопасно):** поле остаётся пустым, `placeholder` =
   `configured ••••last4` / `не настроен` (как сейчас,
   `web/app.js:2055-2061`). Добавляется видимый **hint** под полем:
   «Ключ сохранён (••••last4) — можно проверить без ввода». Сырое значение
   НЕ попадает в DOM/сеть/логи.
3. Если пользователь ввёл новый ключ (черновик) — отправляется именно он
   (тест до сохранения, как раньше). Пустая строка/отсутствие → сохранённый.

## Отклонено

- **Показ сырого ключа в `:value`** — прямое нарушение R17; отклонено,
  несмотря на буквальный запрос владельца. Компромисс: маска + hint +
  рабочий тест без ввода.
- **Фронт шлёт sentinel `__stored__`** — лишний протокол; сервер и так
  знает блок и может резолвить сам, а sentinel пришлось бы валидировать.
- **Наполнять `blockDrafts` ключом при загрузке** — раскрывает секрет в
  памяти/DOM и ломает MINOR-3-семантику `null`/`''`.

## Последствия

- Плюс: «Проверить» работает без повторного ввода для всех секретных блоков
  (включая `media_share`); R17 сохранён; `saveBlock` (MINOR-3: `null` = не
  трогать, `''` = очистить) не меняется.
- Минус: пользователь не «видит» ключ — компенсируется mask-hint.
- **Feature flag не требуется:** изменение аддитивно (только fallback при
  пустом ключе), не меняет env/схему; rollback = `git revert`.
