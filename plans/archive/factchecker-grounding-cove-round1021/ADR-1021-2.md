# ADR-1021-2 — Strict grounding цитат + Chain-of-Verification фактчекера

- **Статус:** **Accepted** (UPD владельца после Human Gate, раунд 10.21)
- **Дата:** 18.09.2026, раунд 10.21
- **Контекст:** F2 `factchecker-grounding-cove-round1021`, T-1953…T-1961
- **Связано:** ADR-1021-3 (канон-миграция), ADR-1020-5 (Full Tool Access), ADR-1020-7 (reasoning)

## 1. Контекст

Фактчекер галлюцинирует теги `[04.2023 | fact:2574]`: ID и даты не существуют во входном контексте.
`FACTCHECK_SYSTEM_PROMPT` (`services/factcheck_prompts.py:74`) просит модель быть аккуратной, но не
запрещает выдумывать якоря. Full Tool Access (10.20) даёт доступ к локальной базе, но не гарантирует,
что цитируемые ID взяты из полученного тул-вывода.

## 2. Решение

Двухконтурная защита:

1. **Детерминированный extern verifier (всегда ON).** Новый чистый модуль собирает из `user`-контента
   допустимые `fact:ID`, месяцы `ММ.ГГГГ` и ISO-даты. Пост-обработчик вердикта **жёстко вырезает**
   фантомные теги (id/месяц не в множестве; Д6=вырезать). Стоимость 0 LLM, риск ложных срабатываний
   минимизирован (идём от точного формата тега, а не от «любой даты»).
2. **CoVe-hidden-блок (безусловно, default ON — UPD).** Промпт добавляет скрытый `<reasoning>`-черновик
   «найденные факты → сверка → чего нет в контексте»; вердикт — после `</reasoning>`. Отдельного флага нет.
   Срез обеспечивает существующий `strip_reasoning_tags` через `cleanup_llm_text`
   (`services/factcheck_service.py:121`).

## 3. Обоснование (research)

- CoVe (ACL Findings 2024, arXiv 2309.11495): декомпозиция проверки и независимость от baseline-ответа
  существенно снижают галлюцинации; самая надёжная часть — **явная** стадия сверки.
- LLM2 (arXiv 2412.20372): внешний процессный верификатор (System 2) отсекает нежелательные шаги —
  архитектурно это ровно наш детерминированный валидатор.

## 4. Альтернативы

| Альтернатива | Вердикт |
|---|---|
| Только промпт (без валидатора) | Недостаточно: LLM игнорирует инструкции под давлением формата. |
| Полный factored-CoVe в отдельных вызовах | Дорого (×2–3) в чат-контуре; даёт прирост, который в нашем масштабе перекрывается валидатором. Отложено. |
| Запретить любые даты в вердикте | Ломает полезную функцию ссылок на локальную историю. Отклонено. |
| Проверять ID походом в БД | Ложные негативы (ID из tool-output не всегда есть в `graph_facts` в момент проверки) + лишние запросы. Отклонено. |

## 5. Последствия

- **Δ каталога = 0:** отдельного флага нет; CoVe — безусловный блок канона (см. сводную таблицу F1 §7).
- Канон-миграция обязательна и **атомарна с F3** (ADR-1013-3): константа + `PREV_*` + `prompt_migrations.py` +
  `plans/docs/canon/**` + тесты одним коммитом. Иначе прод-PG останется на старом каноне.
- Валидатор аддитивен и работает всегда; откат — обратная миграция + `git revert`.
- R17: логи только counts.

## 6. Решения Human Gate (UPD)

- **Д5 → CoVe включён по умолчанию** (строка 127 UPD); режима «после живого прогона» нет.
- **Д6 → фантомный тег жёстко вырезается** (вариант «вырезать», без нейтральной замены).
