## 2. Режимы отказа и поведение

1. **Фасад/БД недоступны** → витрина: честное «данные недоступны» + retry-политика опроса; таблица: ошибка с кодом; мутация: не выполняется, состояние UI не теряется. Не имитировать нули.
2. **K-OFF зависимостей** (`MCA_EPISODES_ENABLED`, `MCA_EVENT_CONTRACT_ENABLED`, mca-09 `intents` OFF, mca-18/19/20-гейты) → соответствующие блоки честно `disabled`/скрыты; остальные оси работают (независимые гейты, прецедент mca-07).
3. **Обрыв соединения миниаппа** (A54) → reconnect-сверка по cursor, догрузка без дублей; stale-индикатор «данные от…»; пауза не выглядит live.
4. **Redirect-цель удалена/зациклена** → резолв фасада возвращает честный терминал (нет цели), UI — «история объединена, цель недоступна», без тихой подмены.
5. **Конфликт прав при открытом редакторе** → 403/409 с сохранением набранного локально (без автоповтора).

## 3. Проверки Scanner (T-5173, обязательные)

- RBAC/chat scope всех 5 routes (TH-1/TH-2, A25-репро: чужой чат + неавторизованная мутация).
- Дифф-греп: `v-html`, `eval`, `innerHTML`, `dangerously` в новых блоках — запрещено (TH-3).
- Публичные payload'ы feed/summary без message-контента и raw-логов (TH-4, `:798`).
- Логи/экспорт без initData/Authorization/cookies (TH-5, `:844`).
- CAS: 409-путь без автозатирания; redirect-резолв перед действием (TH-6, A13).
- Серверная валидация пагинации/фильтров/сортировок (TH-7).

**Критерий: Critical/High = 0** (Medium/Low — по стандартному циклу rework).
