## Решения

**D1. Одна модель, один фасад: mca-12 — UI/read-слой поверх `services/mca_episodes.py` (v21), нулевой производитель сущностей.** Никаких новых таблиц, второй модели историй, второго event-канала, своих merge/split/CAS-механик (CA-12-1). Read-side запросы (пагинация/фильтры/агрегаты) — AMEND репозитория существующего фасада; мутации — прямые вызовы `update_story_manual`/`merge_stories`/`split_story`/`set_story_excluded`/`assemble_stories`. Лента — read-проекция существующих `mca_events` (story-типы mca-05), не второй канал (CA-12-2).

**D2. NEW web-слой из двух файлов: `web/api/stories.py` (роутер) + `services/web_stories.py` (read-сборщик DTO).** Отдельный роутер-файл по прецеденту зон (`memory_agi.py`/`oversight.py`) — меньше швов с параллельными пакетами в монолитном `routes.py`. Сборщик — только DTO-агрегация; бизнес-логики нет.

**D3. Размещение: одна вставка в F11-композицию «Статус» после зоны мониторинга интеллекта, до нижних логов; без нового маршрута.** `#/stories` не создаётся (GEN-R12); существующие виджеты и порядок сохранены; Liquid Glass/палитра/градиент сохранены; блок не прячется за меню.

**D4. Лента: polling + cursor/dedup по `event_id`, prepend без сброса scroll, reconnect-сверка (A54/§27.6 `:1434`).** SSE/WS нет — инкрементальный polling (прецедент инцидентов mca-17a); stale ≠ healthy; обе даты (событие/обнаружение) для recheck-событий (A11); bounded ретенцией mca-13 с честной пометкой.

**D5. Счётчики/прогресс — SQL-агрегаты существующих полей + read-рендер статусов существующих процессов** (`episodes.build`/`episodes.backfill`, реестр mca-17a + `task_jobs` mca-01). Пусто/unknown/не запущено — различимые честные состояния; нуль только после успешного расчёта; демо-данные — только с явной меткой.

**D6. Таблица — подраздел существующей «Памяти» (F6-хаб), серверная keyset-пагинация `(chat_id, updated_at, story_id)`, фильтры поверх существующих колонок v21, поиск LIKE title/summary/claims в пределах чата.** Полнотекстовый движок историй не строится; server-side валидация параметров обязательна; деградация на прод-explain → эскалация индекс-санкции через реестр mca-14 (§18), тихие миграции запрещены (CA-12-8).

**D7. Карточка — один UI-объект, два входа (лента — на месте, таблица); состав `:794` полностью.** Источники — SourceRef-форма mca-04a (provenance mca-05 `:2177`); версии/ручные изменения — `mca_story_versions` + `override_*`; противоречия/неизвестное — честно.

**D8. Действия — только операции фасада, CAS `expected_version`; stale → 409 без затирания (A13).** Telegram-ссылка — только при валидных числовых метаданных; иначе архивный просмотр; отсутствие оригинала — явное состояние. Overrides пайплайн не затирает (существующая гарантия `:2140–2157`); переживание сна/пересборки — тест.

**D9. M-MCA05-2 включён в пакет (T-5161, до UI-«пересобрать»): сигнатура unchanged-детектора `:2143–2159` дополняется claims/участниками/датами** (`:1909–1922` — та же зона сборки). Behavior-фикс завершения change-driven контракта — без kill-switch; контрактный тест no-op rebuild. Долг «закрыть до mca-12» (backlog `:118`) закрывается здесь; отдельный backlog-фикс отменён.

**D10. §16.3 — рендер замороженного `intent_snapshot()` mca-09 (`status_service.py:713`); честные disabled/not_run/restricted; без «мыслей».** Журнал — раскрытие + существующая «Аналитика».

**D11. Настройки §16.3 — рендер существующих ParamSpec (default/effective/источник/hot-restart); Δ каталога = 0; F8 NOT_APPLICABLE.** Widget-ID не регистрируются: витрина историй ↔ существующий «Эпизоды/lore» (`mca_process_registry.py:431/815/845`), витрины смежных ↔ существующие ID `:933/:982/:1024/:1063/:1115/:1154`; пробел → эскалация @Architect + mca-17a; матрица/фуннель — mca-17c (CA-12-3). Витрины смежных фич читают существующие API (`/persona/self_model`, `/api/factcheck/temporal/runs`, vision-API, `/api/memory/lessons`); лента 10b — сослаться, не дублировать.

**D12. Права/приватность:** RBAC + chat scope на каждом read/mutation (A25); мутации — права редактирования памяти + CAS; публичная витрина — разрешённые краткие данные, не raw-логи (`:798`); initData/Authorization/cookies — не в UI-логах (§17.3 `:844`), secrets не в localStorage/bundle; story-текст — недоверенный контент: текстовые узлы без `v-html`, CSP zero-build сохраняется; параметризованные запросы.

**D13. Санкции: Δ DDL = 0** (все данные — v21-таблицы/`mca_events`/`task_jobs`; SQLite+PG не меняются); **Δ каталога = 0**; **KS +2** (`MCA_STORIES_VITRINA_ENABLED`, `MCA_STORIES_MANAGE_ENABLED` — env-only `ClassVar` default ON; OFF = блок скрыт/disabled, паритет по своей оси; отсчёт 83→85 от пост-mca-20, 80→82 от HEAD); **reason_code Δ = 0** (отказы — HTTP-семантика + payload-состояния); **тулы Δ = 0**; **процессы/widget-ID — без новых**; **routes +5** (`GET /api/stories/summary`, `GET /api/stories/feed`, `GET /api/stories`, `GET /api/stories/{story_id}`, `POST /api/stories/{story_id}/action`; прецедент action-endpoint `memory_agi.py:1403`); `ROUTES_SHA256_F11` — осознанный re-pin (L-F11S-1; прецеденты mca-19/mca-20).

**D14. Deploy: CA-11, пер-фичевый bump 2.58.64→2.58.65; план `:212` DEFERRED_TO_RELEASE superseded (право §2 плана; прецедент ADR-1028-20 D13).** Обоснование: живой UI главной витрины + мутационный контур → изолированный бласт-радиус/откат; вся волна движется пер-фичево (2.58.55…2.58.64). Rollback: soft — 2 switch OFF + routes-репин; cold — git revert (DDL/каталог не меняются). Секвенция — после деплой-окна mca-20; интеграционные приёмки витрин mca-19/20 — после восстановления канала (рантайм-данные, не код-зависимость).

**D15. Q2-санкция:** M-MCA05-2 — в пакете (D9).

**D16. Risk R2 confirmed; threat-failure-analysis выпущен превентивно** (зона RBAC/публичная витрина/XSS/CAS — TH-1…TH-8, 0 Critical/High без mitigation; Scanner T-5173 обязателен). R3-триггеры (изменение схемы, write-path, фоновая активность, приватность-поверхность raw-данных) не сработали: write-path — существующий CAS-фасад; DDL=0.

## Последствия

Builder получает замороженные контракты (DTO/cursor/CAS-action/routes) и может строить три ленты параллельно (spec §6); параллельная безопасность с mca-17c обеспечена границей «компактные рендеры ≠ матрица»; откат тривиален (DDL/каталог не меняются, 2 гейта). Невыполнение Q2-фикса до «пересобрать» деградирует ленту шумовыми версиями — порядок задач зафиксирован. Смена решения о деплое возможна только новым AMEND этого ADR (@Architect), не молча.
