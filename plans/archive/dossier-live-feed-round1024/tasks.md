## Цель
Виджет «Живая лента досье» нечитаем. Сделать: (1) **вертикальную** прокрутку снизу вверх, заметно медленнее; (2) **каждую строку кликабельной** → открытие модалки «Досье» этого пользователя.

- [x] **T-2213** [@Architect] ADR: вертикальный тикер (CSS `translateY`, скорость), click-through контракт строки, и **UX при GLOBAL-режиме** (лента глобальная, а досье — per-chat) — решение Human Gate №9.
- [x] **T-2214** [@Builder] Backend: добавить `user_id` (и при необходимости `user_name`) в `dossier_feed` (`services/database.py:4551-4580`) и в ответ API (`web/api/oversight.py:196-206`), не раскрывая лишнего.
- [x] **T-2215** [@Builder] CSS: заменить горизонтальную прокрутку на **вертикальную, снизу вверх**, существенно медленнее (например, `translateY` на контейнере фиксированной высоты); уважать `prefers-reduced-motion` (как в `:1028-1029`).
- [x] **T-2216** [@Builder] Frontend: строка ленты кликабельна → `openDossier({ user_id, name })`; при GLOBAL-режиме сначала переключить контекст на нужный `chat_id` (согласно решению T-2213), затем открыть досье; корректный `key`, доступность (`role="button"`, клавиатура).

- [x] **T-2218** [@Builder] Тесты: (a) API отдаёт `user_id`; (b) клик по строке вызывает `openDossier` с верным `user_id`; (c) GLOBAL→chat переключение; (d) `node --check web/app.js`.
- [ ] **T-2219** [@Reviewer] Ревью: лента действительно вертикальная и медленная; интерактив работает; нет утечки приватных полей; GLOBAL-UX корректен.

## Критерии приёмки
- Лента движется вертикально (снизу вверх) и заметно медленнее горизонтального варианта.
- Каждая строка открывает модалку «Досье» соответствующего пользователя; в GLOBAL-режиме контекст чата разрешается корректно.
- API не раскрывает лишних персональных данных; `user_id` приходит.
- JS-гейт и pytest зелёные.

## Риски
- **R1 (High):** GLOBAL-лента ↔ per-chat досье: без активного чата `openDossier` не работает → обязательное решение T-2213 и fallback (подсказка/переключение).
- **R2 (Medium):** вертикальная анимация на длинном списке тормозит TMA → ограничить число элементов, лёгкий CSS.
- **R3 (Medium):** `user_id` может раскрыть внутренние идентификаторы → отдавать только в рамках global-admin эндпоинта (он и так под `requires_global_admin`).
- **R4 (Low):** regress `prefers-reduced-motion`.
